Orthogonality and least squares

By the end of this lesson you can
  • Fit the best line to noisy sensor data
  • Project any vector onto a line or a plane
  • Turn any basis into an orthonormal one with Gram-Schmidt

Perpendicular subspaces, projections, the best answer when Ax = b has no solution, fitting lines to data, and orthonormal bases built by Gram-Schmidt. 8 short slides, then worked examples and problems. Each slide has an everyday picture, a worked example and Python you can run right on the page.

Projection Matrix P = A(AᵀA)⁻¹Aᵀ Explained

The projection onto a line is Pb with P = aaᵀ/aᵀa. Onto the column space of A, P = A(AᵀA)⁻¹Aᵀ. Why P² = P, with examples and Python. Strang §4.2.
