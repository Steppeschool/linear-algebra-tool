Strang §4.3 · Least squares approximations

Least squares: the best answer when there is no exact one.

With more equations than unknowns, Ax = b usually has no solution. Least squares picks the x̂ that makes the error ‖b − Ax‖ as small as possible. Geometrically, Ax̂ is the projection of b onto the column space, and x̂ solves AᵀAx̂ = Aᵀb.

Lesson 5 · slide 4Least squares
AᵀA x̂ = Aᵀb    e = b − Ax̂    Aᵀe = 0
Key ideas
  1. Ax = b is solvable only when b lies in the column space C(A). Noisy data almost never does.
  2. Least squares minimizes E = ‖b − Ax‖², the sum of the squared errors.
  3. The best Ax̂ is the projection of b onto C(A). The error is perpendicular to every column: Aᵀe = 0.
  4. That condition is the normal equations AᵀAx̂ = Aᵀb.
  5. AᵀA is square and invertible when the columns of A are independent.

Three stopwatches, one runner

Three friends time the same 100 m sprint and get 10.2, 10.5 and 10.0 seconds. The "equations" are x = 10.2, x = 10.5, x = 10.0. No single x satisfies all three. Still, everyone agrees on a sensible answer: the average, 10.23 seconds.

That everyday choice is least squares. In matrix form, A has a single column, a = (1, 1, 1), and b = (10.2, 10.5, 10.0). Slide 2 tells us how to project b onto the line through a:

x̂ = aᵀb / aᵀa = (10.2 + 10.5 + 10.0) / 3 = 10.23

The average is the projection onto (1, 1, 1).

The general recipe

Now A has n columns and m > n rows. Every Ax lies in the column space, a flat subspace inside ℝᵐ. The data b sticks out of it. We cannot reach b, so we go to the closest point we can reach, which is the projection p = Ax̂.

The error e = b − Ax̂ must be perpendicular to the column space, so every column dotted with e gives zero. Stack those dot products and you get Aᵀe = 0:

Aᵀ(b − Ax̂) = 0   ⟹   AᵀA x̂ = Aᵀb

We cannot solve Ax = b, but we can always solve AᵀAx̂ = Aᵀb. It is a small square system, n by n, however many measurements there are.

A worked example

Find the best straight line through three measurements: at times t = 0, 1, 2 we read the values b = 1, 1, 4. The line predicts C + Dt at time t, so each measurement gives one equation C + Dt = b:

A = 101112,   x = (C, D),   b = (1, 1, 4)
AᵀA = 3335,   Aᵀb = (6, 9)
Solve 3C + 3D = 6 and 3C + 5D = 9: subtracting gives 2D = 3, so D = 1.5 and C = 0.5.   The best line is 0.5 + 1.5t
Ax̂ = (0.5, 2, 3.5),   e = (0.5, −1, 0.5),   Aᵀe = (0, 0) ✓

Why AᵀA is invertible

Suppose AᵀAx = 0. Multiply by xᵀ on the left: xᵀAᵀAx = (Ax)ᵀ(Ax) = ‖Ax‖² = 0, so Ax = 0. (The transpose of a product reverses the order: (Ax)ᵀ = xᵀAᵀ.) If the columns of A are independent, that forces x = 0. So AᵀA has only the zero vector in its nullspace and is invertible. For a line fit this means: use at least two different times t, so that the column of ones and the column of times are independent.

Where this is used

A GPS receiver usually sees more satellites than the four it needs. Each one gives an equation, the equations disagree slightly because of noise, and the receiver takes the least squares position. More satellites, more equations, a better average.

Worked examples

Example 1 · The average is least squares

One unknown, three readings: x = 3, x = 5, x = 10.

a = (1, 1, 1),   b = (3, 5, 10)
x̂ = aᵀb / aᵀa = 18 / 3 = 6
e = (−3, −1, 4),   sum of errors = 0 ✓ (perpendicular to (1, 1, 1))

Example 2 · The normal equations by hand

A = 100111, b = (1, 1, 0). The three equations x = 1, y = 1, x + y = 0 disagree.

AᵀA = 2112,   Aᵀb = (1, 1)
2x₁ + x₂ = 1 and x₁ + 2x₂ = 1 give x̂ = (⅓, ⅓),   Ax̂ = (⅓, ⅓, ⅔)
e = (⅔, ⅔, −⅔),   Aᵀe = (⅔ − ⅔, ⅔ − ⅔) = (0, 0) ✓

The compromise: each equation is off by ⅔.

Example 3 · When b is already reachable

Same A, but b = (1, 2, 3).

Aᵀb = (4, 5),   AᵀA x̂ = Aᵀb gives x̂ = (1, 2)
Ax̂ = (1, 2, 3) = b,   e = 0

b was in the column space, so least squares returns the exact solution. It never makes a solvable problem worse.

Five readings of one length: 4, 5, 5, 6, 10. What is the least squares estimate?

Write the normal equations for the line C + Dt through (0, 2), (1, 0), (2, 1), and solve them.

A = 101112, b = (2, 0, 1). AᵀA = 3335, Aᵀb = (3, 2).

3C + 3D = 3 and 3C + 5D = 2. Subtract: 2D = −1, so D = −0.5 and C = 1.5. The best line is 1.5 − 0.5t.

3

Explain why the errors in a least squares line fit always add up to zero.

Show solutionHide solution

The first column of A is all ones. Aᵀe = 0 says every column is perpendicular to e. For the column of ones, that means e₁ + e₂ + ... + e_m = 0.

Worked examples

Example 1 · Project onto a line in 3D

Project b = (3, 0, 3) onto the line through a = (1, 2, 2).

aᵀb = 3 + 0 + 6 = 9,   aᵀa = 1 + 4 + 4 = 9,   x̂ = 1
p = (1, 2, 2),   e = b − p = (2, −2, 1)
a · e = 2 − 4 + 2 = 0 ✓

The distance from b to the line is ‖e‖ = 3.

Example 2 · Fit a line to five points

Fit C + Dt to (−2, 0), (−1, 1), (0, 1), (1, 2), (2, 4).

The times are centred: Σt = 0, so the normal equations separate
5C = Σb = 8,   C = 1.6
10D = Σtb = 0 − 1 + 0 + 2 + 8 = 9,   D = 0.9

Best line: 1.6 + 0.9t. Choosing t so that Σt = 0 is a common trick: it makes the columns of A perpendicular, because the column of ones dotted with the column of times is Σt = 0.

Example 3 · Gram-Schmidt and QR in 3D

a = (1, 0, 1), b = (1, 1, 0).

aᵀb = 1, aᵀa = 2:   u₂ = b − ½a = (½, 1, −½),   a · u₂ = ½ − ½ = 0 ✓
q₁ = (1, 0, 1)/√2,   q₂ = u₂/√1.5
With A = [a b]: R = QᵀA, e.g. R₁₂ = q₁ᵀb = 1/√2 = √21/√20√1.5

Check in the lab: Q, R = np.linalg.qr(A), then Q @ R gives A back.

Problems

1

Are (1, −1, 0) and (1, 1, 5) perpendicular? Find a nonzero vector perpendicular to both.

Show solutionHide solution

1 − 1 + 0 = 0, so yes.

A vector (x, y, z) perpendicular to both needs x − y = 0 and x + y + 5z = 0. Take x = y = −5, z = 2: (−5, −5, 2). Check: −5 + 5 + 0 = 0 and −5 − 5 + 10 = 0 ✓

2

Project b = (1, 2, 3) onto the line through a = (1, 0, 1).

Show solutionHide solution

aᵀb = 4, aᵀa = 2, x̂ = 2. p = (2, 0, 2), e = (−1, 2, 1). Check: −1 + 0 + 1 = 0 ✓

3

Find the projection matrix onto the line through a = (2, 1) and apply it to b = (5, 0).

Show solutionHide solution

P = aaᵀ / aᵀa = ⅕4221. Pb = ⅕(20, 10) = (4, 2).

4

Find the least squares solution of x = 1, x = 4, 2x = 4.

Show solutionHide solution

A has one column, a = (1, 1, 2), and b = (1, 4, 4). x̂ = aᵀb / aᵀa = (1 + 4 + 8) / 6 = 13/6 ≈ 2.17.

5

Find the best line C + Dt through (0, 4), (1, 2), (2, 1), (3, 1).

Show solutionHide solution

m = 4, Σt = 6, Σt² = 14, Σb = 8, Σtb = 0 + 2 + 2 + 3 = 7.

4C + 6D = 8 and 6C + 14D = 7 give D = −1 and C = 3.5. Best line: 3.5 − t.
