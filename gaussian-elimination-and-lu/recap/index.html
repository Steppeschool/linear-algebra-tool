What you can now do.

Lesson 2 in one page: two ways to read Ax = b, how elimination solves it, how matrices multiply, and how the steps combine into A = LU.

Lesson 2 · slide 8Recap
A  →  U by elimination    A = LU
Key ideas
  1. Row picture: lines that cross. Column picture: columns that combine to make b.
  2. Pivots and multipliers: ℓ = entry ÷ pivot.
  3. Back substitution solves a triangle from the bottom up.
  4. Zero pivots: exchange rows if possible, otherwise the matrix is singular.
  5. Each step is a matrix E. AB is A times each column of B, and AB ≠ BA in general.
  6. The multipliers build L in A = LU.
  • §2.1 Row and column pictures. The same system read two ways: by rows, lines that cross at the answer; by columns, how much of each column makes b. Parallel lines go with dependent columns.
  • §2.2 Elimination. The café puzzle: subtract one equation from another to remove an unknown. Multiplier = entry ÷ pivot.
  • §2.2 Back substitution. The chain of keys: the last row gives the last unknown, which unlocks the row above.
  • §2.2 Breakdown. The relay race: a zero pivot means swap rows if you can, and if you can't, the system is singular.
  • §2.3 Elimination matrices. Instruction cards: E₂₁ subtracts ℓ times row 1 from row 2. Stack them to reach U.
  • §2.4 Matrix multiplication. Each entry of AB is a row of A times a column of B. Column j of AB is A times column j of B. A is m by n and B is n by p, so AB is m by p. Order matters: AB is usually not BA.
  • §2.6 A = LU. Meal prep: factor once, then solve each new b with two fast triangular solves. L holds the multipliers. In the lab, lu(A) does not exchange rows: if a zero pivot appears, it stops with the error "zero pivot in row k: this matrix needs a row exchange (PA = LU)". Lesson 3 adds the row exchanges.

Examples

Example 1

Solve 2x + y = 4 and 6x + 5y = 14.

Show solutionHide solution

ℓ = 3: (6x + 5y) − 3(2x + y) = 14 − 12 gives 2y = 2, so y = 1 and x = 1.5.

Example 2

Find L and U for 1429.

Show solutionHide solution

ℓ = 2: U = 1401, L = 1021.

Example 3

For which c is 123c singular?

Show solutionHide solution

The second pivot is c − 3·2 = c − 6. It is zero when c = 6: then row 2 is 3 times row 1.
