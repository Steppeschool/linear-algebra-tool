Strang §2.2 · The idea of elimination

Elimination knocks out one unknown at a time.

Elimination is the method every computer uses to solve linear equations. We subtract a multiple of one equation from another so that one unknown disappears. What is left is easier, and we repeat until we can read off the answer.

Lesson 2 · slide 1Elimination
x − 2y = 1    3x + 2y = 11   →   8y = 8
Key ideas
  1. The pivot is the first coefficient of the equation we subtract with (equation 1; here the 1 in 1x). We use it to remove x from the equations below.
  2. The multiplier is ℓ = (entry to remove) ÷ (pivot). In code we write ℓ as l.
  3. Subtracting ℓ times one equation from another keeps the same solution.
  4. When one unknown is left in the last equation, we solve it and work back up: back substitution.

A puzzle you already know how to solve

A coffee and a croissant cost €5. A coffee and two croissants cost €7. What does a croissant cost?

Nobody writes down a formula for this. We compare the two orders: the second has exactly one more croissant and costs €2 more, so a croissant is €2 and the coffee is €3. Without saying so, we subtracted the first equation from the second, and the coffee disappeared. That is elimination.

The same idea, step by step

Take Strang's first system from lesson 1: x − 2y = 1 and 3x + 2y = 11.

  • The first equation starts with 1x. That coefficient is the pivot: we will use it to clear the x below it.
  • The second equation has 3x. To remove it we need 3 copies of the first equation. That number is the multiplier, ℓ = 3 ÷ 1 = 3.
  • Subtract 3 times equation 1 from equation 2. The x terms cancel.
(3x + 2y) − 3(x − 2y) = 11 − 3·1
8y = 8,  so y = 1
Back up to equation 1: x − 2·1 = 1,  so x = 3

The last step, putting y = 1 back into the first equation, is called back substitution.

Why the answer does not change

If (x, y) satisfies both original equations, it also satisfies "equation 2 minus 3 times equation 1", because we only combined true statements. And we can undo the step by adding 3 times equation 1 back. So the new system has exactly the same solutions as the old one, just in an easier form.

What it looks like

Run the code in the lab before and after the subtraction. In the row picture, the second line turns flat: it becomes y = 1. The first line does not move, and the crossing point stays at (3, 1). Elimination turns the second line into a simpler one without moving the crossing point.

Where this is used

Circuit simulators, structural analysis and many other engineering tools solve equations this way. Their systems simply have thousands of unknowns instead of two, and a computer does the subtractions.

Worked examples

Example 1 · Subtract twice the first equation

Solve 2x + y = 5 and 4x − y = 1.

Pivot 2, multiplier ℓ = 4 ÷ 2 = 2
(4x − y) − 2(2x + y) = 1 − 2·5  →  −3y = −9  →  y = 3
Back up: 2x + 3 = 5, so x = 1
Check: 4·1 − 3 = 1 ✓

Example 2 · A pivot of 1

Solve x + 3y = 7 and 2x + y = 4.

ℓ = 2 ÷ 1 = 2.   (2x + y) − 2(x + 3y) = 4 − 14  →  −5y = −10  →  y = 2
x + 6 = 7, so x = 1

A pivot of 1 is the friendliest case: the multiplier is just the entry below it.

Example 3 · A fractional multiplier

Solve 3x + 2y = 7 and x + 4y = 9.

ℓ = 1 ÷ 3 = 1/3
(x + 4y) − (1/3)(3x + 2y) = 9 − 7/3  →  (10/3) y = 20/3  →  y = 2
3x + 4 = 7, so x = 1

Fractions are fine. The rule never changes: multiplier = entry to remove ÷ pivot.

Worked examples

Example 1 · A 2 by 2 system

Solve 2x + 3y = 8 and 4x + 11y = 26.

Pivot 2, multiplier ℓ = 4 ÷ 2 = 2. Equation 2 − 2·(equation 1): 5y = 10
Back substitution: y = 2, then 2x + 6 = 8, so x = 1
Check: 4·1 + 11·2 = 26 ✓

The pivots are 2 and 5. Their product, 10, is det A.

Example 2 · A 3 by 3 system

Solve x + y + z = 6, 2x + 3y + z = 11, x + 3y + 4z = 19.

ℓ₂₁ = 2: row 2 becomes (0, 1, −1 | −1).   ℓ₃₁ = 1: row 3 becomes (0, 2, 3 | 13)
ℓ₃₂ = 2: row 3 becomes (0, 0, 5 | 15)
z = 3  →  y − 3 = −1, y = 2  →  x + 2 + 3 = 6, x = 1

U = 11101−1005, pivots 1, 1, 5.

Example 3 · Factor once, solve with L and U

Factor A = 2168 and use it to solve Ax = (3, 19).

ℓ = 6 ÷ 2 = 3, so U = 2105 and L = 1031
Lc = b: c₁ = 3, then 3·3 + c₂ = 19, so c₂ = 10
Ux = c: 5x₂ = 10, x₂ = 2, then 2x₁ + 2 = 3, x₁ = 1/2
Check: 6·(1/2) + 8·2 = 19 ✓

Problems

1

Solve x − y = 1 and 3x + 2y = 13 by elimination. Name the pivots.

Show solutionHide solution

ℓ = 3. Equation 2 − 3·(equation 1): 5y = 10, so y = 2 and x = 3. Check: 9 + 4 = 13 ✓

Pivots: 1 and 5.

2

For A = 4265, find the multiplier ℓ₂₁, the second pivot and det A.

Show solutionHide solution

ℓ₂₁ = 6 ÷ 4 = 1.5. Second pivot: 5 − 1.5·2 = 2.

det A = 4·2 = 8, the product of the pivots. Check: 4·5 − 2·6 = 8 ✓

3

For which number a does 1a28 have a zero second pivot? Can a row exchange fix it?

Show solutionHide solution

The second pivot is 8 − 2a. It is zero when a = 4.

No row exchange helps: there is no row below row 2 to swap in. The matrix is singular (column 2 = 4·column 1).

4

Write the elimination matrix E₂₁ for A = 210641023 and compute E₂₁A.

Show solutionHide solution

ℓ₂₁ = 6 ÷ 2 = 3, so E₂₁ = 100−310001.

E₂₁A = 210011023. Only row 2 changed: (6, 4, 1) − 3·(2, 1, 0) = (0, 1, 1).

5

Find L and U for A = 12310.

Show solutionHide solution

ℓ = 3, so U = 1204 and L = 1031.

Check: LU = 1236 + 4 = A ✓
