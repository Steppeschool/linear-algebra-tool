Strang §2.6 · Elimination = factorization

LU decomposition: A = LU keeps a record of elimination

Slide 5 wrote elimination as E₃₂E₃₁E₂₁A = U, and slide 6 showed how such products work. Now we run it backwards. Keep every multiplier ℓ from elimination in a lower triangular matrix L: 1s on the diagonal, the multipliers below it, zeros above. Then L times U gives A back: A = LU. Think of meal prep. Chop the week's vegetables on Sunday, and every dinner is quick. Factoring A = LU is the Sunday work, and each new right side b is a quick dinner: two easy triangle solves.

Lesson 2 · slide 7A = LU
A = LU    L = 100ℓ₂₁10ℓ₃₁ℓ₃₂1
Key ideas
  1. A = LU: L is lower triangular with 1s on its diagonal, U is upper triangular.
  2. The multipliers ℓᵢⱼ go straight into L, in the positions where they were used.
  3. To solve Ax = b: first solve Lc = b, then Ux = c. Both are fast triangular solves.
  4. Factor once, then reuse L and U for every new right-hand side b.

Solving with L and U

Why two solves? Ax = b is L(Ux) = b. Call Ux = c. Solve Lc = b for c, then Ux = c for x.

Lc = b  (forward substitution, top to bottom)    then    Ux = c  (back substitution, bottom to top)

This is slide 3's c: b after elimination. Solving Lc = b top-down (forward substitution) just redoes those subtractions on b. Row 2 of L reads ℓ₂₁c₁ + c₂ = b₂, so c₂ = b₂ − ℓ₂₁c₁ = −2 − 2·5 = −12, as on slide 3. Problem 2 below finishes c₃.

Where L comes from

Slide 5 wrote elimination as E₃₂E₃₁E₂₁A = U. To get A back, undo the steps in reverse order:

A = E₂₁⁻¹ E₃₁⁻¹ E₃₂⁻¹ U = LU

Shoes come off before socks: the last step done is the first undone. So E₃₂⁻¹ sits next to U.

Each inverse is the identity with +ℓ where E had −ℓ (slide 5). In this order the multipliers don't mix, as the product below shows. So L needs no extra arithmetic: it is the record of the multipliers.

The example from slides 3 to 5

The multipliers were ℓ₂₁ = 2, ℓ₃₁ = −1, ℓ₃₂ = −1. Multiply the three inverses:
E₂₁⁻¹ E₃₁⁻¹ E₃₂⁻¹ = 100210001 100010−101 1000100−11 = 100210−1−11
Each multiplier sits in place: ℓ₂₁ in row 2, column 1, ℓ₃₁ in row 3, column 1, ℓ₃₂ in row 3, column 2.
Compare the E's themselves. If we multiply E₃₂E₃₁E₂₁, the entries mix: row 3, column 1 comes out as −1, not −ℓ₃₁ = +1. The inverses, in reverse order, do not mix. So L is just the multipliers, and that is why we record L.
L = 100210−1−11   U = 2110−8−2001
Check row 3 of LU: −1·211 − 1·0−8−2 + 1·001 = −272, which is row 3 of A ✓

You can watch both triangles grow at the same time. Start with L = I and U = A. Each elimination step changes one row of U, and its multiplier drops into the same spot of L.

Why it saves time

For n unknowns, factoring takes about n³/3 multiplications, and each triangular solve about n². With n = 1000: roughly 330 million operations to factor, then about a million per new b.

So when only the right side changes, as in a simulation stepping through time, factor once and reuse L and U. In the lab, lu(A) returns both factors so you can check your work.

A bigger example: 4 × 4

A = 2100231002310023
ℓ₂₁ = 2 ÷ 2 = 1: row 2 → 0210.   ℓ₃₂ = 2 ÷ 2 = 1: row 3 → 0021.   ℓ₄₃ = 2 ÷ 2 = 1: row 4 → 0002
The other multipliers (ℓ₃₁, ℓ₄₁, ℓ₄₂) are 0, because those entries are already 0
L = 1000110001100011   U = 2100021000210002
Check row 3 of LU: 1·0210 + 1·0021 = 0231 ✓

Each row of A only touches its neighbours, so L and U stay just as thin. Matrices like this come up in simulations with thousands of unknowns, and the thin L and U make every new solve very fast.

Example 5

Why does A = 0111 have no LU factorization? How is it fixed?

Show solutionHide solution

The first pivot is 0, so no multiplier can be formed. Swap the rows first. Lesson 3 writes this swap as a permutation matrix P: PA = 1101 is already upper triangular, so PA = LU with L = I.
