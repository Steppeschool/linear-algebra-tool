Strang §2.7 · Transposes

The transpose swaps rows and columns.

The transpose Aᵀ turns the rows of A into columns. A matrix that equals its own transpose is called symmetric, and the product AᵀA is always symmetric.

Lesson 3 · slide 5Transpose
123456ᵀ = 135246
Key ideas
  1. Row i of A becomes column i of Aᵀ. An m by n matrix becomes n by m.
  2. (AB)ᵀ = BᵀAᵀ: the order reverses, as for inverses.
  3. Symmetric means S = Sᵀ: entry (i, j) equals entry (j, i).
  4. AᵀA is always symmetric. It is the heart of least squares in the next part of the course (Strang, chapter 4).

Think of turning a spreadsheet

A sales sheet has one row per product and one column per month. Your manager asks for months as rows instead. No number changes; only the way you read them does. That is the transpose.

123456ᵀ = 135246

Symmetric matrices: the distance table

A road atlas has a table of distances between cities. The distance from Paris to Lyon equals the distance from Lyon to Paris, so if you flip the table across its diagonal, nothing changes. Such a table is a symmetric matrix.

The rules

  • (AB)ᵀ = BᵀAᵀ. The order reverses, just as for inverses on slide 3.
  • (A⁻¹)ᵀ = (Aᵀ)⁻¹. Transposing and inverting can be done in either order.
  • The dot product of x and y can be written xᵀy: a row times a column.
  • AᵀA is symmetric. Its (i, j) entry is column i of A dotted with column j. Swapping i and j gives the same dot product.

A worked example

A = 123456 is 3 by 2, so AᵀA is 2 by 2.
(1, 1): 1 + 9 + 25 = 35   (1, 2): 2 + 12 + 30 = 44   (2, 2): 4 + 16 + 36 = 56
AᵀA = 35444456

Where this is used

AᵀA appears whenever we fit a model to many noisy measurements, for example a straight line through sensor readings or the calibration of an accelerometer. For a rotation matrix Q, QᵀQ = I, so the transpose is the inverse: turning back costs nothing to compute.

Worked examples

Example 1 · A wide matrix turned tall

A = 123456 is 2 by 3.

Aᵀ = 142536 is 3 by 2

Example 2 · The order flips

A = 1101, B = 2031.

AB = 5131, so (AB)ᵀ = 5311
BᵀAᵀ = 23011011 = 5311 ✓

Example 3 · Dot product as xᵀy

x = (1, 2, 3), y = (4, 0, −1).

xᵀy = 1·4 + 2·0 + 3·(−1) = 1

Worked examples

Example 1 · A 2 by 2 inverse

Find the inverse of A = 4726.

det A = 4·6 − 7·2 = 10
A⁻¹ = 1/10 · 6−7−24
Check, top-left entry of AA⁻¹: (4·6 + 7·(−2)) / 10 = 1 ✓

Example 2 · Gauss-Jordan step by step

Invert A = 1237 by elimination on [A | I].

[1 2 | 1 0; 3 7 | 0 1]  → row 2 − 3·row 1 →  [1 2 | 1 0; 0 1 | −3 1]
row 1 − 2·row 2 →  [1 0 | 7 −2; 0 1 | −3 1]
A⁻¹ = 7−2−31

det A = 1, so the formula gives the same answer with no fractions.

Example 3 · The transpose of a product

Check (AB)ᵀ = BᵀAᵀ for A = 1201 and B = 1031.

AB = 7231, so (AB)ᵀ = 7321
BᵀAᵀ = 13011021 = 7321 ✓

AᵀBᵀ would be 1327: the wrong order gives a different matrix.

Problems

1

Find the inverse of 3152.

Show solutionHide solution

det = 3·2 − 1·5 = 1, so A⁻¹ = 2−1−53.

Check: row 1 of A times column 1 of A⁻¹ = 3·2 + 1·(−5) = 1 ✓

2

For which k is 2k46 not invertible?

Show solutionHide solution

det = 12 − 4k = 0 when k = 3. Then column 2 = (3, 6) = 1.5·column 1, and the plane is squashed onto a line.

3

A = 1101, B = 2003. Find (AB)⁻¹ as B⁻¹A⁻¹.

Show solutionHide solution

B⁻¹ = ½00⅓ and A⁻¹ = 1−101.

B⁻¹A⁻¹ = ½−½0⅓. Check: AB = 2303 and its inverse from the formula, 1/6·3−302, is the same ✓

4

Compute AᵀA for A = 102103. Is it symmetric?

Show solutionHide solution

AᵀA = 52210. Entry (1, 1) = 1 + 4 + 0, entry (1, 2) = 0 + 2 + 0, entry (2, 2) = 0 + 1 + 9.

Yes, it is symmetric, as AᵀA always is.

5

Find the permutation P that puts the rows of a 3 by 3 matrix in the order 2, 3, 1. What is P⁻¹?

Show solutionHide solution

The rows of P are rows 2, 3, 1 of I: P = 010001100.

P⁻¹ = Pᵀ = 001100010, which puts the rows back.
