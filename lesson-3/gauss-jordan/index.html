Strang §2.5 · Gauss-Jordan elimination

Eliminate on [A | I] and the inverse appears.

Write A and the identity side by side. Use row operations to turn A into I. The same operations turn I into A⁻¹.

[ A  |  I ]  →  [ I  |  A⁻¹ ]

Think: carbon paper

Put a sheet of carbon paper under your work. Every row operation you do on A gets copied onto the identity beside it.

When A has been turned into I, the copy holds the record of everything you did. Undoing A is exactly what that record does, so the copy is A⁻¹.

The steps

  • Forward: clear below the pivots, as in lesson 2.
  • Backward: clear above the pivots too, from the bottom up.
  • Scale: divide each row by its pivot so the diagonal becomes 1s.

The result is the reduced row echelon form. The lab's rref does all three steps.

Worked example

K = 2−10−12−10−12 shows up for a chain of springs and masses.
K⁻¹ = ¼ · 321242123
Check one column: K times (3, 2, 1) = (6 − 2, −3 + 4 − 1, −2 + 2) = (4, 0, 0), which is 4 times the first column of I ✓

Don't use it to solve Ax = b

Computing A⁻¹ costs about three times the work of elimination, and it adds rounding error. To solve Ax = b, use elimination (A = LU). As Strang stresses: the inverse is great for thinking, but don't compute A⁻¹ to solve Ax = b.

Worked examples

Example 1 · A 2 by 2 by hand

Invert A = 2111.

[2 1 | 1 0; 1 1 | 0 1] → row 2 − ½·row 1 → [2 1 | 1 0; 0 ½ | −½ 1]
row 2 × 2 → [0 1 | −1 2]; row 1 − row 2 → [2 0 | 2 −2]; row 1 ÷ 2
A⁻¹ = 1−1−12

Example 2 · A triangular matrix

Invert A = 120013001. Only upward steps are needed.

row 2 − 3·row 3, then row 1 − 2·row 2
A⁻¹ = 1−2601−3001

The 6 comes from the two steps interacting: −2 · (−3).

Example 3 · When Gauss-Jordan stops

Try A = 1224.

row 2 − 2·row 1 → [1 2 | 1 0; 0 0 | −2 1]

The left side has a zero row, so it can never become I. No inverse.

Worked examples

Example 1 · A 2 by 2 inverse

Find the inverse of A = 4726.

det A = 4·6 − 7·2 = 10
A⁻¹ = 1/10 · 6−7−24
Check, top-left entry of AA⁻¹: (4·6 + 7·(−2)) / 10 = 1 ✓

Example 2 · Gauss-Jordan step by step

Invert A = 1237 by elimination on [A | I].

[1 2 | 1 0; 3 7 | 0 1]  → row 2 − 3·row 1 →  [1 2 | 1 0; 0 1 | −3 1]
row 1 − 2·row 2 →  [1 0 | 7 −2; 0 1 | −3 1]
A⁻¹ = 7−2−31

det A = 1, so the formula gives the same answer with no fractions.

Example 3 · The transpose of a product

Check (AB)ᵀ = BᵀAᵀ for A = 1201 and B = 1031.

AB = 7231, so (AB)ᵀ = 7321
BᵀAᵀ = 13011021 = 7321 ✓

AᵀBᵀ would be 1327: the wrong order gives a different matrix.

Problems

1

Find the inverse of 3152.

Show solutionHide solution

det = 3·2 − 1·5 = 1, so A⁻¹ = 2−1−53.

Check: row 1 of A times column 1 of A⁻¹ = 3·2 + 1·(−5) = 1 ✓

2

For which k is 2k46 not invertible?

Show solutionHide solution

det = 12 − 4k = 0 when k = 3. Then column 2 = (3, 6) = 1.5·column 1, and the plane is squashed onto a line.

3

A = 1101, B = 2003. Find (AB)⁻¹ as B⁻¹A⁻¹.

Show solutionHide solution

B⁻¹ = ½00⅓ and A⁻¹ = 1−101.

B⁻¹A⁻¹ = ½−½0⅓. Check: AB = 2303 and its inverse from the formula, 1/6·3−302, is the same ✓

4

Compute AᵀA for A = 102103. Is it symmetric?

Show solutionHide solution

AᵀA = 52210. Entry (1, 1) = 1 + 4 + 0, entry (1, 2) = 0 + 2 + 0, entry (2, 2) = 0 + 1 + 9.

Yes, it is symmetric, as AᵀA always is.

5

Find the permutation P that puts the rows of a 3 by 3 matrix in the order 2, 3, 1. What is P⁻¹?

Show solutionHide solution

The rows of P are rows 2, 3, 1 of I: P = 010001100.

P⁻¹ = Pᵀ = 001100010, which puts the rows back.
