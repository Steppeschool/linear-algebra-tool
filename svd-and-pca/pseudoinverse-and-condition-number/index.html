Strang §7.4 · The pseudoinverse

The pseudoinverse: the best undo for any matrix.

A singular or rectangular matrix has no inverse. The SVD still gives the next best thing: undo each stretch that can be undone, and ignore the directions that were squashed to zero. That is the pseudoinverse A⁺. It also shows how sensitive a problem is: the ratio σ₁/σₙ, the condition number.

Lesson 8 · slide 6Pseudoinverse
A⁺ = VΣ⁺Uᵀ (Σ⁺: 1/σ for each nonzero σ)    x⁺ = A⁺b    condition number = σ₁ / σₙ
Key ideas
  1. Σ⁺ replaces each nonzero σ by 1/σ and keeps the zeros as zeros.
  2. A⁺ = VΣ⁺Uᵀ. If A is invertible, A⁺ = A⁻¹.
  3. x⁺ = A⁺b is the least squares solution (lesson 5) with the smallest length.
  4. The condition number σ₁/σₙ says how much errors in b can be amplified in x.

The best possible undo

A squashed piece of dough cannot be unsquashed: the information about its thickness is gone. But everything that was only stretched can be stretched back. The pseudoinverse does exactly that: undo the turns, divide by every nonzero σ, and leave the squashed directions at zero.

The formula

A = UΣVᵀ,   so undo in reverse order:   A⁺ = VΣ⁺Uᵀ
Σ = σ₁000  →  Σ⁺ = 1/σ₁000

When all σ's are nonzero (A square and invertible), Σ⁺ = Σ⁻¹ and A⁺ is just A⁻¹.

A worked example

A = 1111, b = (2, 4):   x + y = 2 and x + y = 4 contradict each other
σ₁ = 2 with u₁ = v₁ = (1, 1)/√2,   σ₂ = 0
A⁺ = v₁(1/2)u₁ᵀ = ¼1111
x⁺ = A⁺b = ¼(6, 6) = (1.5, 1.5)

The best compromise makes x + y = 3, halfway between 2 and 4: that is least squares. Among all x with x + y = 3, (1.5, 1.5) is the shortest. The pseudoinverse always picks this shortest best answer.

The condition number

If σ₁ is large and σₙ is tiny, A nearly squashes a direction. Solving Ax = b then divides by that tiny σₙ, and any small error in b is blown up. The ratio σ₁/σₙ is the condition number.

A = 1111.001: σ₁ ≈ 2, σ₂ ≈ 0.0005, condition number ≈ 4000
An error of 0.001 in b can move x by about 4000 times as much (relative)

Where this is used

Robot arms near a singular pose use the pseudoinverse (often a damped version) to turn a desired hand motion into joint speeds without asking for infinite speed. Every numerical solver reports the condition number as a warning light: a large one means "do not trust the last digits".

Worked examples

Example 1 · An invertible matrix

A = 2004: A⁺ = ½00¼ = A⁻¹. Condition number 4/2 = 2: very safe.

Example 2 · A tall matrix

A = (1, 1) as a column (2 by 1), b = (3, 5).

σ₁ = √2, u₁ = (1, 1)/√2, v₁ = 1
A⁺ = (1/√2)·(1/√2)(1, 1) = (½, ½) as a row
x⁺ = (3 + 5)/2 = 4: the average, as in lesson 5

Example 3 · A zero matrix

A = 0: every σ is 0, so A⁺ = 0 and x⁺ = 0, the shortest of all (equally bad) answers.

The singular values of A are 100 and 0.01. What is its condition number, and what does it mean?

Show solutionHide solution

100 / 0.01 = 10,000. Relative errors in b can grow up to 10,000 times in x: about four digits of accuracy are lost.

3

Show that AA⁺A = A.

Show solutionHide solution

AA⁺A = UΣVᵀ VΣ⁺Uᵀ UΣVᵀ = UΣΣ⁺ΣVᵀ. ΣΣ⁺Σ = Σ (each nonzero σ gives σ · 1/σ · σ = σ, zeros stay 0). So AA⁺A = UΣVᵀ = A.

Worked examples

Example 1 · SVD of a tall matrix

A = 101101 (3 by 2).

AᵀA = 2112: λ = 3 with (1, 1)/√2,   λ = 1 with (1, −1)/√2
σ₁ = √3, σ₂ = 1
u₁ = Av₁/σ₁ = (1, 2, 1)/√6,   u₂ = Av₂/σ₂ = (1, 0, −1)/√2 (perpendicular ✓)

Example 2 · A rank-one matrix

A = 122436 = (1, 2, 3) times the row (1, 2).

One piece: σ₁ = |(1, 2, 3)| · |(1, 2)| = √14 · √5 = √70 ≈ 8.37,   σ₂ = 0
u₁ = (1, 2, 3)/√14,   v₁ = (1, 2)/√5

Example 3 · Pseudoinverse of a tall matrix

A = 100001, b = (1, 2, 3).

A⁺ = 100001,   x⁺ = (1, 3)
The middle equation 0 = 2 cannot be met; x⁺ satisfies the other two exactly

Problems

1

Find the singular values of 2112.

Show solutionHide solution

It is symmetric with eigenvalues 3 and 1, both positive, so σ₁ = 3 and σ₂ = 1.

2

Find the singular values of 403-5.

Show solutionHide solution

AᵀA = [25 −15; −15 25]: trace 50, det 625 − 225 = 400. λ² − 50λ + 400 = (λ − 40)(λ − 10). σ₁ = √40 ≈ 6.32, σ₂ = √10 ≈ 3.16. Check: σ₁σ₂ = 20 = |det A| ✓

3

Write 3311 as one piece σuvᵀ with unit vectors.

Show solutionHide solution

It is (3, 1) times the row (1, 1). σ = |(3, 1)| · |(1, 1)| = √10 · √2 = √20, u = (3, 1)/√10, v = (1, 1)/√2.

4

A 200 by 300 image has singular values that drop below 1% of σ₁ after the first 30. How many numbers does the rank-30 copy store?

Show solutionHide solution

30 · (200 + 300 + 1) = 15,030, compared with 60,000 for the full image: a quarter.

5

Centered data has singular values 6, 2, 1. What share of the spread do the first two principal components explain?

Show solutionHide solution

Squares 36, 4, 1, total 41. (36 + 4)/41 ≈ 97.6%.
