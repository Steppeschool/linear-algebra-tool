Strang §7.3 · Principal component analysis

PCA: the direction where the data spreads most.

Measurements often form a cloud that is long in one direction and thin in the others. Principal component analysis (PCA) finds the long direction. Subtract the average, take the SVD, and the first right singular vector points along the cloud. σ₁² says how much of the spread it captures.

Lesson 8 · slide 5PCA
center: C = data − mean    C = UΣVᵀ    first principal component = v₁    share = σ₁² / (σ₁² + σ₂² + …)
Key ideas
  1. Put the measurements as rows of a matrix and subtract the average of each column: the centered matrix C.
  2. The first principal component is v₁, the first input direction in the SVD of C (the first right singular vector). It is the direction of greatest spread.
  3. σᵢ² measures the spread along vᵢ; σ₁² / (σ₁² + σ₂² + …) is the share it explains.
  4. The line through the mean along v₁ minimises the sum of squared perpendicular distances to the points.

A robot vacuum along a wall

A robot vacuum drives along a straight wall and logs its xy position eight times. The tracker is noisy, so the points scatter around the true path. The cloud is long along the wall and thin across it. PCA finds the long direction from the numbers.

Step 1: center the data

The average position is 3.942.71. Subtract it from every point, so the cloud sits around the origin. Put the centered points as the rows of an 8 by 2 matrix C.

Step 2: the SVD of C

For a unit direction v, Cv lists how far each point reaches along v. |Cv|² adds up the squares: the spread along v. By slide 1, |Cv| is largest for v = v₁, with |Cv₁| = σ₁. So v₁ is the first principal component.

For the robot data: v₁ points at about 29.6°, the second direction v₂ is perpendicular to it
σ₁² / (σ₁² + σ₂²) ≈ 0.992: the wall direction explains 99.2% of the spread
