Strang §7.1 · Image processing by linear algebra

Compressing an image: keep the big pieces.

A grey picture is a matrix of brightness values. Its SVD lists the picture's pieces from most to least important. Keep the first few pieces and you keep most of the picture while storing far fewer numbers. Pictures with simple structure need very few pieces.

Lesson 8 · slide 4Image compression
A ≈ A_k = σ₁u₁v₁ᵀ + … + σₖuₖvₖᵀ    error set by the dropped σ's
Key ideas
  1. A grey image with m rows and n columns of pixels is an m by n matrix.
  2. A_k, the first k SVD pieces, is the closest matrix of rank k to A (the Eckart–Young theorem).
  3. Storing A_k needs k(m + n + 1) numbers instead of mn.
  4. Fast-falling singular values mean the image compresses well.

A sketch artist

A good sketch artist draws the big shapes first, then the main lines, and only then the fine detail. After a few strokes you already recognise the face. The SVD orders an image the same way: the first piece is the biggest pattern, each later piece adds smaller detail.

Pictures are matrices

Give each pixel a number from 0 (white) to 1 (black). An 8 by 8 picture of the letter F becomes an 8 by 8 matrix of 0s and 1s. A photo of 1000 by 1000 pixels is a 1000 by 1000 matrix: a million numbers.

Keep k pieces

A_k = σ₁u₁v₁ᵀ + σ₂u₂v₂ᵀ + … + σₖuₖvₖᵀ
Each piece costs m + n + 1 numbers (u, v and σ)
1000 by 1000 photo, k = 50: 50 · 2001 ≈ 100,000 numbers instead of 1,000,000

No other matrix of rank k is closer to A than A_k. The error comes only from the dropped pieces: the most the copy can be off in any direction is σₖ₊₁, the largest dropped σ. When the dropped σ's are small, the copy is good.

The letter F

Its singular values: 4.38, 1.41, 0.91, then all zero
Rank 3: three pieces rebuild the F exactly. One piece gives a blurry block; two pieces get the shape roughly right

The F is made of blocks lined up with the rows and columns, so it needs very few pieces. A photo of a face has slowly falling singular values and needs more, but still far fewer than its size.

Where this is used

The same idea, keep the big components and drop the small ones, is used to compress sensor logs, remove noise from signals and shrink large neural networks so they run on a drone's small computer.

Worked examples

Example 1 · A flag with stripes

Three horizontal stripes: each row is one number repeated: a number times the all-ones row.

Rank 1: one piece (a column of stripe values times a row of ones) rebuilds it exactly.

Example 2 · A checkerboard

1010010110100101: rows repeat in two patterns.

Rank 2: σ₁ = σ₂ = 2, then zeros. Two pieces.

Example 3 · Counting storage

A 640 by 480 image kept with k = 20 pieces.

20 · (640 + 480 + 1) = 22,420 numbers
Full image: 640 · 480 = 307,200. About 7% of the size

1

A 100 by 200 image is stored with k pieces. For which k does this stop saving space?

Show solutionHide solution

k(100 + 200 + 1) < 100 · 200 means k < 20000/301 ≈ 66.4. From k = 67 on, the pieces cost more than the image.

2

The singular values of an image are 50, 10, 1, 0.1, 0.01. Roughly how good is the rank-2 copy?

Show solutionHide solution

The dropped σ's are 1, 0.1, 0.01, tiny next to 50 and 10. The rank-2 copy is almost perfect.

3

Why does a picture of a diagonal line need many pieces, while a vertical stripe needs one?

Show solutionHide solution

A vertical stripe has identical rows: rank 1. A diagonal line has a different row for every row (each row's 1 is in a new column), so its rank is large.

Worked examples

Example 1 · SVD of a tall matrix

A = 101101 (3 by 2).

AᵀA = 2112: λ = 3 with (1, 1)/√2,   λ = 1 with (1, −1)/√2
σ₁ = √3, σ₂ = 1
u₁ = Av₁/σ₁ = (1, 2, 1)/√6,   u₂ = Av₂/σ₂ = (1, 0, −1)/√2 (perpendicular ✓)

Example 2 · A rank-one matrix

A = 122436 = (1, 2, 3) times the row (1, 2).

One piece: σ₁ = |(1, 2, 3)| · |(1, 2)| = √14 · √5 = √70 ≈ 8.37,   σ₂ = 0
u₁ = (1, 2, 3)/√14,   v₁ = (1, 2)/√5

Example 3 · Pseudoinverse of a tall matrix

A = 100001, b = (1, 2, 3).

Both σ's are 1 and A⁺ = Aᵀ here: A⁺ = 100001,   x⁺ = (1, 3)
The middle equation 0 = 2 cannot be met; x⁺ satisfies the other two exactly

Problems

1

Find the singular values of 2112.

Show solutionHide solution

It is symmetric with eigenvalues 3 and 1, both positive, so σ₁ = 3 and σ₂ = 1.

2

Find the singular values of 403-5.

Show solutionHide solution

AᵀA = [25 −15; −15 25]: trace 50, det 625 − 225 = 400. λ² − 50λ + 400 = (λ − 40)(λ − 10). σ₁ = √40 ≈ 6.32, σ₂ = √10 ≈ 3.16. Check: σ₁σ₂ = 20 = |det A| ✓

3

Write 3311 as one piece σuvᵀ with unit vectors.

Show solutionHide solution

It is (3, 1) times the row (1, 1). σ = |(3, 1)| · |(1, 1)| = √10 · √2 = √20, u = (3, 1)/√10, v = (1, 1)/√2.

4

A 200 by 300 image has singular values that drop below 1% of σ₁ after the first 30. How many numbers does the rank-30 copy store?

Show solutionHide solution

30 · (200 + 300 + 1) = 15,030, compared with 60,000 for the full image: a quarter.

5

Centered data has singular values 6, 2, 1. What share of the spread do the first two principal components explain?

Show solutionHide solution

Squares 36, 4, 1, total 41. (36 + 4)/41 ≈ 97.6%.
