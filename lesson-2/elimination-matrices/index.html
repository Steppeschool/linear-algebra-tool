Strang §2.3 · Elimination using matrices

Each elimination step is a matrix.

Subtracting ℓ times row 1 from row 2 is the same as multiplying by E₂₁: the identity matrix with −ℓ in row 2, column 1.

E₂₁ = 100−ℓ10001    E₂₁A = A with row 2 − ℓ·(row 1)

Think: an instruction card

A row operation is an instruction: "take row 2, subtract 2 of row 1, leave everything else alone". E₂₁ is that instruction written as a matrix.

Multiplying by E is following the card. Elimination is a stack of cards applied one after another:

E₃₂ E₃₁ E₂₁ A = U
Read right to left, like socks and shoes: E₂₁ acts first.

Why it works: rows combine rows

Lesson 1 read Ax by columns. EA is easiest to read by rows: row i of EA is (row i of E) times A. That is a combination of the rows of A.

  • Row 1 of E₂₁ is (1, 0, 0): keep row 1 as it is.
  • Row 2 is (−ℓ, 1, 0): row 2 minus ℓ times row 1.
  • Row 3 is (0, 0, 1): keep row 3.

Worked example

With ℓ = 2, E₂₁ times A:
new row 2 = (4, −6, 0) − 2·(2, 1, 1) = (0, −8, −2)

Undoing a card

To undo "subtract 2 of row 1", add 2 of row 1 back. So E₂₁⁻¹ is the identity with +ℓ in the same spot. Hold on to that: it is the key to A = LU on the next slide.

Worked examples

Example 1 · A 2 by 2 step

A = 3164. The multiplier is ℓ = 6 ÷ 3 = 2.

E₂₁ = 10−21    E₂₁A = 3102

Example 2 · The third step, E₃₂

After the first two steps, B = 2110−8−2083. Clear the 8 with ℓ₃₂ = 8 ÷ (−8) = −1.

E₃₂ = 100010011   (−ℓ₃₂ = +1 in row 3, column 2)
E₃₂B = 2110−8−2001 = U

Example 3 · Undoing a step

E₂₁ = 100−210001 subtracts 2·row 1 from row 2.

E₂₁⁻¹ = 100210001 adds it back
E₂₁⁻¹E₂₁ = I

Only the sign of the multiplier changes.

Worked examples

Example 1 · A 2 by 2 system

Solve 2x + 3y = 8 and 4x + 11y = 26.

Pivot 2, multiplier ℓ = 4 ÷ 2 = 2. Equation 2 − 2·(equation 1): 5y = 10
Back substitution: y = 2, then 2x + 6 = 8, so x = 1
Check: 4·1 + 11·2 = 26 ✓

The pivots are 2 and 5. Their product, 10, is det A.

Example 2 · A 3 by 3 system

Solve x + y + z = 6, 2x + 3y + z = 11, x + 3y + 4z = 19.

ℓ₂₁ = 2: row 2 becomes (0, 1, −1 | −1).   ℓ₃₁ = 1: row 3 becomes (0, 2, 3 | 13)
ℓ₃₂ = 2: row 3 becomes (0, 0, 5 | 15)
z = 3  →  y − 3 = −1, y = 2  →  x + 2 + 3 = 6, x = 1

U = 11101−1005, pivots 1, 1, 5.

Example 3 · Factor once, solve with L and U

Factor A = 2168 and use it to solve Ax = (3, 19).

ℓ = 6 ÷ 2 = 3, so U = 2105 and L = 1031
Lc = b: c₁ = 3, then 3·3 + c₂ = 19, so c₂ = 10
Ux = c: 5x₂ = 10, x₂ = 2, then 2x₁ + 2 = 3, x₁ = 1/2
Check: 6·(1/2) + 8·2 = 19 ✓

Problems

1

Solve x − y = 1 and 3x + 2y = 13 by elimination. Name the pivots.

Show solutionHide solution

ℓ = 3. Equation 2 − 3·(equation 1): 5y = 10, so y = 2 and x = 3. Check: 9 + 4 = 13 ✓

Pivots: 1 and 5.

2

For A = 4265, find the multiplier ℓ₂₁, the second pivot and det A.

Show solutionHide solution

ℓ₂₁ = 6 ÷ 4 = 1.5. Second pivot: 5 − 1.5·2 = 2.

det A = 4·2 = 8, the product of the pivots. Check: 4·5 − 2·6 = 8 ✓

3

For which number a does 1a28 have no second pivot? Can a row exchange fix it?

Show solutionHide solution

The second pivot is 8 − 2a. It is 0 when a = 4.

No row exchange helps: the only row below is already used. The matrix is singular (column 2 = 4·column 1).

4

Write the elimination matrix E₂₁ for A = 210641023 and compute E₂₁A.

Show solutionHide solution

ℓ₂₁ = 6 ÷ 2 = 3, so E₂₁ = 100−310001.

E₂₁A = 210011023. Only row 2 changed: (6, 4, 1) − 3·(2, 1, 0) = (0, 1, 1).

5

Find L and U for A = 12310.

Show solutionHide solution

ℓ = 3, so U = 1204 and L = 1031.

Check: LU = 1236 + 4 = A ✓
