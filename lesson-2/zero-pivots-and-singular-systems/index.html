Strang §2.2 · Breakdown of elimination

A zero pivot: swap rows, or stop.

Elimination needs a nonzero number in every pivot position. When a zero appears there, one of two things is true: either a row exchange fixes it, or the system does not have exactly one solution.

zero pivot  →  swap with a lower row   |   nothing to swap  →  singular
Key ideas
  1. A zero in a pivot position stops elimination, because we cannot divide by it.
  2. Temporary failure: a row below has a nonzero entry in that column. Exchange the rows and continue.
  3. Permanent failure: no row can help. The matrix is singular: no solution or infinitely many.
  4. Singular means dependent columns and det A = 0, the squashed plane from lesson 1.

Think of a relay race

The runner for the second leg is missing. If someone else on the team can run that leg, you swap the order and the race goes on. That is a temporary problem, and the fix is a row exchange.

If nobody on the team can run it, the race is over. That is a permanent problem, and the matrix is called singular.

A temporary failure

0x + 2y = 4    3x − 2y = 5
The first pivot position holds 0, so we cannot form a multiplier. But the second equation has a 3 there. Exchange the two equations: 3x − 2y = 5 and 2y = 4. Now y = 2 and x = 3.

The equations are the same, only their order changed, so the solution is unaffected.

Two permanent failures

  • No solution. x − 2y = 1 and 2x − 4y = 11. Subtracting 2 times the first leaves 0 = 9, which is impossible. In the row picture the two lines are parallel and never meet.
  • Infinitely many solutions. x − 2y = 1 and 2x − 4y = 2. Subtracting leaves 0 = 0, which is always true. The second equation added no information, and every point on the line x − 2y = 1 is a solution.

In both cases the second pivot is 0 and there is no row below to exchange with. The left-hand side, x − 2y and 2x − 4y, is the same in both: its columns (1, 2) and (−2, −4) are dependent. That is lesson 1's squashed plane again, with det A = 0. The right-hand side only decides which of the two failures we get.

Small pivots are dangerous too

A computer stores numbers with about 16 significant digits. Dividing by a tiny pivot such as 0.0000001 makes the multipliers huge and magnifies rounding errors. So practical solvers, NumPy's included, exchange rows at every step to bring the entry that is largest in absolute value into the pivot position. This is called partial pivoting.

Worked examples

Example 1 · A swap fixes it

0x + y = 2 and x + y = 3.

The first pivot is 0. Swap the equations: x + y = 3, y = 2
y = 2, then x = 1

Example 2 · Infinitely many solutions

x + y = 2 and 2x + 2y = 4.

ℓ = 2: the second equation becomes 0 = 0
Only x + y = 2 is left. Choose y = t freely; then x = 2 − t

Every point (2 − t, t) is a solution: the whole line.

Example 3 · A zero pivot in the middle of a 3 by 3

A = 111112123.

ℓ₂₁ = 1: row 2 → (0, 0, 1).   ℓ₃₁ = 1: row 3 → (0, 1, 2)
The second pivot is 0, but row 3 has a 1 there. Swap rows 2 and 3
U = 111012001, pivots 1, 1, 1

A temporary breakdown: the matrix is invertible.

Worked examples

Example 1 · A 2 by 2 system

Solve 2x + 3y = 8 and 4x + 11y = 26.

Pivot 2, multiplier ℓ = 4 ÷ 2 = 2. Equation 2 − 2·(equation 1): 5y = 10
Back substitution: y = 2, then 2x + 6 = 8, so x = 1
Check: 4·1 + 11·2 = 26 ✓

The pivots are 2 and 5. Their product, 10, is det A.

Example 2 · A 3 by 3 system

Solve x + y + z = 6, 2x + 3y + z = 11, x + 3y + 4z = 19.

ℓ₂₁ = 2: row 2 becomes (0, 1, −1 | −1).   ℓ₃₁ = 1: row 3 becomes (0, 2, 3 | 13)
ℓ₃₂ = 2: row 3 becomes (0, 0, 5 | 15)
z = 3  →  y − 3 = −1, y = 2  →  x + 2 + 3 = 6, x = 1

U = 11101−1005, pivots 1, 1, 5.

Example 3 · Factor once, solve with L and U

Factor A = 2168 and use it to solve Ax = (3, 19).

ℓ = 6 ÷ 2 = 3, so U = 2105 and L = 1031
Lc = b: c₁ = 3, then 3·3 + c₂ = 19, so c₂ = 10
Ux = c: 5x₂ = 10, x₂ = 2, then 2x₁ + 2 = 3, x₁ = 1/2
Check: 6·(1/2) + 8·2 = 19 ✓

Problems

Solve x − y = 1 and 3x + 2y = 13 by elimination. Name the pivots.

Show solutionHide solution

ℓ = 3. Equation 2 − 3·(equation 1): 5y = 10, so y = 2 and x = 3. Check: 9 + 4 = 13 ✓

Pivots: 1 and 5.

2

For A = 4265, find the multiplier ℓ₂₁, the second pivot and det A.

Show solutionHide solution

ℓ₂₁ = 6 ÷ 4 = 1.5. Second pivot: 5 − 1.5·2 = 2.

det A = 4·2 = 8, the product of the pivots. Check: 4·5 − 2·6 = 8 ✓

3

For which number a does 1a28 have no second pivot? Can a row exchange fix it?

Show solutionHide solution

The second pivot is 8 − 2a. It is 0 when a = 4.

No row exchange helps: the only row below is already used. The matrix is singular (column 2 = 4·column 1).

4

Write the elimination matrix E₂₁ for A = 210641023 and compute E₂₁A.

Show solutionHide solution

ℓ₂₁ = 6 ÷ 2 = 3, so E₂₁ = 100−310001.

E₂₁A = 210011023. Only row 2 changed: (6, 4, 1) − 3·(2, 1, 0) = (0, 1, 1).

5

Find L and U for A = 12310.

Show solutionHide solution

ℓ = 3, so U = 1204 and L = 1031.

Check: LU = 1236 + 4 = A ✓
