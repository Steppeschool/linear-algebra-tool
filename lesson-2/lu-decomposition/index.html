Strang §2.6 · Elimination = factorization

A = LU: the triangle U and the receipt L.

Elimination turns A into an upper triangular matrix U. If we keep the multipliers, they form a lower triangular matrix L, and multiplying L times U gives A back. This factorization A = LU is how computers solve systems in practice.

A = LU    L = 100ℓ₂₁10ℓ₃₁ℓ₃₂1
Key ideas
  1. A = LU: L is lower triangular with 1s on its diagonal, U is upper triangular.
  2. The multipliers ℓᵢⱼ go straight into L, in the positions where they were used.
  3. To solve Ax = b: first solve Lc = b, then Ux = c. Both are fast triangular solves.
  4. Factor once, then reuse L and U for every new right-hand side b.

Think of meal prep

On Sunday you chop all the vegetables for the week. That takes time. Then every weekday dinner takes five minutes, because the slow part is already done.

Factoring A = LU is the Sunday work. Each new right-hand side b is a weekday dinner: two quick triangular solves.

Lc = b  (forward substitution, top to bottom)    then    Ux = c  (back substitution, bottom to top)

Where L comes from

Slide 4 wrote elimination as E₃₂E₃₁E₂₁A = U. To get A back, undo the steps in reverse order:

A = E₂₁⁻¹ E₃₁⁻¹ E₃₂⁻¹ U = LU

Each inverse is the identity with +ℓ where E had −ℓ. Multiplied together in this order, they do not interfere with each other, and each multiplier lands in its own position. So L needs no extra arithmetic: it is simply the record of every multiplier we used, like a receipt.

The example from slides 2 to 4

The multipliers were ℓ₂₁ = 2, ℓ₃₁ = −1, ℓ₃₂ = −1.
L = 100210−1−11   U = 2110−8−2001
Check row 3 of LU: −1·(2, 1, 1) − 1·(0, −8, −2) + 1·(0, 0, 1) = (−2, 7, 2), which is row 3 of A ✓

Why it saves time

For n unknowns, factoring costs about n³/3 multiplications. Each triangular solve after that costs about n². With n = 1000 that is roughly 330 million operations for the factoring, and then about a million for each new b.

So when the matrix stays the same and only the right side changes, as in a simulation stepping through time, we factor once and reuse L and U. In the lab, lu(A) returns both factors so you can check your own work.

Worked examples

Example 1 · Factor, then solve

A = 1238, b = (5, 19).

ℓ = 3: U = 1202, L = 1031
Lc = b: c₁ = 5, c₂ = 19 − 15 = 4
Ux = c: 2x₂ = 4, x₂ = 2; x₁ + 4 = 5, x₁ = 1

Example 2 · A 3 by 3 factorization

A = 111122123 (from slide 2).

L = 100110111   U = 111011001

Each multiplier was 1, so L has 1s everywhere below the diagonal.

Example 3 · A fractional multiplier

A = 4363.

ℓ = 6 ÷ 4 = 1.5: U = 430−1.5, L = 101.51
Check row 2 of LU: 1.5·(4, 3) + (0, −1.5) = (6, 3) ✓

Show solutionHide solution

Worked examples

Example 1 · A 2 by 2 system

Solve 2x + 3y = 8 and 4x + 11y = 26.

Pivot 2, multiplier ℓ = 4 ÷ 2 = 2. Equation 2 − 2·(equation 1): 5y = 10
Back substitution: y = 2, then 2x + 6 = 8, so x = 1
Check: 4·1 + 11·2 = 26 ✓

The pivots are 2 and 5. Their product, 10, is det A.

Example 2 · A 3 by 3 system

Solve x + y + z = 6, 2x + 3y + z = 11, x + 3y + 4z = 19.

ℓ₂₁ = 2: row 2 becomes (0, 1, −1 | −1).   ℓ₃₁ = 1: row 3 becomes (0, 2, 3 | 13)
ℓ₃₂ = 2: row 3 becomes (0, 0, 5 | 15)
z = 3  →  y − 3 = −1, y = 2  →  x + 2 + 3 = 6, x = 1

U = 11101−1005, pivots 1, 1, 5.

Example 3 · Factor once, solve with L and U

Factor A = 2168 and use it to solve Ax = (3, 19).

ℓ = 6 ÷ 2 = 3, so U = 2105 and L = 1031
Lc = b: c₁ = 3, then 3·3 + c₂ = 19, so c₂ = 10
Ux = c: 5x₂ = 10, x₂ = 2, then 2x₁ + 2 = 3, x₁ = 1/2
Check: 6·(1/2) + 8·2 = 19 ✓

For A = 4265, find the multiplier ℓ₂₁, the second pivot and det A.

ℓ₂₁ = 6 ÷ 4 = 1.5. Second pivot: 5 − 1.5·2 = 2.

det A = 4·2 = 8, the product of the pivots. Check: 4·5 − 2·6 = 8 ✓

3

For which number a does 1a28 have no second pivot? Can a row exchange fix it?

Show solutionHide solution

The second pivot is 8 − 2a. It is 0 when a = 4.

No row exchange helps: the only row below is already used. The matrix is singular (column 2 = 4·column 1).

4

Write the elimination matrix E₂₁ for A = 210641023 and compute E₂₁A.

E₂₁A = 210011023. Only row 2 changed: (6, 4, 1) − 3·(2, 1, 0) = (0, 1, 1).

5

ℓ = 3, so U = 1204 and L = 1031.

Check: LU = 1236 + 4 = A ✓
