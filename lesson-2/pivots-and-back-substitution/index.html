Strang §2.2 · Pivots

Pivots clear the columns. Back substitution climbs back up.

With three equations we eliminate one column at a time. The first pivot clears column 1, the second pivot clears column 2, and the system becomes a triangle. Then back substitution solves it from the bottom up.

2114−60−272  →  2110−8−2001
Key ideas
  1. Elimination works column by column, from left to right.
  2. Each multiplier uses the current pivot, after the earlier steps.
  3. The result is an upper triangular matrix U. Its diagonal entries are the pivots.
  4. Back substitution solves the last row first, then moves up one row at a time.

From two equations to three

Nothing new is needed for bigger systems. We just repeat the step from slide 1, carefully, in a fixed order. Take

A = 2114−60−272    with right side b = (5, −2, 9)

Column 1

The first pivot is 2, in the top left corner. Below it we must clear the 4 and the −2:

  • ℓ₂₁ = 4 ÷ 2 = 2. Subtract 2 times row 1 from row 2: (4, −6, 0) − 2·(2, 1, 1) = (0, −8, −2).
  • ℓ₃₁ = −2 ÷ 2 = −1. Subtract −1 times row 1 from row 3, which means adding row 1: (−2, 7, 2) + (2, 1, 1) = (0, 8, 3).

Column 2

Now the second row starts with 0, −8. The second pivot is −8, and we use it to clear the 8 below it. The multiplier is ℓ₃₂ = 8 ÷ (−8) = −1, so we add row 2 to row 3: (0, 8, 3) + (0, −8, −2) = (0, 0, 1).

Notice that ℓ₃₂ uses −8, the pivot as it stands now, not the −6 that was in that position at the start. This is the most common mistake in hand calculations.

The triangle

U = 2110−8−2001    pivots 2, −8, 1

U is upper triangular: every entry below the diagonal is zero. A pivot must not be zero, because we divide by it to get the multipliers. Slide 3 is about what happens when one is.

Back substitution: a chain of keys

Picture three locked boxes. The key to box 2 is inside box 3, and the key to box 1 is inside box 2. You have to open box 3 first. A triangular system works the same way: the last equation has only one unknown, its value unlocks the equation above, and so on to the top.

Do the same subtractions to b: b₂ becomes −2 − 2·5 = −12, and b₃ becomes 9 + 5 = 14, then 14 + (−12) = 2.
Row 3: z = 2  →  Row 2: −8y − 2·2 = −12, so y = 1  →  Row 1: 2x + 1 + 2 = 5, so x = 1

Always apply each step to b as well as to A. Changing only the left side would give a different system.

Worked examples

Example 1 · A full 3 by 3 solve

Solve x + y + z = 3, x + 2y + 2z = 5, x + 2y + 3z = 6.

ℓ₂₁ = 1: row 2 → (0, 1, 1 | 2).   ℓ₃₁ = 1: row 3 → (0, 1, 2 | 3)
ℓ₃₂ = 1: row 3 → (0, 0, 1 | 1)
z = 1  →  y + 1 = 2, y = 1  →  x + 1 + 1 = 3, x = 1

The pivots are 1, 1, 1.

Example 2 · Back substitution on its own

Solve Ux = c with U = 213012004 and c = (9, 4, 8).

Row 3: 4z = 8, so z = 2
Row 2: y + 2·2 = 4, so y = 0
Row 1: 2x + 0 + 3·2 = 9, so x = 1.5

Example 3 · The pivots give the determinant

For A = 2114−60−272, elimination gave the pivots 2, −8 and 1.

det A = 2 · (−8) · 1 = −16

Multiplying the pivots is how computers find determinants. Strang's chapter 5 (determinants) explains why it works (no row exchanges here).

Worked examples

Example 1 · A 2 by 2 system

Solve 2x + 3y = 8 and 4x + 11y = 26.

Pivot 2, multiplier ℓ = 4 ÷ 2 = 2. Equation 2 − 2·(equation 1): 5y = 10
Back substitution: y = 2, then 2x + 6 = 8, so x = 1
Check: 4·1 + 11·2 = 26 ✓

The pivots are 2 and 5. Their product, 10, is det A.

Example 2 · A 3 by 3 system

Solve x + y + z = 6, 2x + 3y + z = 11, x + 3y + 4z = 19.

ℓ₂₁ = 2: row 2 becomes (0, 1, −1 | −1).   ℓ₃₁ = 1: row 3 becomes (0, 2, 3 | 13)
ℓ₃₂ = 2: row 3 becomes (0, 0, 5 | 15)
z = 3  →  y − 3 = −1, y = 2  →  x + 2 + 3 = 6, x = 1

U = 11101−1005, pivots 1, 1, 5.

Example 3 · Factor once, solve with L and U

Factor A = 2168 and use it to solve Ax = (3, 19).

ℓ = 6 ÷ 2 = 3, so U = 2105 and L = 1031
Lc = b: c₁ = 3, then 3·3 + c₂ = 19, so c₂ = 10
Ux = c: 5x₂ = 10, x₂ = 2, then 2x₁ + 2 = 3, x₁ = 1/2
Check: 6·(1/2) + 8·2 = 19 ✓

Problems

1

Solve x − y = 1 and 3x + 2y = 13 by elimination. Name the pivots.

Show solutionHide solution

ℓ = 3. Equation 2 − 3·(equation 1): 5y = 10, so y = 2 and x = 3. Check: 9 + 4 = 13 ✓

Pivots: 1 and 5.

2

For A = 4265, find the multiplier ℓ₂₁, the second pivot and det A.

Show solutionHide solution

ℓ₂₁ = 6 ÷ 4 = 1.5. Second pivot: 5 − 1.5·2 = 2.

det A = 4·2 = 8, the product of the pivots. Check: 4·5 − 2·6 = 8 ✓

3

For which number a does 1a28 have no second pivot? Can a row exchange fix it?

Show solutionHide solution

The second pivot is 8 − 2a. It is 0 when a = 4.

No row exchange helps: the only row below is already used. The matrix is singular (column 2 = 4·column 1).

4

Write the elimination matrix E₂₁ for A = 210641023 and compute E₂₁A.

Show solutionHide solution

ℓ₂₁ = 6 ÷ 2 = 3, so E₂₁ = 100−310001.

E₂₁A = 210011023. Only row 2 changed: (6, 4, 1) − 3·(2, 1, 0) = (0, 1, 1).

5

Find L and U for A = 12310.

Show solutionHide solution

ℓ = 3, so U = 1204 and L = 1031.

Check: LU = 1236 + 4 = A ✓
