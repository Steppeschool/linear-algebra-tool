Strang §5.1 · The properties of the determinant

The three rules that define the determinant

Slide 3 measured det A as an area, and for 2 by 2 the formula ad − bc did the work. For 3 by 3 and bigger, we start from three rules instead. Think of a board game: learn three rules, and every move in the game follows from them. Rule 1: the identity I moves nothing, so det I = 1. Rule 2: swapping two rows flips the sign, like turning a page face down. Rule 3: the determinant is linear in each row: make one row twice as long and the volume doubles, just as a box with one side doubled holds twice as much. (Slide 3 built the box from the columns; rows work too, because slide 5 shows det Aᵀ = det A.) Everything else follows from these three, including the most useful fact of all: elimination steps never change det.

Lesson 6 · slide 4Three rules
det I = 1    row swap: det changes sign    linear in each row
Key ideas
  1. Rule 1: det I = 1. The identity does not change any volume.
  2. Rule 2: swapping two rows changes the sign of det.
  3. Rule 3: det is linear in each row on its own: scale a single row by t and det scales by t, and a row that is a sum splits det into a sum.
  4. Consequences: two equal rows give det = 0; adding a multiple of one row to another row does not change det.

Rule 1: det I = 1

The identity leaves every vector where it is, so the unit square (or cube) keeps area 1.

det 1001 = 1·1 − 0·0 = 1

Rule 2: a row swap flips the sign

Swap the two rows of a matrix and its determinant changes sign. The size of the area stays, but the plane is turned over.

det 3112 = 6 − 1 = 5    swap the rows:   det 1231 = 1 − 6 = −5
Swap the rows of I:   det 0110 = 0 − 1 = −1, the mirror across y = x

Rule 3: linear in each row, one row at a time

Two parts. First, multiply one row by t and det is multiplied by t:

det 1234 = 4 − 6 = −2    row 1 times 5:   det 51034 = 20 − 30 = −10 = 5 × (−2) ✓

Second, if one row is a sum, det splits into two determinants, one for each part. The other rows stay the same:

det 1 + 22 + 034 = det 1234 + det 2034
left: det 3234 = 12 − 6 = 6    right: −2 + 8 = 6 ✓

Careful: one row at a time. Doubling the whole n by n matrix doubles all n rows, so det is multiplied by 2ⁿ. And det(A + B) is usually not det A + det B. With A = B = I (2 by 2): det(2I) = 2·2 = 4, but det A + det B = 1 + 1 = 2.

What follows from the rules

Two equal rows give det = 0. Swapping them changes nothing, but rule 2 says the sign flips. So det = −det, and that means det = 0.

det 1212 = 2 − 2 = 0 ✓

Subtracting ℓ times row j from row i leaves det unchanged (ℓ is the multiplier from lesson 2). The new row i is (row i) − ℓ(row j). By rule 3, det splits into det A − ℓ × det(A with row i replaced by row j). That second matrix has row j twice, so its det is 0. What is left is det A.

1234 → row 2 − 3·row 1 → 120−2   det = 1·(−2) − 2·0 = −2, the same ✓

This is the big one: elimination steps (lesson 2) don't change det. As a move of the plane, an elimination matrix is a shear. It slants the box without changing its size, like pushing a deck of cards sideways.

A row of zeros gives det = 0. Multiply that row by 0: nothing changes, but rule 3 says det is multiplied by 0.

A worked check: one step, then a swap

Here is a 3 by 3 matrix whose determinant is 2. (Slides 5 and 6 show two ways to get that number; take it on trust for now.) One elimination step, then one row swap:

A = 120251013   det A = 2
row 2 − 2·row 1 → B = 120011013   det B = 2 (an elimination step keeps det)
swap rows 2 and 3 → 120013011   det = −2 (a swap flips the sign)
