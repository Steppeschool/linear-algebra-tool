Strang §1.3 · Matrices

Ax is a combination of the columns of A.

Put the vectors v and w side by side as the columns of a matrix A, and put the numbers c and d into a vector x. Then the product Ax is exactly the combination cv + dw.

a₁₁a₁₂a₂₁a₂₂ x₁x₂ = x₁ a₁₁a₂₁ + x₂ a₁₂a₂₂
Key ideas
  1. A matrix is a block of numbers. Its columns are vectors.
  2. Ax is a combination of the columns of A, with the entries of x as the weights.
  3. Each entry of Ax can also be computed as a dot product of a row of A with x. Both ways give the same numbers.
  4. The column way tells us what Ax means. The row way is how we usually calculate it by hand.

From combinations to matrices

On the last slide we wrote combinations like c(2, 1) + d(−1, 1). Writing out the vectors every time gets long. So we store them as the columns of a matrix, and store c and d in a vector x:

A = 2−111    x = (c, d)    Ax = c·(2, 1) + d·(−1, 1)

That is the definition we will use: Ax is x₁ times column 1, plus x₂ times column 2. If A had more columns, x would need more entries, one weight per column.

An everyday picture: a shopping basket

You buy eggs and rice. One egg gives about 6 g of protein and 1 g of carbohydrate. One bowl of rice gives about 4 g of protein and 45 g of carbohydrate. Put each food in a column:

A = 64145    x = (2 eggs, 1 bowl)

The total in your basket is 2·(6, 1) + 1·(4, 45) = (16, 47): 16 g of protein and 47 g of carbohydrate. That total is Ax. Adding up whole foods is the column way.

The row way gives the same answer

You could also add up one nutrient at a time. Protein: 6·2 + 4·1 = 16. Carbohydrate: 1·2 + 45·1 = 47. Each of these is a dot product of a row of A with x: multiply matching entries and add.

Both ways always agree, because they add the same products in a different order. When we calculate by hand, rows are usually quicker. When we want to understand what Ax can be, columns are the way to think. Strang returns to this point again and again, and so will we.

Watch the sizes

For Ax to make sense, x must have one entry for each column of A. The result has one entry for each row. A 2 by 3 matrix (2 rows, 3 columns) takes a vector with 3 entries and produces a vector with 2 entries.

Worked examples

Example 1 · Both ways

A = 3125, x = (1, 2).

By columns: 1·(3, 2) + 2·(1, 5) = (5, 12)
By rows: (3·1 + 1·2, 2·1 + 5·2) = (5, 12)

Example 2 · A wide matrix

A = 102311 has 3 columns, so x needs 3 entries. Take x = (2, 1, 1).

Ax = 2·(1, 3) + 1·(0, 1) + 1·(2, 1) = (4, 8)

Three columns in, a vector with 2 entries out: one per row of A.

Example 3 · Picking out a column

What is A times x = (1, 0)? And times (0, 1)?

A(1, 0) = 1·(column 1) + 0·(column 2) = column 1
A(0, 1) = column 2

So the columns of A are exactly what A does to (1, 0) and (0, 1). We use this again on slide 5.
