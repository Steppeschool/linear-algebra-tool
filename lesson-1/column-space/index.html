Strang §1.3 and §3.1 · Column space

The column space C(A) is every possible Ax.

Try every possible x and collect all the outputs Ax. That collection is the column space of A. Solving Ax = b comes down to one question: is b in it?

C(A) = all vectors Ax = all combinations of the columns
Key ideas
  1. The column space C(A) contains every combination of the columns of A, that is, every vector Ax.
  2. Ax = b has a solution exactly when b is in C(A).
  3. In the plane, C(A) is the whole plane, a line through the origin, or just the origin.
  4. The rank is the number of independent directions in C(A): 2, 1 or 0.

All the outputs at once

So far we computed one product Ax at a time. Now let x vary over every possible vector and mark each output Ax on the plane. The set of all those points is the column space, written C(A).

Because every Ax is a combination of the columns, C(A) is simply "all combinations of the columns". That is where the name comes from.

An engineering picture: a boat with two thrusters

A small boat has two thrusters. Column 1 of A is the push from thruster 1 at full power, and column 2 is the push from thruster 2. The entries of x are the two throttle settings, and a negative setting means reverse. Then Ax is the total push on the boat.

  • If the thrusters point in different directions, mixing them can push the boat any way you like. C(A) is the whole plane.
  • If both thrusters point forward, the boat can only go forward or backward. C(A) is a line, and a sideways target is out of reach no matter how you set the throttles.

Three possibilities in the plane

For a 2 by 2 matrix there are only three cases:

  • The whole plane: the two columns point in different directions. We call them independent.
  • A line: one column is a multiple of the other. We call them dependent.
  • Just the origin: both columns are zero.

The rank counts the independent directions that survive: 2, 1 or 0.

A closer look at the dependent case

A = 1224. Column 2 is 2 times column 1.
Ax = x₁(1, 2) + x₂(2, 4) = (x₁ + 2x₂)·(1, 2)
Every output is a multiple of (1, 2). So b = (3, 6) is reachable, but b = (1, 0) is not.

Notice something else: x = (3, 0) and x = (1, 1) both give (3, 6). With dependent columns, different inputs can produce the same output. That extra freedom gets its own name in chapter 3: the nullspace.

Two questions that sound alike

  • Can we solve Ax = b for this particular b? Yes, if b is in C(A).
  • Can we solve Ax = b for every b? Only if C(A) is the whole plane.

For 2 by 2 matrices there is a quick test. The columns are independent exactly when ad − bc ≠ 0. When ad − bc = 0, the matrix squashes the plane onto a line, and no matrix can undo that squash. We will meet this number again as the determinant.

Worked examples

Example 1 · A line, and who is on it

A = 2412. Column 2 = 2·column 1, so C(A) is the line through (2, 1).

b = (6, 3) = 3·(2, 1): in C(A), for example x = (3, 0)
b = (1, 1): not a multiple of (2, 1), so Ax = b has no solution

Example 2 · The whole plane

A = 111−1. det A = −1 − 1 = −2 ≠ 0, so C(A) is the whole plane. Solve Ax = (4, 2):

x₁ + x₂ = 4    x₁ − x₂ = 2
x₁ = 3, x₂ = 1

Example 3 · Is b in the column space?

A = 1326, b = (2, 5).

Column 2 = 3·column 1, so C(A) is the line of multiples of (1, 2)
Is (2, 5) a multiple of (1, 2)? It would need 2·(1, 2) = (2, 4), not (2, 5)

So b is not in C(A), and Ax = b has no solution. Changing b to (2, 4) would make it solvable.
