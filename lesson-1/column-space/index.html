Strang §1.3 and §3.1 · Column space

The column space C(A) is every possible Ax.

A matrix can only produce certain outputs. The column space is the list of everything Ax can produce. Solving Ax = b means asking one question: is b on that list?

C(A) = all vectors Ax = all combinations of the columns

Think: reachable outputs

The columns are the directions you are allowed to move in. The vector x says how far to go along each one. Ax is where you end up.

Try every possible x and mark every place you land. That set of landing spots is C(A).

An engineering picture

A small boat has two thrusters. Column 1 is the push you get from thruster 1 at full throttle. Column 2 is the push from thruster 2. The entries of x are the two throttle settings, and a negative throttle means reverse.

  • Thrusters at an angle: by mixing them you can push the boat in any direction. C(A) is the whole plane.
  • Both thrusters pointing forward: you can only go forward or back. C(A) is a line. A sideways target is out of reach, whatever the throttles.

Three possibilities in the plane

  • The whole plane: the columns point in different directions. They are independent.
  • A line: one column is a multiple of the other. They are dependent.
  • Just the origin: A is all zeros.

The rank counts how many dimensions survive: 2, 1 or 0. It is also the number of independent columns.

Worked example

A = 1224. Column 2 is 2 times column 1.
Ax = x₁(1, 2) + x₂(2, 4) = (x₁ + 2x₂)·(1, 2)
Every output is a multiple of (1, 2). So b = (3, 6) is reachable, and b = (1, 0) never is.
Notice that x = (3, 0) and x = (1, 1) both give (3, 6). With dependent columns, different inputs can land on the same output. Chapter 3 calls the leftover freedom the nullspace.

Two questions that look alike

  • Can I solve Ax = b for this b? Only if b is in C(A).
  • Can I solve Ax = b for every b? Only if C(A) is the whole plane.

For 2 by 2 there is a quick test. The columns are independent exactly when ad − bc ≠ 0. When it is 0, the plane gets squashed onto a line. A squash cannot be undone, so A has no inverse.
