Strang §1.1 · Linear combinations

Linear algebra starts with cv + dw.

Everything in this course grows out of one operation. Take two vectors, multiply each one by a number, and add the results. The answer is called a linear combination.

c 21 + d -11 = 2c − dc + d
Key ideas
  1. A vector in the plane is a pair of numbers, v = (v₁, v₂). We draw it as an arrow from the origin.
  2. Two operations: multiply a vector by a number c, and add two vectors. Both work one component at a time.
  3. Doing both gives a linear combination cv + dw.
  4. The big question: which vectors can we reach with all possible c and d?

Why vectors at all?

Suppose a sensor reports two numbers: 2 metres east and 1 metre north. Those numbers belong together, and it makes no sense to add the east value to the north value. So we keep them as a pair and give the pair one name: v = (2, 1). That is a vector.

When we add two vectors, the first components go together and the second components go together. They never mix:

v = (2, 1),   w = (−1, 1)  →  v + w = (2 + (−1), 1 + 1) = (1, 2)

On the plane, adding means walking: go along v, then from its tip go along w. You arrive at the tip of v + w.

Multiplying by a number

To get 3v, multiply each component by 3: 3v = (6, 3). The arrow points the same way and is three times as long. The number 3 is called a scalar, because it only scales the vector.

A negative scalar turns the arrow around: −v = (−2, −1). And 0·v is the zero vector (0, 0), the arrow of length zero at the origin.

Putting both together

Now combine the two operations. Choose numbers c and d and form cv + dw. With c = 3 and d = 2:

3v + 2w = (6, 3) + (−2, 2) = (4, 5)

That is a linear combination. Think of it as giving directions with only two kinds of step: "take 3 steps of v, then 2 steps of w". Every such instruction lands you somewhere.

The question behind everything

Here is the question we keep asking for the rest of the course: which vectors can we reach?

For one vector, the multiples cv fill a line through the origin. That is where the word "linear" comes from. For two vectors that point in different directions, like v and w here, the combinations cv + dw fill the whole plane. Every point is reachable.

Going the other way is harder. Given a target like (4, 5), how do we find c and d? We need 2c − d = 4 and c + d = 5, two equations at once. Solving that kind of system is what slide 4 and lesson 2 are about.

Worked examples

Example 1 · Compute a combination

v = (1, 1), w = (1, −1), c = 2, d = 3. Find cv + dw.

2v = (2, 2)    3w = (3, −3)
2v + 3w = (2 + 3, 2 − 3) = (5, −1)

Example 2 · Find the numbers

Write (3, 0) as c·(1, 1) + d·(1, −1).

c + d = 3    c − d = 0
Adding: 2c = 3, so c = 1.5 and d = 1.5
Check: 1.5·(1, 1) + 1.5·(1, −1) = (3, 0) ✓

Example 3 · When the plane is not filled

Take v = (1, 2) and w = (2, 4). Notice that w = 2v: both arrows lie on the same line.

cv + dw = c(1, 2) + 2d(1, 2) = (c + 2d)·(1, 2)

Every combination is a multiple of (1, 2), so the combinations only fill a line, not the plane. The target (1, 0) can never be reached.

No. (−1, −2) = −½·(2, 4), so both vectors lie on the line y = 2x. Every combination stays on that line, and (1, 0) is not on it.
