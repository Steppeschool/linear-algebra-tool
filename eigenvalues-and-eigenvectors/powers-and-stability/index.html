Strang §6.2 · Powers, stability and Markov matrices

Repeat A many times: the eigenvalues decide what survives.

Many systems update by the same matrix every step: uₖ₊₁ = Auₖ. Write the start as a mix of eigenvectors, and each part gets multiplied by its λ at every step. Parts with |λ| < 1 die out, |λ| > 1 grows, and λ = 1 survives unchanged.

Lesson 7 · slide 4Stability
uₖ = c₁λ₁ᵏx₁ + c₂λ₂ᵏx₂    stable ⇔ every |λ| < 1
Key ideas
  1. Split u₀ = c₁x₁ + c₂x₂ into eigenvectors. Then uₖ = Aᵏu₀ = c₁λ₁ᵏx₁ + c₂λ₂ᵏx₂.
  2. |λ| < 1: that part shrinks to 0. |λ| > 1: it grows. λ = 1: it stays.
  3. A Markov matrix has nonnegative entries and columns adding to 1. It always has λ = 1.
  4. Its eigenvector for λ = 1, scaled to add to 1, is the steady state the system settles into.

Two cities, people moving every year

Each year 10% of the people in city 1 move to city 2, and 20% of city 2 moves to city 1. Everyone else stays. Track the fractions u = (city 1, city 2). Write uₖ for the fractions after k years:

uₖ₊₁ = A uₖ,   A = 0.90.20.10.8
Column 1: of city 1's people, 0.9 stay and 0.1 leave. Column 2: of city 2's, 0.2 leave and 0.8 stay. Each column adds to 1: nobody is lost

Start with everyone in city 2, u₀ = (0, 1). Then u₁ = (0.2, 0.8), u₂ = (0.34, 0.66), u₃ ≈ (0.44, 0.56) … The fractions creep towards a fixed split. Why, and which split?

The eigenvalues explain it

trace = 1.7,   det = 0.72 − 0.02 = 0.7,   so λ² − 1.7λ + 0.7 = (λ − 1)(λ − 0.7) = 0
λ = 1:   A − I = −0.10.20.1−0.2 gives x₁ = (2, 1)
λ = 0.7:   A − 0.7I = 0.20.20.10.1 gives x₂ = (1, −1)

Split the start into these two directions: (0, 1) = ⅓·(2, 1) − ⅔·(1, −1). (Solve 2c₁ + c₂ = 0 and c₁ − c₂ = 1 for the two amounts.) At every step the x₁ part is multiplied by 1, so it stays. The x₂ part is multiplied by 0.7, so after k years it has shrunk by 0.7ᵏ: after 20 years less than 0.1% is left. What survives is the x₁ direction. Scaled so the fractions add to 1, that is the steady state s = (2/3, 1/3).

Check: As = (0.9·⅔ + 0.2·⅓, 0.1·⅔ + 0.8·⅓) = (⅔, ⅓) ✓. Two thirds end up in city 1, wherever everyone started.

Stability

The same reasoning answers a central engineering question. A system updated by uₖ₊₁ = Auₖ is stable (every disturbance dies out) exactly when every eigenvalue has |λ| < 1. One eigenvalue with |λ| > 1 and some disturbance grows without limit.

A preview, not needed now: for systems that change smoothly in time (du/dt = Au), each part behaves like e^(λt). There the rule is that every λ must be negative (Strang §6.3).

Where this is used

A drone's position filter (a Kalman filter) combines GPS and motion-sensor readings and updates its error by a matrix every step. Designers check that the eigenvalues of that error matrix stay inside |λ| < 1, so errors shrink instead of piling up. Web search ranking (PageRank) is the steady state of a giant Markov matrix.

Worked examples

Example 1 · Growth and decay

A = 2000.5, u₀ = (1, 1).

u₁₀ = (2¹⁰, 0.5¹⁰) = (1024, 0.001)
The first part explodes, the second vanishes: unstable

Example 2 · A stable system

A = 0.50.20.20.5: λ = 0.7 with (1, 1) and λ = 0.3 with (1, −1).

Both |λ| < 1: every start shrinks to 0
After 10 steps the (1, 1) part is 0.7¹⁰ ≈ 0.03 of its size

Example 3 · Steady state of another Markov matrix

A = 0.80.30.20.7: columns add to 1.

A − I = −0.20.30.2−0.3: row 1 says −0.2a + 0.3b = 0, so x = (3, 2)
Scaled to add to 1: s = (0.6, 0.4)

1

Find the steady state of 0.70.40.30.6.

Show solutionHide solution

A − I has row 1 (−0.3, 0.4): −0.3a + 0.4b = 0, so x = (4, 3). Scaled: s = (4/7, 3/7) ≈ (0.571, 0.429).

2

A has eigenvalues 0.9 and 1.1. Is uₖ₊₁ = Auₖ stable? Explain.

Show solutionHide solution

No. The part along the eigenvector with λ = 1.1 grows like 1.1ᵏ. Unless the start has no part in that direction, uₖ blows up.

3

Why does every Markov matrix have λ = 1?

Show solutionHide solution

Each column of A adds to 1, so each column of A − I adds to 0. Then the rows of A − I add up to the zero row, so the rows are dependent and A − I is singular. That means det(A − I) = 0: λ = 1 is an eigenvalue.

Worked examples

Example 1 · Eigenvalues of a triangular 3 by 3

A = 120030005.

Triangular: det(A − λI) = (1 − λ)(3 − λ)(5 − λ), so λ = 1, 3, 5
λ = 3: A − 3I = −220000002 gives x = (1, 1, 0)
λ = 1: x = (1, 0, 0).   λ = 5: x = (0, 0, 1)

Example 2 · A power by eigenvectors

A = 2112, u₀ = (3, 1). Find A⁵u₀.

Split: (3, 1) = 2·(1, 1) + 1·(1, −1)
A⁵u₀ = 2·3⁵(1, 1) + 1·1⁵(1, −1) = 486(1, 1) + (1, −1) = (487, 485)

Example 3 · A steady state

A = 0.60.40.40.6: columns add to 1.

λ = 1 with (1, 1),   λ = 0.2 with (1, −1)
Steady state (½, ½): both cities lose the same share each step, so they end up equal

Problems

1

Find the eigenvalues and eigenvectors of 3103. Can it be diagonalized?

Show solutionHide solution

λ = 3 twice. A − 3I = [0 1; 0 0] has null space only along (1, 0). One eigenvector line, so no: not diagonalizable.

2

Find the eigenvalues of 01-2-3. Is du/dt = Au stable?

Show solutionHide solution

Trace −3, det 2: λ² + 3λ + 2 = (λ + 1)(λ + 2), so λ = −1, −2. Both negative: every solution decays like e^(−t) and e^(−2t). Stable.

3

The Fibonacci rule F_(k+2) = F_(k+1) + F_k is u_(k+1) = Au_k with u_k = (F_(k+1), F_k) and A = 1110. Find its eigenvalues.

Show solutionHide solution

λ² − λ − 1 = 0, so λ = (1 ± √5)/2 ≈ 1.618 and −0.618. The first grows; it is the golden ratio, and F_(k+1)/F_k approaches it.

4

Diagonalize A = 2112 with Q orthogonal.

Show solutionHide solution

λ = 3 with (1, 1)/√2 and λ = 1 with (1, −1)/√2. Q = (1/√2)[1 1; 1 −1], Λ = diag(3, 1), A = QΛQᵀ.

5

Is 2-10-12-10-12 positive definite?

Show solutionHide solution

Yes. Pivots 2, 3/2, 4/3 are all positive (lesson 6). The eigenvalues are 2 − √2, 2, 2 + √2, all positive.
