Strang §6.5 · Positive definite matrices

Positive definite matrices: every eigenvalue positive

Slide 5 showed that a symmetric matrix stretches along perpendicular axes, each by its own eigenvalue. Now ask for the nicest case: every one of those stretches is positive, so no axis is flipped. Such a matrix is called positive definite. Think of a marble. In a bowl it rolls to the one lowest point, wherever you drop it. On a horse saddle it rolls off, because one direction goes up and another goes down. For a symmetric A, the height over the point x is the number xᵀAx. Positive definite matrices give bowls: xᵀAx > 0 for every x except 0. One negative eigenvalue gives a saddle.

Lesson 7 · slide 6Positive definite
A positive definite ⇔ all λ > 0 ⇔ xᵀAx > 0 for all x ≠ 0
Key ideas
  1. A symmetric A is positive definite when all its eigenvalues are positive.
  2. Equivalent test: the energy xᵀAx > 0 for every nonzero x.
  3. For 2 by 2 abbc: a > 0 and ac − b² > 0. (Also: all pivots positive.)
  4. The graph of xᵀAx is a bowl. One negative eigenvalue turns it into a saddle.

The number xᵀAx

xᵀAx is the dot product of x with Ax: one number for every x, often called the energy. The name comes from springs: for the row of springs in the bigger example below, ½xᵀAx is the energy stored when the masses are moved by x. For A = abbc and x = x₁x₂:

xᵀAx = a x₁² + 2b x₁x₂ + c x₂²
A = 2112:   2x₁² + 2x₁x₂ + 2x₂² = x₁² + x₂² + (x₁ + x₂)²
At x = 10: 2.   At x = 1−1: 2 − 2 + 2 = 2.   At x = 11: 2 + 2 + 2 = 6

It is a sum of squares, so it is positive unless x = 0. Plotted as a height over the plane, it is a bowl with its lowest point at the origin. Since xᵀAx = x · Ax, being positive also means Ax never points more than 90° away from x (lesson 1: a positive dot product means an angle under 90°).

The eigenvalue test

Write x in the perpendicular unit eigenvectors from slide 5: x = c₁q₁ + c₂q₂. Then Ax = λ₁c₁q₁ + λ₂c₂q₂. Multiply out the dot product of the two, using q₁ · q₁ = q₂ · q₂ = 1 and q₁ · q₂ = 0:

xᵀAx = (c₁q₁ + c₂q₂) · (λ₁c₁q₁ + λ₂c₂q₂)
= λ₁c₁²(q₁ · q₁) + λ₂c₁c₂(q₁ · q₂) + λ₁c₂c₁(q₂ · q₁) + λ₂c₂²(q₂ · q₂)
= λ₁c₁² + 0 + 0 + λ₂c₂² = λ₁c₁² + λ₂c₂²

Both λ positive: this is positive for every nonzero x. A bowl. One λ negative: move along its eigenvector and xᵀAx goes negative. A saddle. Both λ negative: xᵀAx is negative for every nonzero x, an upside-down bowl (a hilltop).

A = 2112: λ = 3 and 1, both positive. Bowl
A = 2332: λ = 5 and −1. Saddle: x = 1−1 gives xᵀAx = 2 − 6 + 2 = −2

Quick tests for 2 by 2

abbc is positive definite exactly when a > 0 and ac − b² > 0. The determinant ac − b² equals λ₁λ₂ (slide 2), so a negative determinant means one λ is negative: a saddle. A positive determinant means both λ have the same sign. Why also a > 0? Because a is xᵀAx at x = 10, so a > 0 rules out both λ being negative (the upside-down bowl). For 2bb2, that happens when b² > 4.

4223:   a = 4 > 0,   ac − b² = 12 − 4 = 8 > 0.   Positive definite
1331:   ac − b² = 1 − 9 = −8 < 0.   Saddle

The pivot test

Elimination gives the same answer: A is positive definite exactly when all its pivots (lesson 2) are positive. For a 2 by 2 matrix the pivots are a and (ac − b²)/a, so this is the same test as above:

2112  →  row 2 − ½·row 1  →  2101.5:   pivots 2 and 1.5, both positive ✓

Pivots are the cheap test for big matrices: one pass of elimination, no eigenvalues needed.
