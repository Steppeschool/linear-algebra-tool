Strang §6.1 · The characteristic equation

Finding eigenvalues: make A − λI singular.

Rewrite Ax = λx as (A − λI)x = 0. A nonzero x can solve that only if A − λI is singular, so its determinant must be zero. That gives an equation for λ alone. Solve it first, then find each eigenvector from a null space.

Lesson 7 · slide 2det(A − λI) = 0
det(A − λI) = 0    λ₁ + λ₂ = trace A (sum of the diagonal)    λ₁ · λ₂ = det A
Key ideas
  1. Ax = λx is the same as (A − λI)x = 0.
  2. A nonzero solution x exists only when A − λI is singular: det(A − λI) = 0. This is the characteristic equation.
  3. For 2 by 2 it is λ² − (trace)λ + det = 0, where the trace is the sum of the diagonal entries.
  4. For each λ, the eigenvectors are the nonzero vectors in the null space of A − λI.

Tuning until something gives

Picture turning a dial labelled λ. For most settings, A − λI is an ordinary invertible matrix: only x = 0 is sent to zero. At a few special settings the matrix suddenly becomes singular and a whole line of vectors is sent to zero. Those settings are the eigenvalues.

From Ax = λx to an equation for λ

Ax = λx
Ax − λx = 0
(A − λI)x = 0   (we write λI so that we subtract a matrix from a matrix)

If A − λI were invertible, the only solution would be x = 0. We want a nonzero x, so A − λI must be singular. Lesson 6 gives the test: its determinant is zero.

A worked example

A = 4123,   A − λI = 4 − λ123 − λ
det = (4 − λ)(3 − λ) − 2 = λ² − 7λ + 10
λ² − 7λ + 10 = (λ − 5)(λ − 2) = 0,   so λ = 5 or λ = 2

Then the eigenvectors

λ = 5:   A − 5I = −112−2.   Row 2 is a multiple of row 1 (A − 5I is singular), so one row is enough. For x = (a, b), row 1 says −a + b = 0, so x = (1, 1)
λ = 2:   A − 2I = 2121.   Row 1 says 2a + b = 0, so x = (1, −2)
Check: A(1, −2) = (4 − 2, 2 − 6) = (2, −4) = 2·(1, −2) ✓

Two quick checks

For any 2 by 2 matrix A = [a b; c d] the characteristic equation is λ² − (a + d)λ + (ad − bc) = 0. So the two eigenvalues always add up to the trace a + d, and multiply to the determinant. Here 5 + 2 = 7 = 4 + 3 and 5 · 2 = 10 = 12 − 2 ✓. Use these to catch mistakes.

Where this is used

Engineers check stability by finding eigenvalues. A control loop, a bridge or a filter has a matrix; its eigenvalues say whether disturbances die away or grow. Slide 4 shows how.

Worked examples

Example 1 · A triangular matrix

A = 1203.

det(A − λI) = (1 − λ)(3 − λ) − 0
λ = 1 and λ = 3: the diagonal entries

For triangular matrices the eigenvalues sit on the diagonal.

Example 2 · A symmetric matrix

A = 2332: trace 4, det 4 − 9 = −5.

λ² − 4λ − 5 = (λ − 5)(λ + 1) = 0
λ = 5 with x = (1, 1),   λ = −1 with x = (1, −1)

Example 3 · A singular matrix

A = 1224: det A = 0.

λ² − 5λ + 0 = λ(λ − 5) = 0
λ = 0: the null space direction (−2, 1) is squashed to zero
λ = 5: the direction (1, 2)

λ = 0 is an eigenvalue exactly when A is singular.

Worked examples

Example 1 · Eigenvalues of a triangular 3 by 3

A = 120030005.

Triangular: det(A − λI) = (1 − λ)(3 − λ)(5 − λ), so λ = 1, 3, 5
λ = 3: A − 3I = −220000002 gives x = (1, 1, 0)
λ = 1: x = (1, 0, 0).   λ = 5: x = (0, 0, 1)

Example 2 · A power by eigenvectors

A = 2112, u₀ = (3, 1). Find A⁵u₀.

Split: (3, 1) = 2·(1, 1) + 1·(1, −1)
A⁵u₀ = 2·3⁵(1, 1) + 1·1⁵(1, −1) = 486(1, 1) + (1, −1) = (487, 485)

Example 3 · A steady state

A = 0.60.40.40.6: columns add to 1.

λ = 1 with (1, 1),   λ = 0.2 with (1, −1)
Steady state (½, ½): both cities lose the same share each step, so they end up equal

Problems

1

Find the eigenvalues and eigenvectors of 3103. Can it be diagonalized?

Show solutionHide solution

λ = 3 twice. A − 3I = [0 1; 0 0] has null space only along (1, 0). One eigenvector line, so no: not diagonalizable.

2

Find the eigenvalues of 01-2-3. Is du/dt = Au stable?

Show solutionHide solution

Trace −3, det 2: λ² + 3λ + 2 = (λ + 1)(λ + 2), so λ = −1, −2. Both negative: every solution decays like e^(−t) and e^(−2t). Stable.

3

The Fibonacci rule F_(k+2) = F_(k+1) + F_k is u_(k+1) = Au_k with u_k = (F_(k+1), F_k) and A = 1110. Find its eigenvalues.

Show solutionHide solution

λ² − λ − 1 = 0, so λ = (1 ± √5)/2 ≈ 1.618 and −0.618. The first grows; it is the golden ratio, and F_(k+1)/F_k approaches it.

4

Diagonalize A = 2112 with Q orthogonal.

Show solutionHide solution

λ = 3 with (1, 1)/√2 and λ = 1 with (1, −1)/√2. Q = (1/√2)[1 1; 1 −1], Λ = diag(3, 1), A = QΛQᵀ.

5

Is 2-10-12-10-12 positive definite?

Show solutionHide solution

Yes. Pivots 2, 3/2, 4/3 are all positive (lesson 6). The eigenvalues are 2 − √2, 2, 2 + √2, all positive.
