Strang §6.2 · Diagonalizing a matrix

Diagonalizing: A in its own best coordinates.

Put the eigenvectors of A into the columns of a matrix X and the eigenvalues on the diagonal of Λ. Then AX = XΛ, so A = XΛX⁻¹. In the coordinates of its eigenvectors, A is just a diagonal matrix: each direction is stretched on its own.

Lesson 7 · slide 3A = XΛX⁻¹
A = XΛX⁻¹    Aᵏ = XΛᵏX⁻¹
Key ideas
  1. X has the eigenvectors as columns; Λ (capital lambda) is diagonal with the eigenvalues, in the same order.
  2. AX = XΛ says Axᵢ = λᵢxᵢ for every column at once.
  3. If A is n by n and has n independent eigenvectors, X is invertible and A = XΛX⁻¹.
  4. Powers become easy: Aᵏ = XΛᵏX⁻¹, and Λᵏ just raises each diagonal entry to the power k.

Turning the map

A street map is easiest to read when it is turned so the main streets run straight up and across. The city did not change; you chose better axes. Diagonalizing does this for a matrix. In the right coordinates, its eigenvectors, a messy matrix becomes a diagonal one: each axis is stretched by its own eigenvalue and nothing mixes. (Unlike the streets on a map, these axes do not have to be at right angles.)

All eigenvectors at once

Put the eigenvectors x₁, x₂ in the columns of X. Multiply by A: column by column, A x₁ = λ₁x₁ and A x₂ = λ₂x₂. Those are the columns of X times the diagonal matrix Λ:

AX = A[x₁ x₂] = [λ₁x₁   λ₂x₂] = [x₁ x₂]λ₁00λ₂ = XΛ
Multiply on the right by X⁻¹:   A = XΛX⁻¹

The order must match: the eigenvalue in position i of Λ belongs to the eigenvector in column i of X.

A worked example

A = 4123 (slide 2):   λ = 5 with (1, 1),   λ = 2 with (1, −2)
X = 111−2,   Λ = 5002,   X⁻¹ = ⅓211−1
XΛ = 525−4,   so XΛX⁻¹ = XΛ · ⅓211−1 = ⅓12369 = 4123 ✓

Powers for free

A² = XΛX⁻¹XΛX⁻¹ = XΛ²X⁻¹, because X⁻¹X = I in the middle. In the same way Aᵏ = XΛᵏX⁻¹. And Λᵏ is easy: raise each diagonal entry to the power k. A¹⁰⁰ costs no more work than A².

When it fails

Some matrices do not have enough independent eigenvectors. A = 1101 has λ = 1 twice, but only the direction (1, 0). Then X would have two parallel columns, X⁻¹ does not exist, and A cannot be diagonalized. This can only happen when an eigenvalue repeats: different eigenvalues always give independent eigenvectors.

Where this is used

Signal processing, vibration analysis and control design all switch to eigenvector coordinates ("modes"). Each mode can then be studied on its own, as a simple number λ instead of a full matrix.

Worked examples

Example 1 · A diagonal matrix is already done

A = 3007: X = I and Λ = A. The axes are the eigenvectors.

Example 2 · A power

A = 2112 has λ = 3 with (1, 1) and λ = 1 with (1, −1).

A¹⁰(1, 1) = 3¹⁰(1, 1) = (59049, 59049)
A¹⁰(1, −1) = 1¹⁰(1, −1) = (1, −1)
A¹⁰(2, 0) = A¹⁰[(1, 1) + (1, −1)] = (59050, 59048)

Split the vector into eigenvectors, then each part just gets multiplied by its λᵏ.

Example 3 · Not diagonalizable

A = 2102: λ = 2 twice.

A − 2I = 0100 has null space only along (1, 0)
One eigenvector line, not two: no X⁻¹

2

A = XΛX⁻¹ with Λ = diag(2, ½). What happens to Aᵏ as k grows?

Show solutionHide solution

Λᵏ = diag(2ᵏ, (½)ᵏ). The first eigenvector direction grows without limit; the second dies out. Aᵏx lines up more and more with the first eigenvector.

3

If A = XΛX⁻¹, what is A⁻¹? When does it exist?

Show solutionHide solution

A⁻¹ = XΛ⁻¹X⁻¹, with Λ⁻¹ = diag(1/λ₁, 1/λ₂). It exists when no eigenvalue is 0.

Worked examples

Example 1 · Eigenvalues of a triangular 3 by 3

A = 120030005.

Triangular: det(A − λI) = (1 − λ)(3 − λ)(5 − λ), so λ = 1, 3, 5
λ = 3: A − 3I = −220000002 gives x = (1, 1, 0)
λ = 1: x = (1, 0, 0).   λ = 5: x = (0, 0, 1)

Example 2 · A power by eigenvectors

A = 2112, u₀ = (3, 1). Find A⁵u₀.

Split: (3, 1) = 2·(1, 1) + 1·(1, −1)
A⁵u₀ = 2·3⁵(1, 1) + 1·1⁵(1, −1) = 486(1, 1) + (1, −1) = (487, 485)

Example 3 · A steady state

A = 0.60.40.40.6: columns add to 1.

λ = 1 with (1, 1),   λ = 0.2 with (1, −1)
Steady state (½, ½): both cities lose the same share each step, so they end up equal

Problems

1

Find the eigenvalues and eigenvectors of 3103. Can it be diagonalized?

Show solutionHide solution

λ = 3 twice. A − 3I = [0 1; 0 0] has null space only along (1, 0). One eigenvector line, so no: not diagonalizable.

2

Find the eigenvalues of 01-2-3. Is du/dt = Au stable?

Show solutionHide solution

Trace −3, det 2: λ² + 3λ + 2 = (λ + 1)(λ + 2), so λ = −1, −2. Both negative: every solution decays like e^(−t) and e^(−2t). Stable.

3

The Fibonacci rule F_(k+2) = F_(k+1) + F_k is u_(k+1) = Au_k with u_k = (F_(k+1), F_k) and A = 1110. Find its eigenvalues.

Show solutionHide solution

λ² − λ − 1 = 0, so λ = (1 ± √5)/2 ≈ 1.618 and −0.618. The first grows; it is the golden ratio, and F_(k+1)/F_k approaches it.

4

Diagonalize A = 2112 with Q orthogonal.

Show solutionHide solution

λ = 3 with (1, 1)/√2 and λ = 1 with (1, −1)/√2. Q = (1/√2)[1 1; 1 −1], Λ = diag(3, 1), A = QΛQᵀ.

5

Is 2-10-12-10-12 positive definite?

Show solutionHide solution

Yes. Pivots 2, 3/2, 4/3 are all positive (lesson 6). The eigenvalues are 2 − √2, 2, 2 + √2, all positive.
