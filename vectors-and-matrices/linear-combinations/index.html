Strang §1.1 · Linear combinations

Linear algebra starts with cv + dw.

Everything in this course grows out of one operation. Take two vectors, multiply each one by a number, and add the results. The answer is called a linear combination.

Key ideas
  1. A vector in the plane is a pair of numbers, v = (v₁, v₂). We draw it as an arrow from the origin.
  2. Two operations: multiply a vector by a number c, and add two vectors. Both work one component at a time.
  3. Doing both gives a linear combination cv + dw.
  4. The big question: which vectors can we reach with all possible c and d?

Why vectors at all?

Suppose a sensor reports two numbers: 2 metres east and 1 metre north. Those numbers belong together, and it makes no sense to add the east value to the north value. So we keep them as a pair and give the pair one name: v = (2, 1). That is a vector.

When we add two vectors, the first components go together and the second components go together. They never mix:

v = (2, 1),   w = (−1, 1)  →  v + w = (2 + (−1), 1 + 1) = (1, 2)

On the plane, adding means walking: go along v, then from its tip go along w. You arrive at the tip of v + w.

Multiplying by a number

To get 3v, multiply each component by 3: 3v = (6, 3). The arrow points the same way and is three times as long. The number 3 is called a scalar, because it only scales the vector.

A negative scalar turns the arrow around: −v = (−2, −1). And 0·v is the zero vector (0, 0), the arrow of length zero at the origin.

Putting both together

Now combine the two operations. Choose numbers c and d and form cv + dw. With c = 3 and d = 2:

3v + 2w = (6, 3) + (−2, 2) = (4, 5)

That is a linear combination. Think of it as giving directions with only two kinds of step: "take 3 steps of v, then 2 steps of w". Every such instruction lands you somewhere.

The question behind everything

Here is the question we keep asking for the rest of the course: which vectors can we reach?

For one vector, the multiples cv fill a line through the origin. That is where the word "linear" comes from. For two vectors that point in different directions, like v and w here, the combinations cv + dw fill the whole plane. Every point is reachable.

Going the other way is harder. Given a target like (4, 5), how do we find c and d? First write out the combination, one component at a time:

c(2, 1) + d(−1, 1) = (2c − d, c + d)

For this to equal (4, 5), we need 2c − d = 4 and c + d = 5, two equations at once. Solving that kind of system is what slide 4 and lesson 2 are about.

Worked examples

Example 1 · Compute a combination

v = (1, 1), w = (1, −1), c = 2, d = 3. Find cv + dw.

2v = (2, 2)    3w = (3, −3)
2v + 3w = (2 + 3, 2 − 3) = (5, −1)

Example 2 · Find the numbers

Write (3, 0) as c·(1, 1) + d·(1, −1).

c + d = 3    c − d = 0
Adding: 2c = 3, so c = 1.5 and d = 1.5
Check: 1.5·(1, 1) + 1.5·(1, −1) = (3, 0) ✓

Example 3 · When the plane is not filled

Take v = (1, 2) and w = (2, 4). Notice that w = 2v: both arrows lie on the same line.

cv + dw = c(1, 2) + 2d(1, 2) = (c + 2d)·(1, 2)

Every combination is a multiple of (1, 2), so the combinations only fill a line, not the plane. The target (1, 0) can never be reached.

Worked examples

Example 1 · Find the combination

Write b = (7, 4) as a combination of v = (1, 2) and w = (3, 1).

We need c and d with c·(1, 2) + d·(3, 1) = (7, 4). Component by component:

c + 3d = 7    2c + d = 4
From the second: d = 4 − 2c. Into the first: c + 12 − 6c = 7, so c = 1 and d = 2.
Check: 1·(1, 2) + 2·(3, 1) = (7, 4) ✓

In matrix form this is Ax = b with the columns v and w: 1321 x = (7, 4), x = (1, 2).

Example 2 · Ax by rows and by columns

Compute Ax for A = 2−113 and x = (3, 2).

By columns: 3·(2, 1) + 2·(−1, 3) = (6 − 2, 3 + 6) = (4, 9)
By rows: (2·3 − 1·2, 1·3 + 3·2) = (4, 9)

Same answer. The column way shows that (4, 9) lies in the column space, because it is built from the columns.

Example 3 · Build a matrix from where (1, 0) and (0, 1) land

Find the matrix that sends (1, 0) to (1, 1) and (0, 1) to (−1, 1). What does it do to areas?

The landing spots are the columns: A = 1−111.

det A = 1·1 − (−1)·1 = 2

Both arrows have length √2 and are at 90° to each other. (1, 1) points at 45°, so (1, 0) has turned by 45°. (−1, 1) points at 135°, so (0, 1) has turned by 45° too. So A turns the plane by 45° and stretches it by √2. Areas double, which matches det A = 2.

Problems

1

Is (5, 1) a combination of (1, 1) and (2, −1)? If so, find the numbers c and d.

Show solutionHide solution

Solve c + 2d = 5 and c − d = 1. Subtracting gives 3d = 4, so d = 4/3 and c = 7/3.

Check: 7/3 + 8/3 = 5 and 7/3 − 4/3 = 1 ✓. Yes, because the two vectors point in different directions, every vector in the plane is a combination of them.

2

Compute Ax by columns for A = 1234 and x = (−1, 1).

Show solutionHide solution

Ax = −1·(1, 3) + 1·(2, 4) = (1, 1).

Check by rows: (−1 + 2, −3 + 4) = (1, 1) ✓

3

For which number k are the columns of 1k26 dependent? What is the column space then?

Show solutionHide solution

The columns are dependent when det = 1·6 − 2k = 0, so k = 3.

Then column 2 = (3, 6) = 3·(1, 2). The column space is the line through (1, 2). Ax = b can only be solved when b is a multiple of (1, 2).

4

Find the 2 by 2 matrix that mirrors the plane across the x-axis. What is its determinant, and what does the sign mean?

Show solutionHide solution

(1, 0) stays put and (0, 1) flips to (0, −1), so A = 100−1.

det A = −1. Areas keep their size (|det| = 1), and the minus sign says the plane was flipped over.

5

R = 0−110 turns the plane by 90°. R² means R·R and R⁴ means R·R·R·R. Predict R² and R⁴ from the picture, then check by multiplying.

Show solutionHide solution

Prediction: two quarter turns make a half turn, so R² sends every vector to its opposite. Four quarter turns make a full turn, so R⁴ leaves every vector where it started: R⁴ = I, the identity.

Check: column 1 of R² is R(0, 1) = (−1, 0) and column 2 is R(−1, 0) = (0, −1), so R² = −100−1 ✓. Then R⁴ = R²·R² = 1001 = I ✓
