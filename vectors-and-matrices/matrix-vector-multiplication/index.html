Strang §1.3 · Matrices

Ax is a combination of the columns of A.

Put the vectors v and w side by side as the columns of a matrix A, and put the numbers c and d into a vector x. Then the product Ax is exactly the combination cv + dw.

Lesson 1 · slide 2Matrix times vector
a₁₁a₁₂a₂₁a₂₂ x₁x₂ = x₁ a₁₁a₂₁ + x₂ a₁₂a₂₂
Key ideas
  1. A matrix is a block of numbers. Its columns are vectors.
  2. Ax is a combination of the columns of A, with the entries of x as the weights.
  3. Each entry of Ax can also be computed as a dot product of a row of A with x (multiply matching entries and add). Both ways give the same numbers.
  4. The column way tells us what Ax means. The row way is how we usually calculate it by hand.

From combinations to matrices

On the last slide we wrote combinations like c(2, 1) + d(−1, 1). Writing out the vectors every time gets long. So we store them as the columns of a matrix, and store c and d in a vector x:

A = 2−111    x = (c, d)    Ax = c·(2, 1) + d·(−1, 1)

To save space we write vectors across the line, like (2, 1). It still stands for a column: 2 on top, 1 below.

Each entry needs a name. We write aij for the entry of A in row i, column j, so a₁₂ sits in row 1, column 2. In the same way x = (x₁, x₂), where x₁ is the c and x₂ is the d from slide 1.

That is the definition we will use: Ax is x₁ times column 1, plus x₂ times column 2. The colours match the arrows in the lab (the code and picture below). If A had more columns, x would need more entries, one weight per column.

An everyday picture: a shopping basket

You buy eggs and rice. One egg gives about 6 g of protein and 1 g of carbohydrate. One bowl of rice gives about 4 g of protein and 45 g of carbohydrate. Put each food in a column:

A = 64145    x = (2 eggs, 1 bowl)

The total in your basket is 2·(6, 1) + 1·(4, 45) = (16, 47): 16 g of protein and 47 g of carbohydrate. That total is Ax. Adding up whole foods is the column way.

The row way gives the same answer

You could also add up one nutrient at a time. Protein: 6·2 + 4·1 = 16. Carbohydrate: 1·2 + 45·1 = 47. Each of these is a dot product of a row of A with x: multiply matching entries and add.

Both ways always agree, because they add the same products in a different order. When we calculate by hand, rows are usually quicker. When we want to understand what Ax can be, columns are the way to think. Strang returns to this point again and again, and so will we.

Watch the sizes

We count a vector as a matrix with one column: a vector with n entries is an n by 1 matrix. For Ax to make sense, x must have one entry for each column of A. The result has one entry for each row. A 2 by 3 matrix (2 rows, 3 columns) takes a vector with 3 entries and produces a vector with 2 entries.

(2 × 3) · (3 × 1) → (2 × 1)    the inner numbers must match, the outer numbers give the size of the answer

Worked examples

Example 1 · Both ways

A = 3125, x = (1, 2).

By columns: 1·(3, 2) + 2·(1, 5) = (5, 12)
By rows: (3·1 + 1·2, 2·1 + 5·2) = (5, 12)

Example 2 · A wide matrix

A = 102311 has 3 columns, so x needs 3 entries. Take x = (2, 1, 1). (2 × 3) · (3 × 1) → (2 × 1)

Ax = 2·(1, 3) + 1·(0, 1) + 1·(2, 1) = (4, 8)

Three columns in, a vector with 2 entries out: one per row of A.

Example 3 · Picking out a column

What is A times x = (1, 0)? And times (0, 1)?

A(1, 0) = 1·(column 1) + 0·(column 2) = column 1
A(0, 1) = column 2

So the columns of A are exactly what A does to (1, 0) and (0, 1). We use this again on slide 5.

Example 4 · Two motors on a drone

Look at a drone from behind and keep only two motors, left and right. We track two numbers: the lift (the total upward push) and the tilt (right push minus left push; positive means the right side rises). Each motor gives one column:

M = 11−11   column 1: left motor, column 2: right motor
Both motors at 2:   M(2, 2) = 2·(1, −1) + 2·(1, 1) = (4, 0)
Left 1, right 3:   M(1, 3) = 1·(1, −1) + 3·(1, 1) = (4, 2)

The lift stays 4, so the drone holds its height, but now the right side rises. The output is a mix of the motor columns, weighted by the thrusts.

Worked examples

Example 1 · Find the combination

Write b = (7, 4) as a combination of v = (1, 2) and w = (3, 1).

We need c and d with c·(1, 2) + d·(3, 1) = (7, 4). Component by component:

c + 3d = 7    2c + d = 4
From the second: d = 4 − 2c. Into the first: c + 12 − 6c = 7, so c = 1 and d = 2.
Check: 1·(1, 2) + 2·(3, 1) = (7, 4) ✓

In matrix form this is Ax = b with the columns v and w: 1321 x = (7, 4), x = (1, 2).

Example 2 · Ax by rows and by columns

Compute Ax for A = 2−113 and x = (3, 2).

By columns: 3·(2, 1) + 2·(−1, 3) = (6 − 2, 3 + 6) = (4, 9)
By rows: (2·3 − 1·2, 1·3 + 3·2) = (4, 9)

Same answer. The column way shows that (4, 9) lies in the column space, because it is built from the columns.

Example 3 · Build a matrix from where (1, 0) and (0, 1) land

Find the matrix that sends (1, 0) to (1, 1) and (0, 1) to (−1, 1). What does it do to areas?

The landing spots are the columns: A = 1−111.

det A = 1·1 − (−1)·1 = 2

Both arrows have length √2 and are at 90° to each other. (1, 1) points at 45°, so (1, 0) has turned by 45°. (−1, 1) points at 135°, so (0, 1) has turned by 45° too. So A turns the plane by 45° and stretches it by √2. Areas double, which matches det A = 2.

Problems

1

Is (5, 1) a combination of (1, 1) and (2, −1)? If so, find the numbers c and d.

Show solutionHide solution

Solve c + 2d = 5 and c − d = 1. Subtracting gives 3d = 4, so d = 4/3 and c = 7/3.

Check: 7/3 + 8/3 = 5 and 7/3 − 4/3 = 1 ✓. Yes, because the two vectors point in different directions, every vector in the plane is a combination of them.

2

Compute Ax by columns for A = 1234 and x = (−1, 1).

Show solutionHide solution

Ax = −1·(1, 3) + 1·(2, 4) = (1, 1).

Check by rows: (−1 + 2, −3 + 4) = (1, 1) ✓

3

For which number k are the columns of 1k26 dependent? What is the column space then?

Show solutionHide solution

The columns are dependent when det = 1·6 − 2k = 0, so k = 3.

Then column 2 = (3, 6) = 3·(1, 2). The column space is the line through (1, 2). Ax = b can only be solved when b is a multiple of (1, 2).

4

Find the 2 by 2 matrix that mirrors the plane across the x-axis. What is its determinant, and what does the sign mean?

Show solutionHide solution

(1, 0) stays put and (0, 1) flips to (0, −1), so A = 100−1.

det A = −1. Areas keep their size (|det| = 1), and the minus sign says the plane was flipped over.

5

R = 0−110 turns the plane by 90°. R² means R·R and R⁴ means R·R·R·R. Predict R² and R⁴ from the picture, then check by multiplying.

Show solutionHide solution

Prediction: two quarter turns make a half turn, so R² sends every vector to its opposite. Four quarter turns make a full turn, so R⁴ leaves every vector where it started: R⁴ = I, the identity.

Check: column 1 of R² is R(0, 1) = (−1, 0) and column 2 is R(−1, 0) = (0, −1), so R² = −100−1 ✓. Then R⁴ = R²·R² = 1001 = I ✓
