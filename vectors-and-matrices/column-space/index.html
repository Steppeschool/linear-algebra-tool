Strang §1.3 and §3.1 · Column space

The column space C(A) is every possible Ax.

Try every possible x and collect all the outputs Ax. That collection is the column space of A. Now pick a target b, a vector we want to reach. Solving Ax = b comes down to one question: is b in the column space?

Lesson 1 · slide 3Column space
C(A) = all vectors Ax = all combinations of the columns
Key ideas
  1. The column space C(A) contains every combination of the columns of A, that is, every vector Ax.
  2. Ax = b has a solution exactly when b is in C(A).
  3. In the plane, C(A) is the whole plane, a line through the origin, or just the origin.
  4. The rank measures the size of C(A): 2 for the whole plane, 1 for a line, 0 for the origin alone.

All the outputs at once

So far we computed one product Ax at a time. Now let x vary over every possible vector and mark each output Ax on the plane. The set of all those points is the column space, written C(A).

Because every Ax is a combination of the columns, C(A) is simply "all combinations of the columns". That is where the name comes from.

An engineering picture: a boat with two thrusters

A small boat has two thrusters. Column 1 of A is the push from thruster 1 at full power, and column 2 is the push from thruster 2. The entries of x are the two throttle settings, and a negative setting means reverse. Then Ax is the total push on the boat.

  • If the thrusters point in different directions, mixing them can push the boat any way you like. C(A) is the whole plane.
  • If both thrusters point forward, the boat can only go forward or backward. C(A) is a line, and a sideways target is out of reach no matter how you set the throttles.

Three possibilities in the plane

For a 2 by 2 matrix there are only three cases:

  • The whole plane: the two columns point in different directions. We call them independent.
  • A line: one column is a multiple of the other. We call them dependent.
  • Just the origin: both columns are zero.

The rank is a number that says which case we are in: rank 2 when C(A) is the whole plane, rank 1 when it is a line, rank 0 when it is the origin alone.

A closer look at the dependent case

A = 1224. Column 2 is 2 times column 1.
Ax = x₁(1, 2) + x₂(2, 4) = (x₁ + 2x₂)·(1, 2)
Every output is a multiple of (1, 2). So b = (3, 6) is reachable, but b = (1, 0) is not.

Notice something else: x = (3, 0) and x = (1, 1) both give (3, 6). With dependent columns, different inputs can produce the same output. That extra freedom gets its own name in lesson 4: the nullspace.

Two questions that sound alike

  • Can we solve Ax = b for this particular b? Yes, if b is in C(A).
  • Can we solve Ax = b for every b? Only if C(A) is the whole plane.

For 2 by 2 matrices there is a quick test. Call the entries p, q (top row) and r, s (bottom row): A = pqrs. Column 1 is (p, r) and column 2 is (q, s). The columns are independent exactly when ps − qr ≠ 0. When ps − qr = 0, the columns are dependent and C(A) is only a line (or the origin). This number ps − qr is called the determinant of A, written det A. Slide 5 shows what it means as a motion of the plane.

Worked examples

Example 1 · A line, and who is on it

A = 2412. Column 2 = 2·column 1, so C(A) is the line through (2, 1).

b = (6, 3) = 3·(2, 1): in C(A), for example x = (3, 0)
b = (1, 1): not a multiple of (2, 1), so Ax = b has no solution

Example 2 · The whole plane

A = 111−1. Here p = 1, q = 1, r = 1, s = −1, so det A = ps − qr = 1·(−1) − 1·1 = −2. That is not 0, so C(A) is the whole plane. Solve Ax = (4, 2):

x₁ + x₂ = 4    x₁ − x₂ = 2
x₁ = 3, x₂ = 1

Example 3 · Is b in the column space?

A = 1326, b = (2, 5).

Column 2 = 3·column 1, so C(A) is the line of multiples of (1, 2)
Is (2, 5) a multiple of (1, 2)? It would need 2·(1, 2) = (2, 4), not (2, 5)

So b is not in C(A), and Ax = b has no solution. Changing b to (2, 4) would make it solvable.

Worked examples

Example 1 · Find the combination

Write b = (7, 4) as a combination of v = (1, 2) and w = (3, 1).

We need c and d with c·(1, 2) + d·(3, 1) = (7, 4). Component by component:

c + 3d = 7    2c + d = 4
From the second: d = 4 − 2c. Into the first: c + 12 − 6c = 7, so c = 1 and d = 2.
Check: 1·(1, 2) + 2·(3, 1) = (7, 4) ✓

In matrix form this is Ax = b with the columns v and w: 1321 x = (7, 4), x = (1, 2).

Example 2 · Ax by rows and by columns

Compute Ax for A = 2−113 and x = (3, 2).

By columns: 3·(2, 1) + 2·(−1, 3) = (6 − 2, 3 + 6) = (4, 9)
By rows: (2·3 − 1·2, 1·3 + 3·2) = (4, 9)

Same answer. The column way shows that (4, 9) lies in the column space, because it is built from the columns.

Example 3 · Build a matrix from where (1, 0) and (0, 1) land

Find the matrix that sends (1, 0) to (1, 1) and (0, 1) to (−1, 1). What does it do to areas?

The landing spots are the columns: A = 1−111.

det A = 1·1 − (−1)·1 = 2

Both arrows have length √2 and are at 90° to each other. (1, 1) points at 45°, so (1, 0) has turned by 45°. (−1, 1) points at 135°, so (0, 1) has turned by 45° too. So A turns the plane by 45° and stretches it by √2. Areas double, which matches det A = 2.

Problems

1

Is (5, 1) a combination of (1, 1) and (2, −1)? If so, find the numbers c and d.

Show solutionHide solution

Solve c + 2d = 5 and c − d = 1. Subtracting gives 3d = 4, so d = 4/3 and c = 7/3.

Check: 7/3 + 8/3 = 5 and 7/3 − 4/3 = 1 ✓. Yes, because the two vectors point in different directions, every vector in the plane is a combination of them.

2

Compute Ax by columns for A = 1234 and x = (−1, 1).

Show solutionHide solution

Ax = −1·(1, 3) + 1·(2, 4) = (1, 1).

Check by rows: (−1 + 2, −3 + 4) = (1, 1) ✓

3

For which number k are the columns of 1k26 dependent? What is the column space then?

Show solutionHide solution

The columns are dependent when det = 1·6 − 2k = 0, so k = 3.

Then column 2 = (3, 6) = 3·(1, 2). The column space is the line through (1, 2). Ax = b can only be solved when b is a multiple of (1, 2).

4

Find the 2 by 2 matrix that mirrors the plane across the x-axis. What is its determinant, and what does the sign mean?

Show solutionHide solution

(1, 0) stays put and (0, 1) flips to (0, −1), so A = 100−1.

det A = −1. Areas keep their size (|det| = 1), and the minus sign says the plane was flipped over.

5

R = 0−110 turns the plane by 90°. R² means R·R and R⁴ means R·R·R·R. Predict R² and R⁴ from the picture, then check by multiplying.

Show solutionHide solution

Prediction: two quarter turns make a half turn, so R² sends every vector to its opposite. Four quarter turns make a full turn, so R⁴ leaves every vector where it started: R⁴ = I, the identity.

Check: column 1 of R² is R(0, 1) = (−1, 0) and column 2 is R(−1, 0) = (0, −1), so R² = −100−1 ✓. Then R⁴ = R²·R² = 1001 = I ✓
