Strang §2.4 · Rules for matrix operations

AB means: apply B first, then A.

Multiplying two matrices chains two motions into one. In AB, the matrix B acts first and A acts second, because (AB)v = A(Bv).

Lesson 1 · slide 6AB ≠ BA
AB = A b₁b₂ = Ab₁Ab₂
Key ideas
  1. AB means: apply B, then apply A. Read products from right to left.
  2. Column j of AB is A times column j of B.
  3. Usually AB ≠ BA. The order of the motions matters. When AB = BA we say A and B commute.
  4. Grouping does not matter: (AB)C = A(BC). And det(AB) = det(A)·det(B).

Socks and shoes

You put on socks first, then shoes. Do it in the other order and the result is very different. Two motions of the plane behave the same way: shear then turn is not the same as turn then shear.

In the product AB the matrix next to the vector acts first: (AB)v = A(Bv). So we read products from right to left, just as f(g(x)) applies g first.

How to compute AB

Where does (1, 0) end up after both motions? First B sends it to its first column, b₁. Then A sends b₁ to Ab₁. So the first column of AB is A times the first column of B, and the same holds for every column:

AB = A [ b₁   b₂ ] = [ Ab₁   Ab₂ ]

So multiplying two matrices is nothing new: it is matrix times vector, once for each column of B.

A worked example

R turns by 90°, and S is a shear:
R = 0−110   S = 1101
Column 1 of RS = R·(column 1 of S) = R(1, 0) = (0, 1).   Column 2 = R(1, 1) = 1·(0, 1) + 1·(−1, 0) = (−1, 1)
Column 1 of SR = S·(column 1 of R) = S(0, 1) = (1, 1).   Column 2 = S(−1, 0) = −1·(1, 0) = (−1, 0)
RS = 0−111   SR = 1−110
RS shears first and then turns. SR turns first and then shears. Different matrices, different motions. Watch where the F ends up in the lab. The picture draws a capital letter F on the graph paper: an F looks different when it is turned, slanted or flipped, so it shows each motion at a glance.

The rules

  • AB is usually not BA. Some pairs do commute, meaning AB = BA (two rotations, for example), but we can never assume it.
  • (AB)C = A(BC). Either way C acts first, then B, then A. The brackets only change how we write it.
  • det(AB) = det(A)·det(B). If B doubles every area and A triples it, together they multiply areas by 6.

Where this is used

A robot arm is a chain of joints, each one a rotation. The position of the gripper comes from multiplying those matrices in joint order. Swap two of them and the gripper ends up somewhere else.

Worked examples

Example 1 · Two orders

A = 1201 (shear), B = 2001 (stretch).

AB = 2201    BA = 2401

Stretch then shear differs from shear then stretch.

Example 2 · Two quarter turns

R = 0−110 turns by 90°.

RR = −100−1

Two quarter turns make a half turn. For rotations, multiplying adds the angles.

Example 3 · A pair that commutes

Two stretches: A = 2001, B = 1003.

AB = 2003 = BA

Stretching along x and stretching along y don't interfere, so the order doesn't matter here. A diagonal matrix has zeros everywhere except on the main diagonal (top left to bottom right). Diagonal matrices always commute with each other.

Worked examples

Example 1 · Find the combination

Write b = (7, 4) as a combination of v = (1, 2) and w = (3, 1).

We need c and d with c·(1, 2) + d·(3, 1) = (7, 4). Component by component:

c + 3d = 7    2c + d = 4
From the second: d = 4 − 2c. Into the first: c + 12 − 6c = 7, so c = 1 and d = 2.
Check: 1·(1, 2) + 2·(3, 1) = (7, 4) ✓

In matrix form this is Ax = b with the columns v and w: 1321 x = (7, 4), x = (1, 2).

Example 2 · Ax by rows and by columns

Compute Ax for A = 2−113 and x = (3, 2).

By columns: 3·(2, 1) + 2·(−1, 3) = (6 − 2, 3 + 6) = (4, 9)
By rows: (2·3 − 1·2, 1·3 + 3·2) = (4, 9)

Same answer. The column way shows that (4, 9) lies in the column space, because it is built from the columns.

Example 3 · Build a matrix from where (1, 0) and (0, 1) land

Find the matrix that sends (1, 0) to (1, 1) and (0, 1) to (−1, 1). What does it do to areas?

The landing spots are the columns: A = 1−111.

det A = 1·1 − (−1)·1 = 2

Both arrows have length √2 and are at 90° to each other. (1, 1) points at 45°, so (1, 0) has turned by 45°. (−1, 1) points at 135°, so (0, 1) has turned by 45° too. So A turns the plane by 45° and stretches it by √2. Areas double, which matches det A = 2.

Problems

1

Is (5, 1) a combination of (1, 1) and (2, −1)? If so, find the numbers c and d.

Show solutionHide solution

Solve c + 2d = 5 and c − d = 1. Subtracting gives 3d = 4, so d = 4/3 and c = 7/3.

Check: 7/3 + 8/3 = 5 and 7/3 − 4/3 = 1 ✓. Yes, because the two vectors point in different directions, every vector in the plane is a combination of them.

2

Compute Ax by columns for A = 1234 and x = (−1, 1).

Show solutionHide solution

Ax = −1·(1, 3) + 1·(2, 4) = (1, 1).

Check by rows: (−1 + 2, −3 + 4) = (1, 1) ✓

3

For which number k are the columns of 1k26 dependent? What is the column space then?

Show solutionHide solution

The columns are dependent when det = 1·6 − 2k = 0, so k = 3.

Then column 2 = (3, 6) = 3·(1, 2). The column space is the line through (1, 2). Ax = b can only be solved when b is a multiple of (1, 2).

4

Find the 2 by 2 matrix that mirrors the plane across the x-axis. What is its determinant, and what does the sign mean?

Show solutionHide solution

(1, 0) stays put and (0, 1) flips to (0, −1), so A = 100−1.

det A = −1. Areas keep their size (|det| = 1), and the minus sign says the plane was flipped over.

5

R = 0−110 turns the plane by 90°. R² means R·R and R⁴ means R·R·R·R. Predict R² and R⁴ from the picture, then check by multiplying.

Show solutionHide solution

Prediction: two quarter turns make a half turn, so R² sends every vector to its opposite. Four quarter turns make a full turn, so R⁴ leaves every vector where it started: R⁴ = I, the identity.

Check: column 1 of R² is R(0, 1) = (−1, 0) and column 2 is R(−1, 0) = (0, −1), so R² = −100−1 ✓. Then R⁴ = R²·R² = 1001 = I ✓
