Strang §4.2 · Projection matrices

Projection matrices: P flattens everything onto the line.

The projection p = a(aᵀb)/(aᵀa) can be produced by one matrix P acting on b. For a line, P = aaᵀ/aᵀa. For the column space of a matrix A, P = A(AᵀA)⁻¹Aᵀ. Projecting twice gives the same result as projecting once: P² = P.

P = aaᵀ / aᵀa    P = A(AᵀA)⁻¹Aᵀ    P² = P
Key ideas
  1. P multiplies any vector b and returns its projection p = Pb.
  2. For a line, P = aaᵀ / aᵀa: a column times a row, divided by a number.
  3. P² = P: projecting a second time changes nothing. Also Pᵀ = P.
  4. For the column space of A (independent columns), P = A(AᵀA)⁻¹Aᵀ.
  5. I − P projects onto the perpendicular part: (I − P)b = e.

A machine that projects

On the last slide we projected one vector. Often we want to project many: every reading from a sensor, every pixel of an image. It is worth building one matrix that does the job for any b.

Write p = a(aᵀb) / aᵀa. Now regroup the product: a(aᵀb) is the same as (aaᵀ)b, because matrix products can be grouped either way. So p = (aaᵀ / aᵀa) b. The matrix in brackets is P.

a = (1, 2):   aaᵀ = 1224,   aᵀa = 5
P = 0.20.40.40.8
Pb for b = (4, 3): (0.8 + 1.2, 1.6 + 2.4) = (2, 4) ✓ (the same p as slide 2)

Pressing twice changes nothing

Think of a press that flattens dough onto a tray. Once the dough is flat, pressing it again leaves it as it is. A projection behaves the same way. After the first projection, p is already on the line, and its projection is p itself. So P(Pb) = Pb for every b, which says P² = P.

In the lab, run show(P). The whole plane collapses onto the line through (1, 2). The determinant is 0: P is not invertible. You cannot recover b from its shadow p.

Projecting onto a plane or a column space

Now project b onto the column space of a matrix A with independent columns. The projection is p = Ax̂ for some vector x̂ of coefficients. The error e = b − Ax̂ must be perpendicular to every column of A, so Aᵀe = 0:

Aᵀ(b − Ax̂) = 0
AᵀA x̂ = Aᵀb
x̂ = (AᵀA)⁻¹Aᵀb,    p = A(AᵀA)⁻¹Aᵀ b

So P = A(AᵀA)⁻¹Aᵀ. When A has a single column a, AᵀA is the number aᵀa and we get back aaᵀ/aᵀa. The middle equation, AᵀAx̂ = Aᵀb, is the most important equation in this lesson. The next slide puts it to work.

Where this is used

Noise cancelling and signal cleanup often work by projection. Build P onto the subspace where the clean signals live and apply it to every measurement. The part that survives, Pb, is the signal. The part removed, (I − P)b, is treated as noise.

Worked examples

Example 1 · Onto the x-axis

a = (1, 0): aaᵀ = 1000, aᵀa = 1.

P = 1000,   P(5, 7) = (5, 0)

The projection keeps the x component and drops the y component: a shadow cast straight down onto the x-axis.

Example 2 · Onto the diagonal

a = (1, 1): aaᵀ = 1111, aᵀa = 2, so P = ½1111.

P(3, 1) = ½(4, 4) = (2, 2)   (as in slide 2, example 1)
P² = ¼2222 = ½1111 = P ✓

Example 3 · Onto a plane in 3D

A = 101101: its two columns span a plane.

AᵀA = 2112,   (AᵀA)⁻¹ = ⅓2−1−12
P = A(AᵀA)⁻¹Aᵀ = ⅓21−1121−112
P(1, 0, 0) = ⅓(2, 1, −1). The error ⅓(1, −1, 1) is perpendicular to both columns ✓

The plane is perpendicular to n = (1, −1, 1), and I − P = nnᵀ/3 projects onto that normal line.

Find the projection matrix onto the line through a = (0, 3).

2

Show from the formula that P = aaᵀ/aᵀa satisfies P² = P.

Show solutionHide solution

P² = (aaᵀ)(aaᵀ) / (aᵀa)² = a(aᵀa)aᵀ / (aᵀa)².

The middle aᵀa is a number. One copy cancels with the denominator, leaving aaᵀ/aᵀa = P.

3

For a = (1, 1), what is I − P, and onto which line does it project?

Show solutionHide solution

I − P = 1001 − ½1111 = ½1−1−11.

It is the projection onto the line through (1, −1), the line perpendicular to a.

Worked examples

Example 1 · Project onto a line in 3D

Project b = (3, 0, 3) onto the line through a = (1, 2, 2).

aᵀb = 3 + 0 + 6 = 9,   aᵀa = 1 + 4 + 4 = 9,   x̂ = 1
p = (1, 2, 2),   e = b − p = (2, −2, 1)
a · e = 2 − 4 + 2 = 0 ✓

The distance from b to the line is ‖e‖ = 3.

Example 2 · Fit a line to five points

Fit C + Dt to (−2, 0), (−1, 1), (0, 1), (1, 2), (2, 4).

The times are centred: Σt = 0, so the normal equations separate
5C = Σb = 8,   C = 1.6
10D = Σtb = 0 − 1 + 0 + 2 + 8 = 9,   D = 0.9

Best line: 1.6 + 0.9t. Choosing t so that Σt = 0 is a common trick: it makes the columns of A perpendicular.

Example 3 · Gram-Schmidt and QR in 3D

a = (1, 0, 1), b = (1, 1, 0).

aᵀb = 1, aᵀa = 2:   B = b − ½a = (½, 1, −½),   a · B = ½ − ½ = 0 ✓
q₁ = (1, 0, 1)/√2,   q₂ = B/√1.5
R = QᵀA = √21/√20√1.5

Check in the lab: Q, R = np.linalg.qr(A), then Q @ R gives A back.

Problems

1

Are (1, −1, 0) and (1, 1, 5) perpendicular? Find a nonzero vector perpendicular to both.

Show solutionHide solution

1 − 1 + 0 = 0, so yes.

A vector (x, y, z) perpendicular to both needs x − y = 0 and x + y + 5z = 0. Take x = y = −5, z = 2: (−5, −5, 2). Check: −5 + 5 + 0 = 0 and −5 − 5 + 10 = 0 ✓

2

Project b = (1, 2, 3) onto the line through a = (1, 0, 1).

Show solutionHide solution

aᵀb = 4, aᵀa = 2, x̂ = 2. p = (2, 0, 2), e = (−1, 2, 1). Check: −1 + 0 + 1 = 0 ✓

3

Find the projection matrix onto the line through a = (2, 1) and apply it to b = (5, 0).

Show solutionHide solution

P = aaᵀ / aᵀa = ⅕4221. Pb = ⅕(20, 10) = (4, 2).

4

Find the least squares solution of x = 1, x = 4, 2x = 4.

Show solutionHide solution

A = (1, 1, 2), b = (1, 4, 4). x̂ = aᵀb / aᵀa = (1 + 4 + 8) / 6 = 13/6 ≈ 2.17.

5

Find the best line C + Dt through (0, 4), (1, 2), (2, 1), (3, 1).

Show solutionHide solution

m = 4, Σt = 6, Σt² = 14, Σb = 8, Σtb = 0 + 2 + 2 + 3 = 7.

4C + 6D = 8 and 6C + 14D = 7 give D = −1 and C = 3.5. Best line: 3.5 − t.
