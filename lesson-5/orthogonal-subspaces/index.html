Strang §4.1 · Orthogonality of the four subspaces

Perpendicular vectors, perpendicular subspaces.

Two vectors are perpendicular when their dot product is zero. Whole subspaces can be perpendicular too. The four subspaces from lesson 4 come in two perpendicular pairs, and that fact drives the rest of this lesson.

vᵀw = 0    N(A) ⟂ C(Aᵀ)    N(Aᵀ) ⟂ C(A)
Key ideas
  1. v and w are orthogonal (perpendicular) when v · w = vᵀw = 0.
  2. Then Pythagoras holds: ‖v‖² + ‖w‖² = ‖v + w‖².
  3. Two subspaces are orthogonal when every vector in one is perpendicular to every vector in the other.
  4. Ax = 0 says each row of A has dot product 0 with x. So the nullspace is perpendicular to the row space.
  5. The two pieces fill the input space: every x splits into a row space part plus a nullspace part.

Perpendicular means "no overlap"

Walk along a street that runs exactly north. However far you go, your east-west position does not change. North and east are perpendicular directions: moving in one tells you nothing about the other.

In algebra the test is the dot product. Multiply matching components and add. If the total is zero, the vectors are perpendicular. For v = (2, 1) and w = (−1, 2): v · w = −2 + 2 = 0.

We also write the dot product as vᵀw: a row times a column. It is the same number.

Why the dot product is the right test

For a right angle, Pythagoras says the squared lengths add up. Check it on the example:

‖v‖² = 4 + 1 = 5    ‖w‖² = 1 + 4 = 5
v + w = (1, 3),   ‖v + w‖² = 1 + 9 = 10 = 5 + 5 ✓

In general ‖v + w‖² = ‖v‖² + 2vᵀw + ‖w‖². The middle term vanishes exactly when vᵀw = 0. So "dot product zero" and "right angle" are the same statement.

Perpendicular subspaces

Now raise the level. Two subspaces V and W are orthogonal if every vector in V is perpendicular to every vector in W. The floor of a room and a vertical line through the corner are an example: the line is perpendicular to every direction on the floor.

Look again at Ax = 0. Each component of Ax is one row of A dotted with x. So Ax = 0 says: x is perpendicular to every row. Then x is also perpendicular to every combination of the rows, which is the whole row space C(Aᵀ).

A = 1326   row space: the line through (1, 3)
nullspace: the line through (−3, 1)
(1, 3) · (−3, 1) = −3 + 3 = 0 ✓

The same reasoning with Aᵀ in place of A shows that the left nullspace N(Aᵀ) is perpendicular to the column space C(A).

The two pieces fill the space

The row space has dimension r and the nullspace has dimension n − r. Together that is n, the whole input space. So the nullspace is not just some perpendicular subspace: it contains every vector perpendicular to the row space. Strang calls the two subspaces orthogonal complements.

This means every input x splits in exactly one way into x = x_r + x_n, a row space part plus a nullspace part. Since Ax_n = 0, the matrix only "sees" the row space part: Ax = Ax_r.

Where this is used

An IMU (the motion sensor in a phone or drone) has three accelerometer axes at right angles. Because the axes are perpendicular, each one measures its own direction only. Tilt the board along x, and the y and z readings stay put, apart from noise.

Worked examples

Example 1 · Test with the dot product

Are v = (1, 2, 3) and w = (3, 0, −1) perpendicular?

v · w = 1·3 + 2·0 + 3·(−1) = 3 + 0 − 3 = 0 ✓
Pythagoras: ‖v‖² = 14, ‖w‖² = 10, v + w = (4, 2, 2), ‖v + w‖² = 24 = 14 + 10 ✓

Yes. In 3D the test is the same: one product per component, then add.

Example 2 · Rows against the nullspace

A = 121242. Rank 1, so the row space is the line through (1, 2, 1).

Special solutions of Ax = 0: s₁ = (−2, 1, 0), s₂ = (−1, 0, 1)
(1, 2, 1) · (−2, 1, 0) = −2 + 2 + 0 = 0 ✓
(1, 2, 1) · (−1, 0, 1) = −1 + 0 + 1 = 0 ✓

The nullspace is a plane, the row space is a line, and the line sticks straight out of the plane. Dimensions 2 + 1 = 3.

Example 3 · Split an input into two parts

For A = 1326, split x = (4, 2) into a row space part and a nullspace part.

Row space part: a multiple c·(1, 3). The rest must be perpendicular to (1, 3).
(4 − c, 2 − 3c) · (1, 3) = 0  gives  10 − 10c = 0,  c = 1
x_r = (1, 3),   x_n = (3, −1),   x_r + x_n = (4, 2) ✓
Ax = (10, 20) and Ax_r = (10, 20): the nullspace part changed nothing

Find c so that (1, c) is perpendicular to (4, 2).

Show solutionHide solution

(1, c) · (4, 2) = 4 + 2c = 0, so c = −2. The vector is (1, −2).

2

Find a nonzero vector in the nullspace of 110011 and check that it is perpendicular to both rows.

Show solutionHide solution

From row 2, y = −z. From row 1, x = −y = z. With z = 1: x = (1, −1, 1).

Row 1: 1 − 1 + 0 = 0 ✓   Row 2: 0 − 1 + 1 = 0 ✓

3

Can the row space and the nullspace of a 3 by 3 matrix both be planes?

Show solutionHide solution

No. Their dimensions are r and 3 − r, which add to 3, not 4.

There is also a picture reason: two planes through the origin in 3D always share a line. A vector on that line would have to be perpendicular to itself, and only the zero vector is.

Worked examples

Example 1 · Project onto a line in 3D

Project b = (3, 0, 3) onto the line through a = (1, 2, 2).

aᵀb = 3 + 0 + 6 = 9,   aᵀa = 1 + 4 + 4 = 9,   x̂ = 1
p = (1, 2, 2),   e = b − p = (2, −2, 1)
a · e = 2 − 4 + 2 = 0 ✓

The distance from b to the line is ‖e‖ = 3.

Example 2 · Fit a line to five points

Fit C + Dt to (−2, 0), (−1, 1), (0, 1), (1, 2), (2, 4).

The times are centred: Σt = 0, so the normal equations separate
5C = Σb = 8,   C = 1.6
10D = Σtb = 0 − 1 + 0 + 2 + 8 = 9,   D = 0.9

Best line: 1.6 + 0.9t. Choosing t so that Σt = 0 is a common trick: it makes the columns of A perpendicular.

Example 3 · Gram-Schmidt and QR in 3D

a = (1, 0, 1), b = (1, 1, 0).

aᵀb = 1, aᵀa = 2:   B = b − ½a = (½, 1, −½),   a · B = ½ − ½ = 0 ✓
q₁ = (1, 0, 1)/√2,   q₂ = B/√1.5
R = QᵀA = √21/√20√1.5

Check in the lab: Q, R = np.linalg.qr(A), then Q @ R gives A back.

Problems

1

Are (1, −1, 0) and (1, 1, 5) perpendicular? Find a nonzero vector perpendicular to both.

Show solutionHide solution

1 − 1 + 0 = 0, so yes.

A vector (x, y, z) perpendicular to both needs x − y = 0 and x + y + 5z = 0. Take x = y = −5, z = 2: (−5, −5, 2). Check: −5 + 5 + 0 = 0 and −5 − 5 + 10 = 0 ✓

2

Project b = (1, 2, 3) onto the line through a = (1, 0, 1).

Show solutionHide solution

aᵀb = 4, aᵀa = 2, x̂ = 2. p = (2, 0, 2), e = (−1, 2, 1). Check: −1 + 0 + 1 = 0 ✓

3

Find the projection matrix onto the line through a = (2, 1) and apply it to b = (5, 0).

Show solutionHide solution

P = aaᵀ / aᵀa = ⅕4221. Pb = ⅕(20, 10) = (4, 2).

4

Find the least squares solution of x = 1, x = 4, 2x = 4.

Show solutionHide solution

A = (1, 1, 2), b = (1, 4, 4). x̂ = aᵀb / aᵀa = (1 + 4 + 8) / 6 = 13/6 ≈ 2.17.

5

Find the best line C + Dt through (0, 4), (1, 2), (2, 1), (3, 1).

Show solutionHide solution

m = 4, Σt = 6, Σt² = 14, Σb = 8, Σtb = 0 + 2 + 2 + 3 = 7.

4C + 6D = 8 and 6C + 14D = 7 give D = −1 and C = 3.5. Best line: 3.5 − t.
