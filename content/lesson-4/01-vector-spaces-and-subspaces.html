In the plane there are only three kinds: the origin alone, a line through the origin, or the whole plane. v and w in S  ⇒  cv + dw in S, for every c and d

Think: a train on rails

Straight rails run through the station, which is the origin. Drive forward, reverse, combine trips: you always stay on the rails. That line is a subspace.

Now picture rails that miss the station. Scale any position by 0 and you should land at the origin, but the origin is not on those rails. So they are not a subspace.

The three rules

  • It contains the zero vector.
  • Adding two vectors in the set stays in the set.
  • Scaling a vector in the set stays in the set.

Examples and non-examples

  • Yes: the line y = 2x. Add or scale points on it and you stay on it.
  • No: the line y = 2x + 1. It misses the origin.
  • No: the first quadrant. Multiply by −1 and you leave it.
  • No: the two axes together. (1, 0) + (0, 1) = (1, 1) is on neither axis.

Worked example in 3D

All (x, y, z) with x + y + z = 0. Add two such vectors and the sums add: 0 + 0 = 0. Scale one and the sum scales: c·0 = 0. So it is a subspace, a plane through the origin.
With x + y + z = 1 instead, the origin fails the test. Not a subspace.

Why we care

The column space from lesson 1 is a subspace. So is the nullspace on the next slide. Chapter 3 is about these spaces, because they tell you exactly which equations Ax = b can be solved, and how many solutions they have.

Example 1 · A line through the origin

All (x, y) with y = 3x.

Contains (0, 0). If y₁ = 3x₁ and y₂ = 3x₂, then y₁ + y₂ = 3(x₁ + x₂), and cy₁ = 3(cx₁)

A subspace.

Example 2 · A half-plane

All (x, y) with x ≥ 0.

(1, 0) is in the set, but (−1)·(1, 0) = (−1, 0) is not

Not a subspace: scaling can leave it.

Example 3 · Two planes in 3D

All (x, y, z) with z = 0, and all with z = 1.

z = 0: the floor, a plane through the origin. A subspace
z = 1: a parallel plane that misses the origin. Not a subspace
