  1. A subspace contains the zero vector and is closed under addition and scaling.
  2. Lines and planes through the origin are subspaces. Those that miss the origin are not.
  3. The column space C(A) from lesson 1 is a subspace.
  4. This lesson is about four subspaces that every matrix carries.

Think of a train on rails

Straight rails run through a station at the origin. The train can go forward, reverse, or combine several trips, and it always stays on the rails. In vector language: adding and scaling vectors on the line keeps them on the line. That line is a subspace.

Now picture rails that do not pass through the station. Scaling any position by 0 should give the origin, but the origin is not on those rails. So a line that misses the origin is not a subspace.

The definition

A set of vectors S is a subspace when three things hold:

  • The zero vector is in S.
  • If v and w are in S, so is v + w.
  • If v is in S, so is cv for every number c.

Together these say: every linear combination cv + dw of vectors in S stays in S.

Examples and non-examples in the plane

  • Yes: the line y = 2x. Sums and multiples of points on it stay on it.
  • No: the line y = 2x + 1. It misses the origin.
  • No: the first quadrant (x ≥ 0, y ≥ 0). Multiplying by −1 leaves it.
  • No: the two axes together. (1, 0) and (0, 1) are in the set, but their sum (1, 1) is not.

An example in 3D

All (x, y, z) with x + y + z = 0. Adding two such vectors adds their sums, 0 + 0 = 0. Scaling multiplies the sum, c·0 = 0. So this is a subspace: a plane through the origin.
With x + y + z = 1 instead, the origin fails the test, so it is not a subspace.

Why subspaces matter

The column space of lesson 1 is a subspace: a combination of combinations of the columns is still a combination of the columns. The nullspace on the next slide is a subspace too. Together with two more, they answer the central questions of this lesson: which equations Ax = b can be solved, and how many solutions they have.

Example 1 · A line through the origin

All (x, y) with y = 3x.

Contains (0, 0). If y₁ = 3x₁ and y₂ = 3x₂, then y₁ + y₂ = 3(x₁ + x₂), and cy₁ = 3(cx₁)

A subspace.

Example 2 · A half-plane

All (x, y) with x ≥ 0.

(1, 0) is in the set, but (−1)·(1, 0) = (−1, 0) is not

Not a subspace: scaling can leave it.

Example 3 · Two planes in 3D

All (x, y, z) with z = 0, and all with z = 1.

z = 0: the floor, a plane through the origin. A subspace
z = 1: a parallel plane that misses the origin. Not a subspace

No. (1, 1) is on it, but 2·(1, 1) = (2, 2) is not, since 2 ≠ 4.

Yes, the smallest one. 0 + 0 = 0 and c·0 = 0.
