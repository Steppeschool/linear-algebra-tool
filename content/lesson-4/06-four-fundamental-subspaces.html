The row space and the nullspace live among the inputs, the column space and the left nullspace among the outputs. The rank r fixes the size of all four. inputs (ℝⁿ):  row space r + nullspace n − r   |   outputs (ℝᵐ):  column space r + left nullspace m − r
  1. Inputs (ℝⁿ): the row space C(Aᵀ), dimension r, and the nullspace N(A), dimension n − r.
  2. Outputs (ℝᵐ): the column space C(A), dimension r, and the left nullspace N(Aᵀ), dimension m − r.
  3. The row space and the column space always have the same dimension, r.
  4. The row space is perpendicular to the nullspace.

Think of a shadow

The sun is straight overhead, and every object casts a shadow on the floor. Taking an object to its shadow is like a matrix taking 3D inputs to 2D outputs.

  • Moving an object straight up or down does not change its shadow. That lost direction is the nullspace.
  • Moving it along the floor moves the shadow by the same amount. That part of the input is the row space.
  • Every place where a shadow can fall is the column space.
  • If the outputs had a direction that no shadow could ever reach, it would belong to the left nullspace, N(Aᵀ).

The dimensions

For an m by n matrix of rank r:

row space: r  +  nullspace: n − r  =  n
column space: r  +  left nullspace: m − r  =  m

The row space is the column space of Aᵀ, so we write it C(Aᵀ). The left nullspace N(Aᵀ) holds every y with Aᵀy = 0, which is the same as yᵀA = 0: y multiplies A from the left. In the shadow example every point of the floor can be reached, so there the left nullspace is just {0}.

The row space and column space have the same dimension, even though they live in different spaces. Strang calls these four dimensions Part 1 of the Fundamental Theorem of Linear Algebra.

Why the row space is perpendicular to the nullspace

Ax = 0 says that each row of A, dotted with x, gives 0. So x is perpendicular to every row, and therefore to every combination of rows, which is the whole row space. The next lesson (Strang, chapter 4) builds on this.

Each pair is perpendicular: (1, 2)·(−2, 1) = 0 and (1, 3)·(−3, 1) = 0 ✓
