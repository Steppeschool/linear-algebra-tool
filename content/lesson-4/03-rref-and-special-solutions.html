Setting one free variable to 1 and the rest to 0 gives a special solution, and every nullspace vector is a combination of these. 12132438  →  R = 12010012
  1. Elimination does not change the nullspace: Ax = 0 and Rx = 0 have the same solutions.
  2. Pivot variables belong to columns with pivots. Free variables belong to the other columns.
  3. Each free variable gives one special solution.
  4. An m by n matrix of rank r has n − r special solutions, and every vector in N(A) is a combination of them.

Think of a mixing desk

A mixing desk has four sliders. Two of them are free: you set them however you like. The other two are linked and move on their own to keep the total output at zero.

Free variables are the free sliders, and pivot variables are the linked ones. Each setting of the free sliders gives exactly one vector in the nullspace.

Reading R

R is the reduced row echelon form: each pivot is 1, and the pivot columns have zeros everywhere else. For our matrix

A = 12132438  →  R = 12010012

The pivots are in columns 1 and 3, so x₁ and x₃ are pivot variables, and x₂ and x₄ are free. Rx = 0 reads:

x₁ + 2x₂ + x₄ = 0    and    x₃ + 2x₄ = 0

The special solutions

x₂ = 1, x₄ = 0:   x₁ = −2, x₃ = 0  →  s₁ = (−2, 1, 0, 0)
Check with A: 1·(−2) + 2·1 = 0 and 2·(−2) + 4·1 = 0 ✓
The second special solution comes from x₂ = 0, x₄ = 1. That is your exercise.

Counting

A has n = 4 columns and r = 2 pivots, so there are n − r = 2 free variables and 2 special solutions. Every vector in N(A) is a combination x = c·s₁ + d·s₂, so N(A) is a plane inside 4-dimensional space. The number r of pivots is the rank of A.

A shortcut: the entries of R in a free column, with their signs flipped, are the pivot values in that column's special solution.

Example 1 · One free column

A = 123001.

row 1 − 3·row 2: R = 120001. Pivots in columns 1 and 3
Free x₂ = 1: x₁ = −2, x₃ = 0. Special solution (−2, 1, 0)

Example 2 · Two free columns

A = 11111234.

R = 10−1−20123
x₃ = 1: (1, −2, 1, 0).   x₄ = 1: (2, −3, 0, 1)

n − r = 4 − 2 = 2 special solutions.
