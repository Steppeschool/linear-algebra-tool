Keep the direction of a. From b, remove its projection onto a: what is left is perpendicular to a. Then divide each vector by its length. That is Gram-Schmidt, and recording the steps gives A = QR. u₂ = b − (aᵀb / aᵀa) a    q₁ = a / ‖a‖,   q₂ = u₂ / ‖u₂‖    A = QR
  1. The first vector a is kept as it is.
  2. From b, subtract its projection onto a. The remainder u₂ is perpendicular to a.
  3. From a third vector c, subtract its projections onto both a and u₂.
  4. Finally divide each by its length: q₁ = a/‖a‖, q₂ = u₂/‖u₂‖, and so on.
  5. With a, b, c as the columns of A, each column is a combination of the q's: A = QR, with R upper triangular.

Squaring up a frame

A carpenter building a frame fixes the first board wherever it should go. The second board is then pushed until it sits at a right angle to the first, using a set square. Any lean towards the first board is removed. If there is a third board, it is squared against both.

Gram-Schmidt does the same with vectors. We start from independent vectors a, b, c and build perpendicular vectors u₁, u₂, u₃ from them, one at a time. The lean of b towards a is exactly its projection onto a, which we know from slide 2.

The steps

Keep the first direction as it is: u₁ = a (below we just write a).   u₂ = b − (aᵀb / aᵀa) a
Check: aᵀu₂ = aᵀb − (aᵀb / aᵀa) aᵀa = 0 ✓
q₁ = a / ‖a‖,   q₂ = u₂ / ‖u₂‖

u₂ is the error vector e from slide 2: the part of b that sticks out of the line through a.

A worked example

a = (1, 1),   b = (2, 0)
aᵀb = 2,   aᵀa = 2:   u₂ = (2, 0) − 1·(1, 1) = (1, −1)
a · u₂ = 1 − 1 = 0 ✓
q₁ = (1, 1)/√2,   q₂ = (1, −1)/√2

Three vectors and more

For a third vector c, subtract its projection onto each earlier direction:

u₃ = c − (aᵀc / aᵀa) a − (u₂ᵀc / u₂ᵀu₂) u₂

Each fraction is a number (a dot product over a dot product). Because a and u₂ are already perpendicular, the two subtractions do not interfere: removing the a-part of c does not change its u₂-part, because aᵀu₂ = 0. Each new vector gets squared against everything built before it.

A = QR

Put the original vectors in the columns of a matrix, A = [a b c], and the q's in the columns of Q. Each original vector is a combination of the q's built so far: a uses only q₁, b uses q₁ and q₂, c uses q₁, q₂ and q₃. Collect the coefficients in a matrix R: column j of R holds the amounts of q₁, q₂, ... needed to rebuild the j-th original vector. It is upper triangular, and A = QR. Multiply A = QR by Qᵀ on the left: QᵀQ = I, so R = QᵀA. Every entry of R is a dot product of some q with some original vector.

A = 1210 = 1/√21/√21/√2−1/√2√2√20√2
For example R₁₂ = q₁ᵀb = (2 + 0)/√2 = √2: the amount of q₁ inside b.

Elimination recorded its steps as A = LU. Gram-Schmidt records its steps as A = QR. With A = QR, the normal equations AᵀAx̂ = Aᵀb become RᵀQᵀQRx̂ = RᵀQᵀb, which simplifies to Rx̂ = Qᵀb (QᵀQ = I, and Rᵀ is invertible, so it cancels from both sides): a triangular system, solved by back substitution. This is how good software solves least squares.

Where this is used

The drone's rotation matrix from the last slide drifts away from orthonormal. One Gram-Schmidt pass on its three columns squares it up again, a few times per second.

Example 1 · Two vectors in the plane

a = (1, 0), b = (3, 4).

aᵀb = 3, aᵀa = 1:   u₂ = (3, 4) − 3·(1, 0) = (0, 4)
q₁ = (1, 0),   q₂ = (0, 1)

The result is the standard basis, and R = 1304.

Example 2 · Three vectors in 3D

a = (1, 1, 0), b = (1, 0, 1), c = (0, 1, 1).

u₂ = b − ½a = (½, −½, 1)
aᵀc = 1 and aᵀa = 2;   u₂ᵀc = −½ + 1 = ½ and u₂ᵀu₂ = ¼ + ¼ + 1 = 3/2, so the fraction is ⅓
u₃ = c − ½a − ⅓u₂ = (−⅔, ⅔, ⅔)
Checks: a · u₂ = 0,   a · u₃ = 0,   u₂ · u₃ = −⅓ − ⅓ + ⅔ = 0 ✓
Divide by the lengths √2, √(3/2) and 2/√3 to get q₁, q₂, q₃

Example 3 · The computer's version

np.linalg.qr(A) returns Q and R. For A = 1210 it may return −q₁ and −q₂ with a matching sign change in R. Both are correct factorizations. A direction and its opposite span the same line.

Check any answer with two tests: Q.T @ Q is the identity, and Q @ R gives back A.

What happens if b is a multiple of a?

Show solutionHide solution

Then b equals its own projection onto a, and u₂ = 0. There is nothing to normalize, and Gram-Schmidt stops.

That is the signal that the vectors were dependent: b added no new direction.
