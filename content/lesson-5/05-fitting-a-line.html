The best line C + Dt makes the sum of squared vertical errors as small as possible. The normal equations give C and D in one step, for four points or four million. E = Σ (bᵢ − C − D tᵢ)²    mΣtΣtΣt² (C, D) = (Σb, Σtb)
  1. Each data point (tᵢ, bᵢ) gives one equation C + D tᵢ = bᵢ.
  2. A has a column of ones (for C) and a column of times tᵢ (for D).
  3. The errors are the vertical gaps eᵢ = bᵢ − (C + D tᵢ). Least squares minimizes the sum of their squares.
  4. The normal equations become two equations in C and D, built from m and four sums.
  5. The same method fits calibration lines, trends and growth rates.

A ruler across the pins

Picture a corkboard with a few pins and a ruler laid across them. You slide and tilt the ruler until it looks as close as possible to all the pins at once. Least squares makes "as close as possible" precise. Measure each vertical gap, square it, add the squares, and make that total E as small as possible.

The lab does exactly this. Drag C (the value of the line at t = 0) and D (its slope) and watch E. The dashed grey line is the best one. When you land on it, the readout says so.

The data

A motor is switched on and its temperature rise is read once a minute: t = 0, 1, 2, 3 minutes, readings b = 1, 2, 4, 5 degrees. The points are close to a line but not on one.

A = 10111213,   b = (1, 2, 4, 5)

The normal equations

Where do the sums come from? The two rows of Aᵀ are the column of ones and the column of times. So every entry of AᵀA and Aᵀb is a dot product of two columns:

ones · ones = m, the number of points    ones · t = Σt, the sum of the times    t · t = Σt², the sum of the squared times
ones · b = Σb, the sum of the readings    t · b = Σtᵢbᵢ, each time multiplied by its reading, then added
AᵀA = mΣtΣtΣt²,   Aᵀb = (Σb, Σtᵢbᵢ)

For the motor:

m = 4,   Σt = 6,   Σt² = 14,   Σb = 12,   Σtᵢbᵢ = 0 + 2 + 8 + 15 = 25
4C + 6D = 12    6C + 14D = 25
Multiply the first by 1.5 and subtract: 5D = 7, so D = 1.4 and C = 0.9.   Best line: 0.9 + 1.4t
predictions (0.9, 2.3, 3.7, 5.1),   errors (0.1, −0.3, 0.3, −0.1),   E = 0.2

The motor warms by about 1.4 degrees per minute. The errors add up to zero, as the last slide predicted.

Why squares?

We need the errors to count as positive, or misses above and below the line would cancel. Squaring does that, and it gives a smooth bowl-shaped E with a single lowest point. That lowest point is where the normal equations hold. (Calculus confirms it by setting the slopes of E to zero; the projection argument on the last slide reaches the same equations without calculus.) Absolute values also make errors positive, but there is no simple formula for their minimum.

Where this is used

Calibrating a sensor is a line fit. Put an accelerometer in known positions, record what it reads, and fit reading = bias + scale × true value. Example 3 below does exactly this.

Example 1 · The motor, by computer

The same data in NumPy: np.linalg.solve(A.T @ A, A.T @ b) returns (0.9, 1.4).

np.linalg.lstsq(A, b) gives the same answer. It also uses the projection idea, with a more careful method inside.

Example 2 · Points that are already on a line

Points (0, 1), (1, 3), (2, 5).

AᵀA = 3335,   Aᵀb = (9, 13)
C = 1, D = 2,   errors (0, 0, 0),   E = 0

When the data is exactly linear, least squares finds that exact line.

Example 3 · Calibrating an accelerometer axis

Point the axis down, sideways and up. The true acceleration along it is −1 g, 0 and +1 g. The readings are −0.96, 0.03 and 1.08 g.

t = (−1, 0, 1),   b = (−0.96, 0.03, 1.08)
m = 3, Σt = 0, Σt² = 2. With Σt = 0 the off-diagonal entries of AᵀA vanish, so each equation has one unknown:   3C = Σb = 0.15,   2D = Σtᵢbᵢ = 2.04
bias C = 0.05 g,   scale D = 1.02

From now on, the corrected reading is (reading − 0.05) / 1.02. Every IMU calibration routine does a version of this.

2

Fit the best horizontal line b = C (no slope) to the motor data b = 1, 2, 4, 5.

Show solutionHide solution

A is a single column of ones, so C = Σb / m = 12 / 4 = 3, the average. A flat line cannot follow the warming, and its E = 4 + 1 + 1 + 4 = 10 is much larger than 0.2.

3

Why not make the plain sum of the errors as small as possible?

Show solutionHide solution

Errors above and below the line would cancel. For the motor data, the flat line b = 3 has errors (−2, −1, 1, 2), which add to zero, yet it is a poor fit. Squaring makes every miss count.
