Use row operations to turn A into I. The same operations turn I into A⁻¹. [ A  |  I ]  →  [ I  |  A⁻¹ ]
  1. Start with the block matrix [A | I].
  2. Eliminate below the pivots, then above them, then divide each row by its pivot.
  3. When the left half becomes I, the right half is A⁻¹.
  4. To solve Ax = b, use elimination (A = LU), not A⁻¹: it is faster and more accurate.

Think of carbon paper

Put a sheet of carbon paper under your work. Every row operation you apply to A is copied onto the identity beside it. When A has been turned into I, the copy holds the record of every step. Those steps, taken together, undo A, so the copy is A⁻¹.

In matrix language: if a sequence of steps E turns A into I, then EA = I, which means E = A⁻¹. Applying the same steps to I gives EI = E = A⁻¹.

The three stages

  • Forward: clear the entries below each pivot, as in lesson 2.
  • Backward: clear the entries above each pivot, working from the bottom row up.
  • Scale: divide each row by its pivot, so the diagonal becomes all 1s.

The result is called the reduced row echelon form. The lab's rref carries out all three stages.

A worked example

K = 2−10−12−10−12 appears in models of a chain of springs and masses.
K⁻¹ = ¼ · 321242123
Check one column: K times (3, 2, 1) = (6 − 2, −3 + 4 − 1, −2 + 2) = (4, 0, 0), which is 4 times the first column of I ✓

Thinking with the inverse, computing without it

Computing A⁻¹ takes about three times the work of factoring A = LU, and it adds rounding error. So to solve Ax = b, use elimination directly. The inverse is invaluable for reasoning, as in x = A⁻¹b, but it is rarely the best way to compute.

Example 1 · A 2 by 2 by hand

Invert A = 2111.

[2 1 | 1 0; 1 1 | 0 1] → row 2 − ½·row 1 → [2 1 | 1 0; 0 ½ | −½ 1]
row 2 × 2 → [0 1 | −1 2]; row 1 − row 2 → [2 0 | 2 −2]; row 1 ÷ 2
A⁻¹ = 1−1−12

Example 2 · A triangular matrix

Invert A = 120013001. Only upward steps are needed.

row 2 − 3·row 3, then row 1 − 2·row 2
A⁻¹ = 1−2601−3001

The 6 comes from the two steps interacting: −2 · (−3).

Example 3 · When Gauss-Jordan stops

Try A = 1224.

row 2 − 2·row 1 → [1 2 | 1 0; 0 0 | −2 1]

The left side has a zero row, so it can never become I. No inverse.
