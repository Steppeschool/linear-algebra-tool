Use row operations to turn A into I. The same operations turn I into A⁻¹. [ A  |  I ]  →  [ I  |  A⁻¹ ]
  1. Start with A and I written side by side: [A | I].
  2. Eliminate below the pivots, then above them, then divide each row by its pivot.
  3. When the left half becomes I, the right half is A⁻¹.
  4. To solve Ax = b, use elimination (A = LU), not A⁻¹: it is faster and more accurate.

Think of carbon paper

Put a sheet of carbon paper under your work. Every row operation you apply to A is copied onto the identity beside it. When A has been turned into I, the copy holds the record of every step. Those steps, taken together, undo A, so the copy is A⁻¹.

In matrix language: in lesson 2 each elimination step was a matrix E₁, E₂, and so on. Dividing a row by its pivot is a step matrix too: the identity with 1/pivot in place of that row's diagonal 1. Multiply all the step matrices together, with the last step on the left: E = ⋯E₃E₂E₁. If these steps turn A into I, then EA = I. A matrix that turns A into I undoes A, so E = A⁻¹. The same steps applied to I give EI = E, which is A⁻¹.

The three stages

  • Forward: clear the entries below each pivot, as in lesson 2.
  • Backward: clear the entries above each pivot, working from the bottom row up.
  • Scale: divide each row by its pivot, so the diagonal becomes all 1s.

Scaling a row does not disturb the zeros, so it can be done at any time. Doing it last just keeps the fractions away until the end.

The result is called the reduced row echelon form (rref). The lab's rref carries out all three stages.

A worked example

K = 2−10−12−10−12 appears in models of a chain of springs and masses.
Start from [K | I]. Each step below changes one row; the numbers after | are the right half.
Forward: row 2 + ½·row 1 → [0  3/2  −1 | ½  1  0]
Forward: row 3 + ⅔·row 2 → [0  0  4/3 | ⅓  ⅔  1]. The pivots are 2, 3/2, 4/3.
Backward: row 2 + ¾·row 3 → [0  3/2  0 | ¾  3/2  ¾]
Backward: row 1 + ⅔·row 2 → [2  0  0 | 3/2  1  ½]
Scale: row 1 ÷ 2 → [1  0  0 | ¾  ½  ¼]
Scale: row 2 ÷ 3/2 → [0  1  0 | ½  1  ½]
Scale: row 3 ÷ 4/3 → [0  0  1 | ¼  ½  ¾]
The left half is now I. Every entry of the right half is a multiple of ¼, so pull ¼ out front:
K⁻¹ = ¼ · 321242123
Check one column. The first column of K⁻¹ is ¼·(3, 2, 1), and K times it must give the first column of I, (1, 0, 0). Because of the ¼ in front, K·(3, 2, 1) itself should give 4·(1, 0, 0) = (4, 0, 0):
K·(3, 2, 1) = (6 − 2, −3 + 4 − 1, −2 + 2) = (4, 0, 0) ✓

Thinking with the inverse, computing without it

Computing A⁻¹ takes about three times the work of factoring A = LU, and it adds rounding error. So to solve Ax = b, use elimination directly. The inverse is invaluable for reasoning, as in x = A⁻¹b, but it is rarely the best way to compute.

Example 1 · A 2 by 2 by hand

Invert A = 2111.

[2 1 | 1 0; 1 1 | 0 1] → row 2 − ½·row 1 → [2 1 | 1 0; 0 ½ | −½ 1]
above: row 1 − 2·row 2 → [2 0 | 2 −2; 0 ½ | −½ 1]
divide: row 1 ÷ 2 and row 2 ÷ ½ → [1 0 | 1 −1; 0 1 | −1 2]
A⁻¹ = 1−1−12

Example 2 · A triangular matrix

Invert A = 120013001. Only upward steps are needed.

row 2 − 3·row 3, then row 1 − 2·row 2
A⁻¹ = 1−2601−3001

Where does the 6 come from? Follow the right half, which starts as I. Step 1 puts −3 in row 2, column 3, so row 2 becomes [0 1 −3]. Step 2 subtracts 2 times this new row 2 from row 1. Row 1 had 0 in column 3, so it gets 0 − 2·(−3) = 6. The second step uses the result of the first.
