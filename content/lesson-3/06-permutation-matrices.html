PA puts the rows of A in that order. Elimination uses permutations to record row exchanges. P = 001100010   PA = rows 3, 1, 2 of A
  1. Each row and each column of P contains a single 1.
  2. PA reorders the rows of A; AP reorders its columns (Example 1).
  3. P⁻¹ = Pᵀ: transposing undoes the reordering.
  4. With row exchanges, elimination gives PA = LU.

Think of a playlist

PA is like a playlist with slots: first, second, third. Each slot gets one row of A. A 1 in row i, column j of P means "slot i takes row j". In the P at the top of this slide, the 1 at (1, 3) means slot 1 takes row 3.

Undoing a permutation

To undo P, send each row back. If slot i took row j, the undo says "slot j takes row i back": a 1 at (j, i). (Slot 1 took row 3, so the undo has a 1 at (3, 1).) Moving every 1 from (i, j) to (j, i) flips P across its diagonal, which gives Pᵀ. So P⁻¹ = Pᵀ for every permutation matrix.

A worked example

Use a matrix A whose rows are full of 1s, 2s and 3s, so you can see where each row goes.
P = 001100010   PA = 333111222
PᵀP = I ✓

How many are there?

  • n rows can be ordered in n! ways. So there are 6 permutation matrices of size 3, counting I.
  • In the plane the only exchange is 0110. It is the mirror across the line y = x from lesson 1, with det = −1.

Back to elimination

In lesson 2, a zero pivot meant exchanging rows. If A is invertible, do all the exchanges first, with one permutation P. Then elimination never meets a zero pivot, and PA = LU. NumPy and other solvers compute this form. They pick the exchanges so each pivot is as large as possible.

Example 1 · Rows or columns

P = 0110, A = 1234.

PA = 3412: the rows swap
AP = 2143: the columns swap

Why columns? Column j of AP is A times column j of P (Ax by columns, lesson 1). Each column of P has a single 1, so it picks out one column of A. Column 1 of P is (0, 1), which picks column 2 of A.

Example 2 · Reverse order

P = 001010100 puts rows in the order 3, 2, 1.

Pᵀ = P, so P⁻¹ = P: doing it twice restores the order

Example 3 · PA = LU

A = 0231 has a zero first pivot.

Swap: PA = 3102, already upper triangular
So PA = LU with L = I

−1: 0·0 − 1·1 = −1. A mirror keeps areas the same, so the size is 1, and it flips the plane over, so the sign is minus. Preview: a swap of two rows in any size is still a mirror, and the determinants lesson will show its determinant is also −1.
