To undo both, undo the last one first. So the inverse of AB is B⁻¹A⁻¹: the order reverses. (AB)⁻¹ = B⁻¹A⁻¹     (ABC)⁻¹ = C⁻¹B⁻¹A⁻¹
  1. (AB)⁻¹ = B⁻¹A⁻¹. The order reverses.
  2. For three matrices: (ABC)⁻¹ = C⁻¹B⁻¹A⁻¹.
  3. The algebra check: B⁻¹A⁻¹AB = B⁻¹IB = I.
  4. The same reversal happens for transposes: (AB)ᵀ = BᵀAᵀ (ᵀ, the transpose, comes on slide 5).

Socks and shoes

You put on socks, then shoes. You take off shoes first, then socks. Same steps, opposite order.

Matrix products act right to left: AB does B first, then A. A went on last, so A⁻¹ acts first. The first step sits on the right, so the inverse is B⁻¹A⁻¹.

Check it with algebra

(B⁻¹A⁻¹)(AB) = B⁻¹(A⁻¹A)B = B⁻¹ I B = B⁻¹B = I ✓

A meets A⁻¹ in the middle, and they cancel. Then B and B⁻¹ cancel. In the other order, A⁻¹B⁻¹AB, nothing meets its own inverse, and the result is usually not I.

A worked example

R turns by 90°, S is a shear. From lesson 1, RS = 0−111
R⁻¹ = 01−10 (turn back)   S⁻¹ = 1−101 (slide back)
S⁻¹R⁻¹ = 11−10   but   R⁻¹S⁻¹ = 01−11
Only S⁻¹R⁻¹ undoes RS. In the lab, follow v = (1, 1) through S and R, then try both orders on the way back.

Where this is used

Each part of a robot arm has its own set of axes, called its frame. The product of the joint matrices, T₁T₂⋯Tₙ, turns a point measured from the gripper into the same point measured from the base. To go the other way, from base to gripper, use the inverse Tₙ⁻¹⋯T₁⁻¹: the joints in reverse order.

Example 1 · Shear then stretch, undone

A = 2001, B = 1101.

(AB)⁻¹ = B⁻¹A⁻¹ = 1−101½001 = ½−101
Check: AB = 2201, whose inverse is ½·1−202 ✓

Example 2 · Powers

If A is invertible, so is A²:

(A²)⁻¹ = (AA)⁻¹ = A⁻¹A⁻¹ = (A⁻¹)²
(A⁻¹)⁻¹ = A: undoing the undo gets you back

Example 3 · Three steps

For three invertible matrices:

(ABC)⁻¹ = C⁻¹B⁻¹A⁻¹

C acted first, so it is undone last.
