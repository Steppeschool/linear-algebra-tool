Now we ask a bigger question: is there a matrix that simply undoes A? You know this from money. Changing euros into dollars multiplies by the exchange rate, and changing back divides by it, so you end with the euros you started with. For numbers, 3 is undone by 1/3, because (1/3)·3 = 1. For matrices, the inverse A⁻¹ does the same job: A turns an input x into an output Ax, and A⁻¹ turns that output back into x. The matrix that plays the part of the number 1 is the identity I, which changes nothing. When A⁻¹ exists, it solves Ax = b in one step: x = A⁻¹b. Some matrices cannot be undone, and this slide shows how to spot them. A⁻¹A = I     Ax = b  ⇔  x = A⁻¹b
  1. The inverse A⁻¹ undoes A: A⁻¹A = I and AA⁻¹ = I, where I is the identity matrix.
  2. If A has an inverse, Ax = b has exactly one solution, x = A⁻¹b.
  3. A matrix that sends two different inputs to the same output cannot be undone.
  4. A square matrix has an inverse exactly when all its pivots are nonzero, or, equivalently, when no column is a combination of the others (lesson 4 calls this independent). A matrix that has an inverse is called invertible.

Undo for numbers first

Multiplying by 3 is undone by multiplying by 1/3. The pair cancels and leaves 1, the number that changes nothing:

(1/3)·3 = 1    so   3x = 12  →  x = (1/3)·12 = 4

The number 0 has no undo: 0·x is 0 for every x, so from the answer 0 you can never tell what x was. Matrices work the same way, with one twist: many matrices besides the zero matrix (all entries 0) have no undo either.

The identity: the matrix that changes nothing

For matrices, the role of 1 is played by the identity matrix I from lesson 2: 1s on the diagonal and 0s everywhere else. I times any vector gives the same vector back:

I·(4, 7) = 1001(4, 7) = (1·4 + 0·7, 0·4 + 1·7) = (4, 7)

So "A⁻¹ undoes A" means: A⁻¹ times A is I. Inverses only exist for square matrices (lesson 4 shows why), and for them the undo works both ways: AA⁻¹ = I too.

Example: undo “add the second entry to the first”

Take S = 1101. Multiply it by a vector (p, q), by rows as in lesson 1: S·(p, q) = (p + q, q). S adds the second entry to the first and keeps the second entry. Start from (1, 2):

S·(1, 2) = (1 + 2, 2) = (3, 2)

To undo S, take the second entry away from the first one again: (p, q) goes to (p − q, q). That is the matrix S⁻¹ = 1−101. Feed it the output (3, 2):

S⁻¹·(3, 2) = (3 − 2, 2) = (1, 2)  ✓ back where we started

That worked for one vector. To be sure it works for every vector, multiply the two matrices, as in lesson 2. The product should be I:

S⁻¹S = 1−1011101 = 1 + 01 − 10 + 00 + 1 = 1001 ✓

The lab draws each vector as an arrow from the origin, as in lesson 1. Multiplying by S gives a new arrow. Follow v = (1, 2): S sends it to (3, 2). Your S⁻¹ should bring it back.

Why the inverse solves equations

Start with Ax = b and multiply both sides on the left by A⁻¹. Since A⁻¹A = I and Ix = x, the left side is just x:

Ax = b  →  A⁻¹Ax = A⁻¹b  →  x = A⁻¹b

Try it with S. To solve Sx = (5, 2), multiply (5, 2) by S⁻¹:

x = S⁻¹·(5, 2) = (5 − 2, 2) = (3, 2)
Check: S·(3, 2) = (3 + 2, 2) = (5, 2) ✓

If the inverse exists, this x is the one and only solution.

When there is no inverse

Some matrices can't be undone. Here is one. Its second column is just twice the first:

A = 1224

Feed it two different inputs:

A·(2, 0) = (2, 4)    A·(0, 1) = (2, 4)

Different inputs, same output. If all you see is (2, 4), you can't tell which input made it. So nothing can undo A, and A has no inverse. The same happens with A·(2, −1) = (2 − 2, 4 − 4) = (0, 0): this input lands on (0, 0), just like the input (0, 0) does.

A matrix that has an inverse is called invertible. For a square matrix, each of these says the same thing: A is invertible.

  • Every pivot is nonzero (lesson 2). For A above, row 2 − 2·row 1 gives 00, so the second pivot is 0.
  • No column is a combination of the others. Otherwise the outputs miss part of the space (in the plane: they all land on one line, as in lesson 1's column space), so some outputs are shared. Lesson 4 calls columns like that, with no column a combination of the others, independent. For A, column 2 = 2·column 1.
  • Ax = 0 only when x = 0. For A, x = (2, −1) also gives 0.

So one failed test means all of them fail. The next slide adds a quick number test for 2 by 2 matrices.

A bigger example: a 3 × 3 inverse

Lesson 2's elimination matrix E₂₁ subtracts 2 times row 1 from row 2. Its undo adds 2 times row 1 back:

E₂₁ = 100−210001    E₂₁⁻¹ = 100210001
Row 2 of E₂₁⁻¹E₂₁ mixes the rows of E₂₁ using the numbers in row 2 of E₂₁⁻¹ (lesson 2, slide 5): 2·100 + 1·−210 + 0·001 = 010 ✓
Rows 1 and 3 of both matrices are rows of I, so they stay 100 and 001. The product is I.

A matrix with zeros everywhere off the diagonal is called a diagonal matrix, often named D. It multiplies each entry of a vector by its own number, so its inverse divides by those numbers:

D = 200040005    D⁻¹ = ½000¼000⅕    D⁻¹·(2, 4, 5) = (1, 1, 1)

The idea is the same for a matrix with a thousand rows: A⁻¹ is the matrix whose product with A is I.

Next: How do we actually find A⁻¹? For a 2 by 2 matrix there is a short recipe, and one number tells at once whether the inverse exists.

Example 1 · Undo a diagonal matrix

D = 2005 is diagonal: D·(p, q) = (2p, 5q). It multiplies the first entry by 2 and the second by 5.

D⁻¹ = ½00⅕: divide the first entry by 2 and the second by 5

Example 2 · Undo a swap with a sign

R = 0−110 sends (p, q) to (−q, p): the entries trade places and the new first entry gets a minus sign. For example R·(1, 0) = (0, 1).

R⁻¹ = 01−10 sends (p, q) to (q, −p), which brings (−q, p) back to (p, q)
RR⁻¹ = I

Example 3 · Solve with the inverse

Suppose A⁻¹ = 2111. Then Ax = b with b = (1, 2) is solved by one multiplication:

x = A⁻¹b = (2·1 + 1·2, 1·1 + 1·2) = (4, 3)

Example 4 · Check a guess by multiplying

Is 2−1−11 the inverse of B = 1112? Multiply and see if you get I.

Row 1 of B times the guess: 1·2 + 1·(−1)1·(−1) + 1·1 = 10
Row 2 of B times the guess: 1·2 + 2·(−1)1·(−1) + 2·1 = 01
B times the guess = I, so yes ✓

Checking is always easy: one matrix product.
