We start from three rules that the determinant must obey. Every other fact, including how to compute it, follows from these three. det I = 1    row swap: det changes sign    linear in each row
  1. Rule 1: det I = 1. The identity does not change any volume.
  2. Rule 2: swapping two rows changes the sign of det.
  3. Rule 3: det is linear in each row on its own: scale a single row by t and det scales by t, and a row that is a sum splits det into a sum.
  4. Consequences: two equal rows give det = 0; adding a multiple of one row to another row does not change det.

Rules of a game

Chess is defined by a few rules for how each piece moves. Nobody memorises every possible game: the games follow from the rules. The determinant works the same way. Three rules pin it down completely.

The three rules

We state the rules for the rows of A. Slide 3 shows that det Aᵀ = det A, so every rule holds for the columns too. That matters because the columns are the edges of the box from slide 1.

  • det I = 1. The identity moves nothing, so the unit cube keeps volume 1.
  • A row swap flips the sign. Swapping two rows of 0110 gives I, so det 0110 = −1. It is a mirror.
  • Linear in each row, one row at a time. Double one row and the volume doubles: one edge of the box got twice as long. And if one row is a sum, row = u + v, then det splits into two determinants, one with u in that row and one with v (the other rows stay as they are).

Careful: rule 3 is about one row at a time. Doubling the whole n by n matrix multiplies det by 2ⁿ, because each of the n rows doubles. And det(A + B) is usually not det A + det B.

What follows

Two equal rows give det = 0. Swapping them changes nothing, but rule 2 says the sign flips. So det = −det, which means det = 0.
Subtracting ℓ × row j from row i leaves det unchanged. The new row i is (row i) − ℓ(row j). By rule 3 the det splits into det A − ℓ × det(A with row i replaced by row j). That second matrix has row j twice, so its det is 0. What is left is det A.
A row of zeros gives det = 0. Multiply that row by 0: rule 3 says det × 0.

The second fact is the big one. It says that the elimination steps from lesson 2 do not change the determinant. Geometrically, they are shears: they slant the box without changing its volume, like pushing a deck of cards sideways.

A worked check

A = 120251013,   det A = 2
Row 2 − 2·row 1 gives B = 120011013,   det B = 2 ✓

Where this is used

Numerical software never uses a long formula for big determinants. It uses these rules: eliminate (det unchanged), count the row swaps (each flips the sign), and multiply what is left on the diagonal. That is the next slide.

Example 1 · A row swap

det 1234 = 4 − 6 = −2.

Swap the rows: det 3412 = 6 − 4 = 2 = −(−2) ✓

Example 2 · Scaling one row

det 1234 = −2. Multiply row 1 by 5:

det 51034 = 20 − 30 = −10 = 5 × (−2) ✓

Multiplying the whole matrix by 5 would give 5² × (−2) = −50.

Example 3 · Two equal rows

det 123456123 = 0 without any calculation: rows 1 and 3 are equal.

Geometrically, two edges of the box lie on top of each other, so the box is flat.

If det A = 3 for a 3 by 3 matrix A, what is det(2A)? What is det(−A)?

Show solutionHide solution

Each of the 3 rows is doubled: det(2A) = 2³ · 3 = 24. Each row is multiplied by −1: det(−A) = (−1)³ · 3 = −3.

A is 4 by 4 with det A = 5. You swap rows 1 and 2, then rows 3 and 4. What is the new det?

Show solutionHide solution

Two swaps: the sign flips twice. The determinant is 5 again.

Why does a matrix with a row of zeros have determinant 0? Give the rule you use.

Show solutionHide solution

Rule 3: multiplying that row by 0 leaves the matrix the same but multiplies det by 0. So det = 0 · det = 0.

Geometrically, one edge of the box has length 0.
