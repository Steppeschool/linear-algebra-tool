Replace column j of A by b and divide determinants: that is xⱼ. Collect the cofactors and divide by det A: that is A⁻¹. Neat formulas, slow in practice. xⱼ = det Bⱼ / det A    (Bⱼ = A with column j replaced by b)    A⁻¹ = Cᵀ / det A
  1. Cramer's rule: xⱼ = det Bⱼ / det A, where Bⱼ is A with its column j replaced by b.
  2. It needs det A ≠ 0, the same condition as for A⁻¹ to exist.
  3. The inverse: (A⁻¹)ᵢⱼ = Cⱼᵢ / det A. Note the swap: the cofactor matrix is transposed.
  4. For 2 by 2 this is exactly the formula from lesson 3.

A recipe card for each unknown

Elimination solves all the unknowns together. Cramer's rule gives each unknown its own recipe card: one ratio of two determinants, independent of the others. That is handy for a formula on paper, but each card costs a full determinant.

Why it works (2 by 2)

Write the columns of A as a₁ and a₂, so b = x₁a₁ + x₂a₂. Put b into column 1 and use the rules from slide 2:

det [b a₂] = det [x₁a₁ + x₂a₂   a₂] = x₁ det [a₁ a₂] + x₂ det [a₂ a₂]
The last determinant has two equal columns, so it is 0
det B₁ = x₁ · det A,   so x₁ = det B₁ / det A

The same argument works for every column and every size.

A worked example

A = 2113,   b = (5, 10),   det A = 6 − 1 = 5
B₁ = 51103: det = 15 − 10 = 5,   x₁ = 5/5 = 1
B₂ = 25110: det = 20 − 5 = 15,   x₂ = 15/5 = 3
Check: A(1, 3) = (2 + 3, 1 + 9) = (5, 10) ✓

The inverse from cofactors

Column j of A⁻¹ solves Ax = (column j of I). Cramer's rule on those right-hand sides gives every entry of A⁻¹ as a cofactor divided by det A. Put the cofactors Cᵢⱼ in a matrix C, transpose it, and divide:

A⁻¹ = Cᵀ / det A
2 by 2: C = d−c−ba,   Cᵀ = d−b−ca,   A⁻¹ = d−b−ca / (ad − bc)

That is the 2 by 2 recipe from lesson 3, now explained.

Where this is used

Cramer's rule shows up in formulas, not in solvers. For example, it tells you how sensitive one unknown is to one measurement, written as a clean ratio. To actually solve a system with more than three unknowns, elimination is far faster.

Example 1 · Cramer for another 2 by 2

x + 2y = 5,   3x + 4y = 6.

det A = 4 − 6 = −2
x = det 5264 / (−2) = (20 − 12)/(−2) = −4
y = det 1536 / (−2) = (6 − 15)/(−2) = 4.5
Check: −4 + 9 = 5 ✓,   −12 + 18 = 6 ✓

Example 2 · An inverse from cofactors

A = 2153, det A = 1.

A⁻¹ = 3−1−52 / 1
Check: A A⁻¹ = 1001 ✓

Example 3 · When Cramer fails

A = 1224: det A = 0.

Every ratio would divide by zero. That matches lesson 4: the system has no solution or infinitely many, never exactly one.

If A has integer entries and det A = 1, why does A⁻¹ also have integer entries?

Show solutionHide solution

A⁻¹ = Cᵀ / 1, and every cofactor is a sum of products of integers.

import numpy as np A = np.array([[2., 1.], [1., 3.]]) b = np.array([5., 10.]) B1 = np.column_stack([b, A[:, 1]]) # b replaces column 1 B2 = np.column_stack([b, A[:, 1]]) # your turn: b should replace column 2 # hint: np.column_stack([A[:, 0], b]) x = np.array([np.linalg.det(B1), np.linalg.det(B2)]) / np.linalg.det(A) print("x =", x) combo(A, x, b) # Ax should land on b
