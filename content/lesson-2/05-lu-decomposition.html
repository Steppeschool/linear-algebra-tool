If we keep the multipliers, they form a lower triangular matrix L, and multiplying L times U gives A back. This factorization A = LU is how computers solve systems in practice. A = LU    L = 100ℓ₂₁10ℓ₃₁ℓ₃₂1
  1. A = LU: L is lower triangular with 1s on its diagonal, U is upper triangular.
  2. The multipliers ℓᵢⱼ go straight into L, in the positions where they were used.
  3. To solve Ax = b: first solve Lc = b, then Ux = c. Both are fast triangular solves.
  4. Factor once, then reuse L and U for every new right-hand side b.

Think of meal prep

On Sunday you chop all the vegetables for the week. That takes time. Then every weekday dinner takes five minutes, because the slow part is already done.

Factoring A = LU is the Sunday work. Each new right-hand side b is a weekday dinner: two quick triangular solves.

Lc = b  (forward substitution, top to bottom)    then    Ux = c  (back substitution, bottom to top)

Here c is the same c as on slide 2: b after the elimination steps. Forward substitution means solving Lc = b from the top row down, and doing so simply redoes those subtractions on b. Row 2 of L reads ℓ₂₁c₁ + c₂ = b₂, so c₂ = b₂ − ℓ₂₁c₁. With the slide 2 numbers that is c₂ = −2 − 2·5 = −12, the same subtraction we did to b there. Problem 2 below finishes c₃.

Where L comes from

Slide 4 wrote elimination as E₃₂E₃₁E₂₁A = U. To get A back, undo the steps in reverse order:

A = E₂₁⁻¹ E₃₁⁻¹ E₃₂⁻¹ U = LU

Why the reverse order? Think of socks and shoes. You put on socks first and shoes second, but to undo it you take off the shoes first. The last step done is the first one undone. E₃₂ acted last, so its inverse E₃₂⁻¹ sits right next to U and acts on it first.

Each inverse is the identity with +ℓ where E had −ℓ (slide 4). Multiplied in this order, the multipliers do not mix: each one lands in its own position. So L needs no extra arithmetic. It is simply the record of every multiplier we used, like a receipt. The example below checks this.

The example from slides 2 to 4

The multipliers were ℓ₂₁ = 2, ℓ₃₁ = −1, ℓ₃₂ = −1. Multiply the three inverses:
E₂₁⁻¹ E₃₁⁻¹ E₃₂⁻¹ = 100210001 100010−101 1000100−11 = 100210−1−11
Each multiplier sits in place: ℓ₂₁ in row 2, column 1, ℓ₃₁ in row 3, column 1, ℓ₃₂ in row 3, column 2. (The other order mixes them: E₃₂E₃₁E₂₁ has −1 in row 3, column 1, not −ℓ₃₁ = +1. That is why we record L rather than E.)
L = 100210−1−11   U = 2110−8−2001
Check row 3 of LU: −1·(2, 1, 1) − 1·(0, −8, −2) + 1·(0, 0, 1) = (−2, 7, 2), which is row 3 of A ✓

Why it saves time

For n unknowns, factoring costs about n³/3 multiplications. Each triangular solve after that costs about n². With n = 1000 that is roughly 330 million operations for the factoring, and then about a million for each new b.

So when the matrix stays the same and only the right side changes, as in a simulation stepping through time, we factor once and reuse L and U. In the lab, lu(A) returns both factors so you can check your own work.

The first pivot is 0, so no multiplier can be formed. Swap the rows first. Lesson 3 writes this swap as a permutation matrix P: PA = 1101 is already upper triangular, so PA = LU with L = I.
