If a zero shows up there, either a row exchange fixes it, or the system does not have exactly one solution. zero pivot  →  swap with a lower row   |   nothing to swap  →  singular
  1. A zero in a pivot position stops elimination, because we cannot divide by it.
  2. Temporary failure: a row below has a nonzero entry in that column. Exchange the rows and continue.
  3. Permanent failure: no row can help. The matrix is singular: no solution or infinitely many.
  4. Singular means the columns are dependent: one column is a combination of the others (for two columns, a multiple of the other). For two columns, they lie on one line: lesson 1's dependent case.

Think of a relay race

Your second runner is missing. If a teammate can run that leg, swap the order and carry on: a row exchange. If nobody can, the matrix is singular. Then the right-hand side decides: no solution, or infinitely many.

A temporary failure

0x + 2y = 4    3x − 2y = 5
The first pivot position holds 0, so we cannot form a multiplier. But the second equation has a 3 there. Exchange the two equations: 3x − 2y = 5 and 2y = 4. Now y = 2 and x = 3.

Same equations, new order, same solution.

Two permanent failures

  • No solution. x − 2y = 1 and 2x − 4y = 11. Subtracting 2 times the first leaves 0 = 9. Impossible: the lines are parallel.
  • Infinitely many solutions. x − 2y = 1 and 2x − 4y = 2. Subtracting leaves 0 = 0. The second equation adds nothing, so every point on the line x − 2y = 1 works.

Both times the second pivot is zero, with no row below to swap in. The left sides are the same: columns (1, 2) and (−2, −4), the second −2 times the first. Dependent columns: they lie on one line, lesson 1's dependent case. The right side only picks which failure we get.

Small pivots are dangerous too

A computer keeps about 16 significant digits. Dividing by a tiny pivot like 0.0000001 makes huge multipliers and blows up rounding errors. So real solvers, NumPy's included, swap rows at every step to put the entry largest in absolute value in the pivot position. This is called partial pivoting.

Example 1 · A swap fixes it

0x + y = 2 and x + y = 3.

The first pivot is 0. Swap the equations: x + y = 3, y = 2
y = 2, then x = 1

Example 2 · Infinitely many solutions

x + y = 2 and 2x + 2y = 4.

ℓ = 2: the second equation becomes 0 = 0
Only x + y = 2 is left. Choose y = t freely; then x = 2 − t

Every point (2 − t, t) is a solution: the whole line.

Example 3 · A zero pivot in the middle of a 3 by 3

A = 111112123.

ℓ₂₁ = 1: row 2 → (0, 0, 1).   ℓ₃₁ = 1: row 3 → (0, 1, 2)
The second pivot is 0, but row 3 has a 1 there. Swap rows 2 and 3
U = 111012001, pivots 1, 1, 1

A temporary breakdown: after the swap there are three nonzero pivots, so Ax = b has exactly one solution for every b. Whatever b is, back substitution can always divide by each nonzero pivot, so it never gets stuck.
