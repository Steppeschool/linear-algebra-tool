Subtract a multiple of one equation from another so that one unknown disappears. Repeat until you can read off the answer. x − 2y = 1    3x + 2y = 11   →   8y = 8
  1. The pivot is the first coefficient of the equation we subtract with (equation 1; here the 1 in 1x). We use it to remove x from the equations below.
  2. The multiplier is ℓ = (entry to remove) ÷ (pivot). In code we write ℓ as l.
  3. Subtracting ℓ times one equation from another keeps the same solution.
  4. When one unknown is left in the last equation, we solve it and work back up: back substitution.

A puzzle you already know how to solve

A coffee and a croissant cost €5. A coffee and two croissants cost €7. What does a croissant cost?

The second order has one more croissant and costs €2 more. So a croissant is €2 and the coffee is €3. You just subtracted one equation from the other, and the coffee disappeared. That is elimination.

The same idea, step by step

Take Strang's first system from slide 1: x − 2y = 1 and 3x + 2y = 11.

  • Equation 1 starts with 1x. That 1 is the pivot. It clears the x below.
  • Equation 2 has 3x, so we need 3 copies of equation 1. That 3 is the multiplier, ℓ = 3 ÷ 1 = 3.
  • Subtract 3 times equation 1 from equation 2. The x terms cancel.
(3x + 2y) − 3(x − 2y) = 11 − 3·1
8y = 8,  so y = 1
Back up to equation 1: x − 2·1 = 1,  so x = 3

Putting y = 1 back into equation 1 is called back substitution.

Why the answer does not change

Any (x, y) that solves both equations also solves "equation 2 minus 3 times equation 1". And adding 3 times equation 1 back undoes the step. So the new system has exactly the same solutions, just easier to read.

What it looks like

Run the lab code before and after the subtraction. The second line turns flat: y = 1. The first line stays put, and so does the crossing point (3, 1).

Where this is used

Circuit simulators and structural analysis tools solve equations this way, with thousands of unknowns instead of two.

Example 1 · Subtract twice the first equation

Solve 2x + y = 5 and 4x − y = 1.

Pivot 2, multiplier ℓ = 4 ÷ 2 = 2
(4x − y) − 2(2x + y) = 1 − 2·5  →  −3y = −9  →  y = 3
Back up: 2x + 3 = 5, so x = 1
Check: 4·1 − 3 = 1 ✓

Example 2 · A pivot of 1

Solve x + 3y = 7 and 2x + y = 4.

ℓ = 2 ÷ 1 = 2.   (2x + y) − 2(x + 3y) = 4 − 14  →  −5y = −10  →  y = 2
x + 6 = 7, so x = 1

A pivot of 1 is the friendliest case: the multiplier is just the entry below it.

Example 3 · A fractional multiplier

Solve 3x + 2y = 7 and x + 4y = 9.

ℓ = 1 ÷ 3 = 1/3
(x + 4y) − (1/3)(3x + 2y) = 9 − 7/3  →  (10/3) y = 20/3  →  y = 2
3x + 4 = 7, so x = 1

Fractions are fine. The rule never changes: multiplier = entry to remove ÷ pivot.
