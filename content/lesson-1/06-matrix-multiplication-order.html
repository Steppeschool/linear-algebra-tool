Do two motions in a row and you get a new matrix, the product AB. In AB, B acts first and A acts second, because (AB)v = A(Bv). AB = A b₁b₂ = Ab₁Ab₂
  1. AB means: apply B, then apply A. Read products from right to left.
  2. Column j of AB is A times column j of B.
  3. Usually AB ≠ BA. The order of the motions matters. When AB = BA we say A and B commute.
  4. Grouping does not matter: (AB)C = A(BC). And det(AB) = det(A)·det(B).

Socks and shoes

Socks then shoes is not the same as shoes then socks. Motions of the plane work the same way: shear then turn is not turn then shear.

In AB, the matrix next to the vector acts first: (AB)v = A(Bv). So read products from right to left, just as f(g(x)) applies g first.

How to compute AB

Where does (1, 0) end up? B sends it to b₁, the first column of B. Then A sends b₁ to Ab₁. So column 1 of AB is A times column 1 of B. Every column works the same way:

AB = A [ b₁   b₂ ] = [ Ab₁   Ab₂ ]

So AB is nothing new: it is matrix times vector, once for each column of B.

A worked example

R turns by 90°, and S is a shear:
R = 0−110   S = 1101
Column 1 of RS = R·(column 1 of S) = R(1, 0) = (0, 1).   Column 2 = R(1, 1) = 1·(0, 1) + 1·(−1, 0) = (−1, 1)
Column 1 of SR = S·(column 1 of R) = S(0, 1) = (1, 1).   Column 2 = S(−1, 0) = −1·(1, 0) = (−1, 0)
RS = 0−111   SR = 1−110
RS shears first and then turns. SR turns first and then shears. Different matrices, different motions. Watch where the F ends up in the lab. The picture draws a capital letter F on the graph paper: an F looks different when it is turned, slanted or flipped, so it shows each motion at a glance.

The rules

  • AB is usually not BA. Some pairs do commute, meaning AB = BA (two rotations, for example). Never assume it.
  • (AB)C = A(BC). Either way C acts first, then B, then A. The brackets only change how we write it.
  • det(AB) = det(A)·det(B). If B doubles every area and A triples it, together they multiply areas by 6.

Where this is used

A robot arm is a chain of joints, each one a rotation. Multiply their matrices in joint order to find the gripper. Swap two and the gripper lands somewhere else.

AB = 2201    BA = 2401

Stretch then shear differs from shear then stretch.

Example 2 · Two quarter turns

R = 0−110 turns by 90°.

RR = −100−1

Two quarter turns make a half turn. For rotations, multiplying adds the angles.

Example 3 · A pair that commutes

Two stretches: A = 2001, B = 1003.

AB = 2003 = BA

Stretching along x and stretching along y don't interfere, so the order doesn't matter here. A diagonal matrix has zeros everywhere except on the main diagonal (top left to bottom right). Diagonal matrices always commute with each other.
