By rows, each equation is a line, and we look for the crossing point. By columns, we look for the combination of columns that produces b. Both pictures give the same answer. 1-232 xy = 111
  1. Row picture: each equation is a line. The solution is where the lines meet.
  2. Column picture: the system says x·(column 1) + y·(column 2) = b. The solution gives the right weights.
  3. Both pictures describe the same x. They fail together too: parallel lines go with dependent columns.
  4. In higher dimensions the column picture stays easy to think about, so we lean on it.

One system, two readings

Take Strang's first example: x − 2y = 1 and 3x + 2y = 11. In matrix form it is Ax = b with

A = 1−232    b = (1, 11)

The row picture: two clues

Think of a navigator who takes two compass bearings. Each bearing says "the ship is somewhere on this line". The ship is at the point that lies on both lines.

Each equation is such a clue. All points (x, y) with x − 2y = 1 form one straight line. All points with 3x + 2y = 11 form another. The solution is the crossing point, (3, 1). You can check it in both equations: 3 − 2 = 1 and 9 + 2 = 11.

The column picture: a recipe

Now read the same system by columns, as on slide 2:

x·(1, 3) + y·(−2, 2) = (1, 11)
3·(1, 3) + 1·(−2, 2) = (3 − 2, 9 + 2) = (1, 11) ✓

Now the question is different: how much of each column do we need to produce b? The answer is the same pair, x = 3 and y = 1. Only the picture has changed.

When the pictures go wrong

  • Parallel lines: the clues never agree, so there is no solution. In the column picture the two columns are dependent, and b lies off their line.
  • The same line twice: the second clue adds nothing new, so there are infinitely many solutions. In the column picture b lies on the line of the columns.

Why the column picture wins later

With three unknowns each equation becomes a plane in space, and three planes meeting at a point is hard to draw. The column picture stays simple: three arrows, and one target to build from them.

When we actually solve by hand, though, we work with the rows. That is elimination, the subject of lesson 2.

Example 1 · One crossing

x + y = 3 and x − y = 1.

Rows: the lines cross at (2, 1)
Columns: 2·(1, 1) + 1·(1, −1) = (3, 1) = b ✓

Example 2 · The same line twice

x + 2y = 4 and 2x + 4y = 8.

Rows: the second equation is 2 × the first, so both are one line
Columns: (1, 2) and (2, 4) are dependent, and b = (4, 8) lies on their line

Infinitely many solutions, for example (4, 0) and (0, 2).

Example 3 · No crossing at all

x + y = 2 and 2x + 2y = 5.

Rows: the second line is x + y = 2.5, parallel to the first. They never meet
Columns: (1, 2) and (1, 2) are the same vector, and b = (2, 5) is not a multiple of (1, 2)

Both pictures agree: no solution.
