Now collect all of them. Each column of A is a kind of step you're allowed to take, say one step north-east and one step north-west. You can take as many of each as you like, forwards or backwards. The column space is every spot you can reach that way. If the two steps go in different directions, you can get anywhere. If they go the same way, you are stuck walking back and forth along one line. Ax = b has a solution exactly when b is a spot you can reach. C(A) = all vectors Ax = all combinations of the columns
  1. The column space C(A) contains every combination of the columns of A, that is, every vector Ax.
  2. Ax = b has a solution exactly when b is in C(A).
  3. In the plane, C(A) is the whole plane, a line through the origin, or just the origin.
  4. The rank measures the size of C(A): 2 for the whole plane, 1 for a line, 0 for the origin alone.

All the outputs at once

Let x be every possible vector and mark each Ax on the plane. All those points form the column space, C(A). Every Ax is a combination of the columns, hence the name.

A quick picture: two kinds of steps

Each column is one kind of step. x says how many of each to take (negative means walk backwards). Steps in different directions can take you anywhere: C(A) is the plane. Steps in the same direction only take you forward or back along one line: C(A) is a line.

Three possibilities in the plane

  • The whole plane: the columns point different ways. They are independent.
  • A line: one column is a multiple of the other. They are dependent.
  • Just the origin: both columns are zero.

The rank names the case: 2, 1 or 0.

A closer look at the dependent case

A = 1224. Column 2 is 2 times column 1.
Ax = x₁(1, 2) + x₂(2, 4) = (x₁ + 2x₂)·(1, 2)
Every output is a multiple of (1, 2). So b = (3, 6) is reachable, but b = (1, 0) is not.

Also, x = (3, 0) and x = (1, 1) both give (3, 6). With dependent columns, different inputs can give the same output. Lesson 4 gives this extra freedom a name: the nullspace.

Two questions that sound alike

  • Can we solve Ax = b for this one b? Yes, if b is in C(A).
  • Can we solve Ax = b for every b? Only if C(A) is the whole plane.

A 2 by 2 matrix has a quick test. Write A = pqrs, with columns (p, r) and (q, s). They are independent exactly when ps − qr ≠ 0. If ps − qr = 0, C(A) is only a line (or the origin). This number ps − qr is the determinant, det A. Slide 5 shows what it means as a motion of the plane.

A bigger example: columns in 3D

Take two columns with 3 numbers each. Mixing them gives

x₁·(1, 0, 1) + x₂·(0, 1, 1) = (x₁, x₂, x₁ + x₂)

The third number is always the first plus the second. So you can't reach all of space, only a flat sheet through the origin. b = (1, 2, 3) is on the sheet (take x = (1, 2)). b = (1, 2, 0) is not, so Ax = b has no solution for it.

Add a third column that sticks out of the sheet, like (0, 0, 1), and now you can reach every point in space. A third column that lies on the sheet, like (1, 1, 2), adds nothing new. The same holds in any size: the column space can be all of space, or a smaller flat piece of it.

Next: The column space tells us whether Ax = b has a solution. The next slide shows how to find it, by reading the same equations two ways.

Example 1 · A line, and who is on it

A = 2412. Column 2 = 2·column 1, so C(A) is the line through (2, 1).

b = (6, 3) = 3·(2, 1): in C(A), for example x = (3, 0)
b = (1, 1): not a multiple of (2, 1), so Ax = b has no solution

Example 2 · The whole plane

A = 111−1. Here p = 1, q = 1, r = 1, s = −1, so det A = ps − qr = 1·(−1) − 1·1 = −2. That is not 0, so C(A) is the whole plane. Solve Ax = (4, 2):

x₁ + x₂ = 4    x₁ − x₂ = 2
x₁ = 3, x₂ = 1

Example 3 · Is b in the column space?

A = 1326, b = (2, 5).

Column 2 = 3·column 1, so C(A) is the line of multiples of (1, 2)
Is (2, 5) a multiple of (1, 2)? It would need 2·(1, 2) = (2, 4), not (2, 5)

So b is not in C(A), and Ax = b has no solution. Changing b to (2, 4) would make it solvable.
