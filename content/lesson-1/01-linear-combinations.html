  1. A vector in the plane is a pair of numbers, v = (v₁, v₂): v₁ is the first number, v₂ the second. We draw it as an arrow from the origin.
  2. Two operations: multiply a vector by a number c, and add two vectors. Both work one part (component) at a time.
  3. Doing both gives a linear combination cv + dw.
  4. The big question: which vectors can we reach with all possible c and d?

This course follows Professor Gilbert Strang's book Introduction to Linear Algebra. The label above each slide, like §1.1, names the matching section of his book.

Why vectors at all?

A sensor reports two numbers: 2 metres east and 1 metre north. They belong together, so we keep them as one pair: v = (2, 1). That pair is a vector.

A vector is a column of numbers: 2 on top, 1 below, and that is how this site prints it. In a sentence or in the lab code it is often written across, (2, 1) or [2, 1], to save space. It is the same column.

To add two vectors, add first parts to first parts and second parts to second parts. They never mix:

v = (2, 1),   w = (−1, 1)  →  v + w = (2 + (−1), 1 + 1) = (1, 2)

On the plane, adding means walking: go along v, then along w from its tip. You end at the tip of v + w.

Multiplying by a number

To get 3v, multiply each part by 3: 3v = (6, 3). Same direction, three times as long. The 3 is called a scalar, because it only scales.

A negative number turns the arrow around: −v = (−2, −1). And 0·v is the zero vector (0, 0).

Putting both together

Pick numbers c and d and form cv + dw. With c = 3 and d = 2:

3v + 2w = (6, 3) + (−2, 2) = (4, 5)

That is a linear combination: "take 3 steps of v, then 2 steps of w".

The question behind everything

We ask this all course long: which vectors can we reach?

The multiples cv of one vector fill a line through the origin. That is where "linear" comes from. Two vectors that point different ways, like v and w, fill the whole plane.

The reverse is harder. Given a target like (4, 5), what are c and d? Write the combination out:

c(2, 1) + d(−1, 1) = (2c − d, c + d)

We need 2c − d = 4 and c + d = 5 at the same time. For two numbers, the school method works: c + d = 5 gives d = 5 − c. Put that into the first equation: 2c − (5 − c) = 4, so 3c = 9, c = 3 and d = 2. The examples below do the same. Lesson 2 gives a method that works for any number of unknowns.

A bigger example: 3 numbers

The pictures use 2 numbers because paper is flat. Real vectors often have more. A drone flies in 3D, so each of its moves has 3 numbers: (east, north, up).

v = (1, 0, 1),   w = (0, 2, 1)
3v + 2w = (3, 0, 3) + (0, 4, 2) = (3, 4, 5)

The rules don't change: stretch every part, then add part by part. With 4 numbers, 100 numbers, or a million (the pixels of a photo), it works the same way.

Example 1 · Compute a combination

v = (1, 1), w = (1, −1), c = 2, d = 3. Find cv + dw.

2v = (2, 2)    3w = (3, −3)
2v + 3w = (2 + 3, 2 − 3) = (5, −1)

Example 2 · Find the numbers

Write (3, 0) as c·(1, 1) + d·(1, −1).

c + d = 3    c − d = 0
Adding: 2c = 3, so c = 1.5 and d = 1.5
Check: 1.5·(1, 1) + 1.5·(1, −1) = (3, 0) ✓

Example 3 · When the plane is not filled

Take v = (1, 2) and w = (2, 4). Notice that w = 2v: both arrows lie on the same line.

cv + dw = c(1, 2) + 2d(1, 2) = (c + 2d)·(1, 2)

Every combination is a multiple of (1, 2), so the combinations only fill a line, not the plane. The target (1, 0) can never be reached.

Can combinations of (2, 4) and (−1, −2) ever reach (1, 0)?

Show solutionHide solution

No. (−1, −2) = −½·(2, 4), so both vectors lie on the line y = 2x. Every combination stays on that line, and (1, 0) is not on it.
