A nonzero x can solve that only if A − λI is singular, so its determinant must be zero. That gives an equation for λ alone. Solve it first, then find each eigenvector from a null space. det(A − λI) = 0    λ₁ + λ₂ = trace A    λ₁ · λ₂ = det A
  1. Ax = λx is the same as (A − λI)x = 0.
  2. A nonzero solution x exists only when A − λI is singular: det(A − λI) = 0. This is the characteristic equation.
  3. For 2 by 2 it is λ² − (trace)λ + det = 0, where the trace is the sum of the diagonal entries.
  4. For each λ, the eigenvectors are the nonzero vectors in the null space of A − λI.

Tuning until something gives

Picture turning a dial labelled λ. For most settings, A − λI is an ordinary invertible matrix: only x = 0 is sent to zero. At a few special settings the matrix suddenly becomes singular and a whole line of vectors is sent to zero. Those settings are the eigenvalues.

From Ax = λx to an equation for λ

Ax = λx
Ax − λx = 0
(A − λI)x = 0   (we write λI so that we subtract a matrix from a matrix)

If A − λI were invertible, the only solution would be x = 0. We want a nonzero x, so A − λI must be singular. Lesson 6 gives the test: its determinant is zero.

A worked example

A = 4123,   A − λI = 4 − λ123 − λ
det = (4 − λ)(3 − λ) − 2 = λ² − 7λ + 10
λ² − 7λ + 10 = (λ − 5)(λ − 2) = 0,   so λ = 5 or λ = 2

Then the eigenvectors

λ = 5:   A − 5I = −112−2.   Row 1 says −x₁ + x₂ = 0, so x = (1, 1)
λ = 2:   A − 2I = 2121.   Row 1 says 2x₁ + x₂ = 0, so x = (1, −2)
Check: A(1, −2) = (4 − 2, 2 − 6) = (2, −4) = 2·(1, −2) ✓

Two quick checks

For any 2 by 2 matrix the characteristic equation is λ² − (a + d)λ + (ad − bc) = 0. So the two eigenvalues always add up to the trace a + d, and multiply to the determinant. Here 5 + 2 = 7 = 4 + 3 and 5 · 2 = 10 = 12 − 2 ✓. Use these to catch mistakes.

Where this is used

Engineers check stability by finding eigenvalues. A control loop, a bridge or a filter has a matrix; its eigenvalues say whether disturbances die away or grow. Slide 4 shows how.

Example 1 · A triangular matrix

A = 1203.

det(A − λI) = (1 − λ)(3 − λ) − 0
λ = 1 and λ = 3: the diagonal entries

For triangular matrices the eigenvalues sit on the diagonal.

Example 2 · A symmetric matrix

A = 2332: trace 4, det 4 − 9 = −5.

λ² − 4λ − 5 = (λ − 5)(λ + 1) = 0
λ = 5 with x = (1, 1),   λ = −1 with x = (1, −1)

Example 3 · A singular matrix

A = 1224: det A = 0.

λ² − 5λ + 0 = λ(λ − 5) = 0
λ = 0: the null space direction (−2, 1) is squashed to zero
λ = 5: the direction (1, 2)

λ = 0 is an eigenvalue exactly when A is singular.

The eigenvalues of a 2 by 2 matrix are 3 and 4. What are its trace and determinant?

Show solutionHide solution

Trace = 3 + 4 = 7, det = 3 · 4 = 12.

import numpy as np A = np.array([[4., 1.], [2., 3.]]) tr = A[0, 0] + A[1, 1] # trace det = np.linalg.det(A) # lambda^2 - tr*lambda + det = 0, solved by the quadratic formula root = np.sqrt(tr * tr + 4 * det) # your turn: the sign under the root is wrong lam = np.array([(tr + root) / 2, (tr - root) / 2]) print("eigenvalues:", lam, " sum:", lam[0] + lam[1], " product:", lam[0] * lam[1]) table(("A", A), ("lambda", lam))
