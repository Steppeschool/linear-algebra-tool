All their eigenvalues are positive. Equivalently, the 'energy' xᵀAx is positive for every nonzero x, so its graph is a bowl with one lowest point. That is what makes minimisation problems well behaved. A positive definite ⇔ all λ > 0 ⇔ xᵀAx > 0 for all x ≠ 0
  1. A symmetric A is positive definite when all its eigenvalues are positive.
  2. Equivalent test: the energy xᵀAx > 0 for every nonzero x.
  3. For 2 by 2 [a b; b c]: a > 0 and ac − b² > 0. (Also: all pivots positive.)
  4. The graph of xᵀAx is a bowl. One negative eigenvalue turns it into a saddle.

A bowl or a saddle

Drop a marble into a salad bowl and it rolls to the single lowest point, from any side. Drop it on a horse saddle (or a curved crisp) and it rolls off: the surface goes up in one direction and down in another. Positive definite matrices are the bowls.

The energy xᵀAx

For A = [a b; b c] and x = (x₁, x₂), the number xᵀAx is a curved surface:

xᵀAx = a x₁² + 2b x₁x₂ + c x₂²
A = 2112:   2x₁² + 2x₁x₂ + 2x₂² = x₁² + x₂² + (x₁ + x₂)²
A sum of squares: positive unless x = 0. A bowl

The eigenvalue test

Write x in the perpendicular eigenvectors of A (slide 5): x = c₁q₁ + c₂q₂. Then xᵀAx = λ₁c₁² + λ₂c₂². If both λ are positive, this is positive for every nonzero x. If one λ is negative, moving along that eigenvector makes xᵀAx negative: a saddle.

A = 2112: λ = 3 and 1, both positive. Bowl
A = 2332: λ = 5 and −1. Saddle: x = (1, −1) gives xᵀAx = 2 − 6 + 2 = −2

Quick tests for 2 by 2

For [a b; b c]: positive definite exactly when a > 0 and the determinant ac − b² > 0. The determinant is λ₁λ₂, so a negative determinant means one eigenvalue is negative: a saddle. For [2 b; b 2], that happens when b² > 4.

Where this is used

Least squares (lesson 5) minimises a bowl: its matrix AᵀA is positive definite when the columns of A are independent, which is why the minimum is unique. Robot controllers and optimisers check that their "Hessian" matrix is positive definite before trusting a minimum. And a stiffness matrix being positive definite says a structure resists every push.

Example 1 · A diagonal bowl

A = 3001: xᵀAx = 3x₁² + x₂², positive for x ≠ 0. λ = 3 and 1.

Example 2 · The borderline case

A = 1111: λ = 2 and 0.

xᵀAx = (x₁ + x₂)², which is 0 along x = (1, −1)

A trough, not a bowl: positive semidefinite. There is a whole line of lowest points.

Example 3 · AᵀA is positive definite

xᵀ(AᵀA)x = (Ax)ᵀ(Ax) = ‖Ax‖² ≥ 0, and it is 0 only when Ax = 0.

If the columns of A are independent, Ax = 0 forces x = 0, so AᵀA is positive definite.
