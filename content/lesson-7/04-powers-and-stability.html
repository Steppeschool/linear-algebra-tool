Write the start as a mix of eigenvectors, and each part gets multiplied by its λ at every step. Parts with |λ| < 1 die out, |λ| > 1 grows, and λ = 1 survives unchanged. uₖ = c₁λ₁ᵏx₁ + c₂λ₂ᵏx₂    stable ⇔ every |λ| < 1
  1. Split u₀ = c₁x₁ + c₂x₂ into eigenvectors. Then uₖ = Aᵏu₀ = c₁λ₁ᵏx₁ + c₂λ₂ᵏx₂.
  2. |λ| < 1: that part shrinks to 0. |λ| > 1: it grows. λ = 1: it stays.
  3. A Markov matrix has nonnegative entries and columns adding to 1. It always has λ = 1.
  4. Its eigenvector for λ = 1, scaled to add to 1, is the steady state the system settles into.

Two cities, people moving every year

Each year 10% of the people in city 1 move to city 2, and 20% of city 2 moves to city 1. Everyone else stays. Track the fractions u = (city 1, city 2):

uₖ₊₁ = A uₖ,   A = 0.90.20.10.8
Column 1: of city 1's people, 0.9 stay and 0.1 leave. Column 2: of city 2's, 0.2 leave and 0.8 stay. Each column adds to 1: nobody is lost

Start with everyone in city 2, u₀ = (0, 1). Then u₁ = (0.2, 0.8), u₂ = (0.34, 0.66), u₃ ≈ (0.44, 0.56) … The fractions creep towards a fixed split. Why, and which split?

The eigenvalues explain it

trace = 1.7,   det = 0.72 − 0.02 = 0.7,   so λ² − 1.7λ + 0.7 = (λ − 1)(λ − 0.7) = 0
λ = 1:   A − I = −0.10.20.1−0.2 gives x₁ = (2, 1)
λ = 0.7:   x₂ = (1, −1)

Split the start into these two directions. At every step the x₁ part is multiplied by 1, so it stays. The x₂ part is multiplied by 0.7, so after k years it has shrunk by 0.7ᵏ: after 20 years less than 0.1% is left. What survives is the x₁ direction. Scaled so the fractions add to 1, that is the steady state s = (2/3, 1/3).

Check: As = (0.9·⅔ + 0.2·⅓, 0.1·⅔ + 0.8·⅓) = (⅔, ⅓) ✓. Two thirds end up in city 1, wherever everyone started.

Stability

The same reasoning answers a central engineering question. A system updated by uₖ₊₁ = Auₖ is stable (every disturbance dies out) exactly when every eigenvalue has |λ| < 1. One eigenvalue with |λ| > 1 and some disturbance grows without limit. For systems that change continuously, du/dt = Au, the solutions behave like e^(λt) and the rule becomes: every λ must be negative (Strang §6.3).

Where this is used

A Kalman filter, which fuses GPS and IMU readings on a drone, updates its error by a matrix every step. Designers check that the eigenvalues of that error matrix stay inside |λ| < 1, so errors shrink instead of piling up. Web search ranking (PageRank) is the steady state of a giant Markov matrix.

Example 1 · Growth and decay

A = 2000.5, u₀ = (1, 1).

u₁₀ = (2¹⁰, 0.5¹⁰) = (1024, 0.001)
The first part explodes, the second vanishes: unstable

Example 2 · A stable system

A = 0.50.20.20.5: λ = 0.7 with (1, 1) and λ = 0.3 with (1, −1).

Both |λ| < 1: every start shrinks to 0
After 10 steps the (1, 1) part is 0.7¹⁰ ≈ 0.03 of its size

A has eigenvalues 0.9 and 1.1. Is uₖ₊₁ = Auₖ stable? Explain.

Show solutionHide solution

No. The part along the eigenvector with λ = 1.1 grows like 1.1ᵏ. Unless the start has no part in that direction, uₖ blows up.

3

Why does every Markov matrix have λ = 1?

Show solutionHide solution

Each column of A adds to 1, so (1, 1, …, 1)A = (1, 1, …, 1): the all-ones row is a left eigenvector with λ = 1. A and Aᵀ have the same eigenvalues (same characteristic equation, since det(A − λI) = det(Aᵀ − λI)), so A has λ = 1 too.

import numpy as np A = np.array([[0.9, 0.2], [0.1, 0.8]]) # each year: 10% of city 1 leave, 20% of city 2 leave u0 = np.array([0., 1.]) # everyone starts in city 2 u1 = A @ u0 u2 = A @ u1 steady = np.array([0.5, 0.5]) # your turn: the eigenvector for lambda = 1 is (2, 1); # scale it so the entries add to 1 print("A @ steady =", A @ steady, " (a steady state is unchanged by A)") arrows(("u0", u0), ("u1", u1), ("u2", u2), ("steady", steady))
