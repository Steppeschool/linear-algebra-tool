Strang §2.5 · Inverse of a product

Undo in reverse order.

AB means: B first, then A. To undo both moves we must undo the last one first, so the inverse of AB is B⁻¹A⁻¹, with the order reversed.

Lesson 3 · slide 3Inverse of AB
(AB)⁻¹ = B⁻¹A⁻¹     (ABC)⁻¹ = C⁻¹B⁻¹A⁻¹
Key ideas
  1. (AB)⁻¹ = B⁻¹A⁻¹. The order reverses.
  2. For three matrices: (ABC)⁻¹ = C⁻¹B⁻¹A⁻¹.
  3. The algebra check: B⁻¹A⁻¹AB = B⁻¹IB = I.
  4. The same reversal happens for transposes: (AB)ᵀ = BᵀAᵀ (ᵀ, the transpose, comes on slide 5).

Think of taking off socks and shoes

In the morning you put on socks, then shoes. In the evening you take off the shoes first, then the socks. Same two steps, opposite order.

A product of matrices reads from right to left, so AB puts on B first and A second. A went on last, so it must come off first. So A⁻¹ must act first, and the first step goes on the right: B⁻¹A⁻¹. Read it right to left: A⁻¹, then B⁻¹.

Check it with algebra

(B⁻¹A⁻¹)(AB) = B⁻¹(A⁻¹A)B = B⁻¹ I B = B⁻¹B = I ✓

A and A⁻¹ meet in the middle and cancel, then B and B⁻¹ cancel. With the other order, A⁻¹B⁻¹AB, nothing meets its own inverse, and in general the result is not I.

A worked example

R turns by 90°, S is a shear. From lesson 1, RS = 0−111
R⁻¹ = 01−10 (turn back)   S⁻¹ = 1−101 (slide back)
S⁻¹R⁻¹ = 11−10   but   R⁻¹S⁻¹ = 01−11
Only S⁻¹R⁻¹ undoes RS. In the lab, follow v = (1, 1) through S and R, then try both orders on the way back.

Where this is used

A robot arm's pose is a product of joint matrices, T₁T₂⋯Tₙ, which converts a point measured from the gripper into the same point measured from the base. (Each part of the arm has its own set of axes, called its frame.) To convert the other way, from base measurements to gripper measurements, we need the inverse, Tₙ⁻¹⋯T₁⁻¹, with the joints in reverse order.

Worked examples

Example 1 · Shear then stretch, undone

A = 2001, B = 1101.

(AB)⁻¹ = B⁻¹A⁻¹ = 1−101½001 = ½−101
Check: AB = 2201, whose inverse is ½·1−202 ✓

Example 2 · Powers

If A is invertible, so is A²:

(A²)⁻¹ = (AA)⁻¹ = A⁻¹A⁻¹ = (A⁻¹)²
(A⁻¹)⁻¹ = A: undoing the undo gets you back

Example 3 · Three steps

For three invertible matrices:

(ABC)⁻¹ = C⁻¹B⁻¹A⁻¹

C acted first, so it is undone last.

Worked examples

Example 1 · A 2 by 2 inverse

Find the inverse of A = 4726.

det A = 4·6 − 7·2 = 10
A⁻¹ = 1/10 · 6−7−24
Check, top-left entry of AA⁻¹: (4·6 + 7·(−2)) / 10 = 1 ✓

Example 2 · Gauss-Jordan step by step

Invert A = 1237 by elimination on [A | I].

[1 2 | 1 0; 3 7 | 0 1]  → row 2 − 3·row 1 →  [1 2 | 1 0; 0 1 | −3 1]
row 1 − 2·row 2 →  [1 0 | 7 −2; 0 1 | −3 1]
A⁻¹ = 7−2−31

det A = 1, so the formula gives the same answer with no fractions.

Example 3 · The transpose of a product

Check (AB)ᵀ = BᵀAᵀ for A = 1201 and B = 1031.

AB = 7231, so (AB)ᵀ = 7321
BᵀAᵀ = 13011021 = 7321 ✓

AᵀBᵀ would be 1327: the wrong order gives a different matrix.

Problems

1

Find the inverse of 3152.

Show solutionHide solution

det = 3·2 − 1·5 = 1, so A⁻¹ = 2−1−53.

Check: row 1 of A times column 1 of A⁻¹ = 3·2 + 1·(−5) = 1 ✓

2

For which k is 2k46 not invertible?

Show solutionHide solution

det = 12 − 4k = 0 when k = 3. Then column 2 = (3, 6) = 1.5·column 1, and the plane is squashed onto a line.

3

A = 1101, B = 2003. Find (AB)⁻¹ as B⁻¹A⁻¹.

Show solutionHide solution

B⁻¹ = ½00⅓ and A⁻¹ = 1−101.

B⁻¹A⁻¹ = ½−½0⅓. Check: AB = 2303 and its inverse from the formula, 1/6·3−302, is the same ✓

4

Compute AᵀA for A = 102103. Is it symmetric?

Show solutionHide solution

AᵀA = 52210. Entry (1, 1) = 1 + 4 + 0, entry (1, 2) = 0 + 2 + 0, entry (2, 2) = 0 + 1 + 9.

Yes, it is symmetric, as AᵀA always is.

5

Find the permutation P that puts the rows of a 3 by 3 matrix in the order 2, 3, 1. What is P⁻¹?

Show solutionHide solution

The rows of P are rows 2, 3, 1 of I: P = 010001100.

P⁻¹ = Pᵀ = 001100010, which puts the rows back.
