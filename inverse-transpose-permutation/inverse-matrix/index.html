Strang §2.5 · Inverse matrices

The inverse undoes A.

The inverse of A undoes A. Apply A, then A⁻¹, and every vector is back where it started. If the inverse exists, it solves Ax = b in one step: x = A⁻¹b.

Lesson 3 · slide 1The inverse
A⁻¹A = I     Ax = b  ⇔  x = A⁻¹b
Key ideas
  1. A⁻¹A = I and AA⁻¹ = I, where I is the identity matrix.
  2. If A is invertible, Ax = b has exactly one solution, x = A⁻¹b.
  3. A matrix that sends two different vectors to the same output cannot be undone.
  4. An n by n matrix A is invertible ⇔ it has n nonzero pivots ⇔ its columns are independent ⇔ det A ≠ 0.

Play the motion backwards

In lesson 1, a matrix moved the plane: it stretched, turned or slanted the graph paper. The inverse plays that motion backwards. Do A, then A⁻¹, and nothing has moved.

"Nothing has moved" is the identity matrix I. It has 1s on the diagonal and 0s elsewhere. Ix = x for every vector x.

Why the inverse solves equations

Start with Ax = b. Multiply both sides on the left by A⁻¹. Since A⁻¹A = I, the left side is just x. So x = A⁻¹b. If the inverse exists, that is the one and only solution.

Example: undoing a shear

The shear S = 1101 slides each point to the right by its height.
To undo it, slide each point back to the left by the same amount: S⁻¹ = 1−101
S⁻¹S = 1−1011101 = 1001 ✓

In the lab, follow v = 12. S moves it to 32. Your S⁻¹ should bring it back.

When there is no inverse

Some matrices can't be undone. Here is one. Its second column is just twice the first:

A = 1224

Feed it two different inputs:

A·20 = 24    A·01 = 24

Different inputs, same output. If all you see is 24, you can't tell which input made it. So nothing can undo A. A has no inverse.

For a square matrix, each of these says the same thing: A can be undone.

  • Every pivot is nonzero (lesson 2).
  • No column is a combination of the others (lesson 1).
  • det A ≠ 0 (the determinants lesson).
  • Ax = 0 only when x = 0.
