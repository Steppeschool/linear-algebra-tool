Strang §3.3 · The complete solution to Ax = b

Solving Ax = b completely: one solution plus the nullspace

Slide 3 found every input that does nothing. Now the right side is a real target b. Think of walking to the bakery. You know one route that gets you there. Before you leave, add any stroll that brings you back to your own door, and you still end up at the bakery. Those strolls are the nullspace vectors. So once you have one solution, the particular solution x_p, every solution is x_p plus a nullspace vector. That is the complete solution. And if the bakery can't be reached at all, because b is not in the column space, there is no solution.

Lesson 4 · slide 4Complete solution
x = x_p + x_n     Ax_p = b,   Ax_n = 0
Key ideas
  1. If Ax_p = b, then every solution is x = x_p + x_n with x_n in N(A).
  2. Ax = b is solvable exactly when b is in the column space C(A).
  3. To find x_p, eliminate on [A | b], set all free variables to 0 and read off the pivot variables.
  4. The rank r tells you whether there are 0, 1 or infinitely many solutions.

One route plus a loop

Take A = 1224 from slide 2 and b = 48. One solution is easy to see: x_p = 40, four of column 1. Now add the nullspace vector −21:

x = 40 + −21 = 21  →  Ax = 2 + 24 + 4 = 48 ✓

Add it twice and you get 02, another solution: two of column 2.

Why every solution has this form

  • Adding a nullspace vector keeps a solution: A(x_p + x_n) = Ax_p + Ax_n = b + 0 = b.
  • Any two solutions differ by a nullspace vector: if Ax = b and Ay = b, then A(x − y) = b − b = 0. Check: 02 − 40 = −42 = 2·−21 ✓

So the solutions form a line parallel to N(A), shifted to pass through x_p. In the row picture from lesson 2 you can see that line directly:

The nullspace is the parallel line x + 2y = 0 through the origin. Slide the nullspace over by x_p and you get the solution line.

How to find x_p

Write b as an extra column after A, with a bar between them: [A | b]. This is the augmented matrix from lesson 2. Row operations act on whole rows, so they change the b column too.

1. Eliminate on [A | b] until the part before the bar is R.
2. A row of zeros before the bar with a nonzero number after it says 0 = that number. Then there is no solution.
3. Otherwise set every free variable to 0. Each nonzero row now says: its pivot variable = the number after the bar. That is x_p.

For our A and b = 48: row 2 − 2·row 1 turns 24|8 into 00|0, leaving 12|4. The free variable is x₂. Set x₂ = 0, then x₁ = 4, so x_p = 40. With N(A) = all c·−21:

x = 40 + c·−21 = 4 − 2cc
c = 2: x = 02. Check: 0 + 2·2 = 4 and 0 + 4·2 = 8 ✓

When there is no solution

Change b to 412. Row 2 − 2·row 1 gives 0 = 12 − 2·4 = 4. Impossible. b = 412 is not a multiple of 12, so it is off the column space line.
