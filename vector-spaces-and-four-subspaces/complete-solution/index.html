Strang §3.3 · The complete solution to Ax = b

Every solution = one particular solution + the nullspace.

When Ax = b has a solution, it usually has many. All of them have the same form: one particular solution plus any vector from the nullspace.

Lesson 4 · slide 4Complete solution
x = x_p + x_n     Ax_p = b,   Ax_n = 0
Key ideas
  1. If Ax_p = b, then every solution is x = x_p + x_n with x_n in N(A).
  2. Ax = b is solvable exactly when b is in the column space C(A).
  3. To find x_p, eliminate on [A | b], set all free variables to 0 and read off the pivot variables.

Think of a route plus a loop

You know one route that reaches your destination. Add any loop that brings you back to where you started, and you still reach the destination. The loops are the nullspace.

With the boat: one throttle setting produces the motion you want. Add any cancelling combination such as (2, −1), and the boat moves exactly the same.

Why every solution has this form

  • Adding a nullspace vector keeps a solution: A(x_p + x_n) = Ax_p + Ax_n = b + 0 = b.
  • Any two solutions differ by a nullspace vector: if Ax = b and Ay = b, then A(x − y) = b − b = 0.

In the plot, the solutions form a line parallel to N(A), shifted so that it passes through x_p.

How to find x_p

Write b as an extra column next to A, with a bar between them: [A | b]. This is the augmented matrix. The column after the bar holds the right-hand sides. A row operation acts on a whole row, so it changes that column too.

1. Eliminate on [A | b] until the part before the bar is R.
2. A row of zeros before the bar with a nonzero number after it says 0 = that number. Then there is no solution.
3. Otherwise set every free variable to 0. Each nonzero row now says: its pivot variable = the number after the bar. That is x_p.
