Strang §3.2 · Solving Ax = 0 and Rx = 0

Free columns are yours to choose. Pivot columns follow.

To find the whole nullspace, reduce A to its reduced row echelon form R. A variable whose column has a pivot is a pivot variable; the others are free. Setting one free variable to 1 and the rest to 0 gives a special solution, and every nullspace vector is a combination of these.

12132438  →  R = 12010012
Key ideas
  1. Elimination does not change the nullspace: Ax = 0 and Rx = 0 have the same solutions. Row operations combine equations whose right-hand sides are all 0, so the right side stays 0.
  2. A variable whose column has a pivot is a pivot variable. The others are free variables.
  3. Each free variable gives one special solution.
  4. The rank r of A is the number of pivots.
  5. An m by n matrix of rank r has n − r special solutions, and every vector in N(A) is a combination of them.

Think of a mixing desk

A mixing desk has four sliders. Two of them are free: you set them however you like. The other two are linked and move on their own to keep the total output at zero.

Free variables are the free sliders, and pivot variables are the linked ones. Each setting of the free sliders gives exactly one vector in the nullspace.

Reading R

R is the reduced row echelon form: each pivot is 1, and the pivot columns have zeros everywhere else. For our matrix it takes two row operations:

A = 12132438
row 2 − 2·row 1:  (2, 4, 3, 8) − (2, 4, 2, 6) = (0, 0, 1, 2)  →  12130012
row 1 − row 2:  (1, 2, 1, 3) − (0, 0, 1, 2) = (1, 2, 0, 1)  →  R = 12010012
The second step clears the entry above the pivot in column 3. Both pivots are now 1, with zeros above and below them.

Why is this allowed? Each row operation adds a multiple of one equation to another. When every right-hand side is 0, the new right side is still 0, so no solution is gained or lost. Multiplying a row by a nonzero number is also allowed: 0 times that number stays 0.

The pivots are in columns 1 and 3, so x₁ and x₃ are pivot variables, and x₂ and x₄ are free. Rx = 0 reads:

x₁ + 2x₂ + x₄ = 0    and    x₃ + 2x₄ = 0

The special solutions

Set x₂ = 1, x₄ = 0.
Second equation: x₃ + 2·0 = 0, so x₃ = 0
First equation: x₁ + 2·1 + 0 = 0, so x₁ = −2  →  s₁ = (−2, 1, 0, 0)
Check with A: 1·(−2) + 2·1 = 0 and 2·(−2) + 4·1 = 0 ✓
The second special solution comes from x₂ = 0, x₄ = 1. That is your exercise.
