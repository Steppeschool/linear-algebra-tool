Strang §3.2 · The nullspace of A

The nullspace: inputs that do nothing.

The nullspace N(A) contains every vector x with Ax = 0. These are the inputs that produce no output at all. It tells us whether solutions are unique.

Lesson 4 · slide 2Nullspace
N(A) = all x with Ax = 0
Key ideas
  1. N(A) = all solutions of Ax = 0. It always contains x = 0.
  2. N(A) is a subspace: if Ax = 0 and Ay = 0, then A(cx + dy) = 0.
  3. If A is invertible, N(A) contains only 0.
  4. A nonzero x in N(A) describes a dependency between the columns.

Think of engines running and a boat standing still

Back to the boat with two thrusters pointing the same way, thruster 2 twice as strong: A = 1224.

Run thruster 1 forward at 2 and thruster 2 in reverse at 1. The two pushes cancel exactly: both engines are working, and the boat does not move. The throttle setting x = (2, −1) is in the nullspace, because Ax = 0.

Why the nullspace is a subspace

If Ax = 0 and Ay = 0, then A(x + y) = Ax + Ay = 0 and A(cx) = cAx = 0. So sums and multiples of nullspace vectors stay in the nullspace. In the example, every multiple c·(2, −1) is also a cancelling setting, and N(A) is a whole line.

A line through 0 can be named by any of its nonzero vectors. All multiples of (2, −1) and all multiples of (−2, 1) are the same line, and later slides use (−2, 1).

What a nullspace vector tells us

Ax = 0 says x₁·(column 1) + x₂·(column 2) = 0. So a nonzero vector in N(A) is a recipe for combining the columns into zero, which means the columns are dependent. Here: 2·(1, 2) − 1·(2, 4) = (0, 0).

If A is invertible, the only solution of Ax = 0 is x = A⁻¹0 = 0, so the nullspace is just the zero vector.
