Strang §3.2 · The nullspace of A

The nullspace: finding the inputs that give zero

Slide 1 showed that the column space, the set of all outputs, is a subspace. Now turn to the inputs. Suppose your two kinds of steps are a short step and a double step in the same direction. Take two short steps forward and one double step back, and you are right where you started. Your feet moved, but you went nowhere. Inputs like that, with Ax = 0, are the inputs that do nothing, and all of them together form the nullspace N(A). Standing still, x = 0, is always one of them. If there are others, then two different inputs can give the same output, and whenever Ax = b has a solution, it has many.

Lesson 4 · slide 2Nullspace
N(A) = all x with Ax = 0
Key ideas
  1. N(A) = all solutions of Ax = 0. It always contains x = 0.
  2. N(A) is a subspace: if Ax = 0 and Ay = 0, then A(cx + dy) = 0.
  3. If A is invertible, N(A) contains only 0.
  4. A nonzero x in N(A) is a recipe that mixes the columns into zero, so the columns are dependent: one is a combination of the others (slide 5 says more).

An input that gives zero

Take a matrix whose second column is twice the first: A = 1224.

Try the input x = 2−1: two of column 1, minus one of column 2.

2·12 − 1·24 = 2 − 24 − 4 = 00

The two columns cancel exactly. So 2−1 is in the nullspace.

You can also check it row by row, the way lesson 1 taught Ax. Each row of A, dotted with x, must give 0:

row 1: 1·2 + 2·(−1) = 0    row 2: 2·2 + 4·(−1) = 0 ✓

The nullspace is a subspace

If Ax = 0 and Ay = 0, then A(x + y) = Ax + Ay = 0 + 0 = 0, and A(cx) = c·Ax = 0. Sums and multiples stay in. So every multiple c·2−1 also gives zero. For example, c = 3:

A6−3 = (1·6 + 2·(−3), 2·6 + 4·(−3)) = 00 ✓

Here N(A) is a whole line through the origin, and nothing else: Ax = 0 says x₁ + 2x₂ = 0 (row 2 says the same thing, times 2), which is exactly this line. Any nonzero vector on a line can name it: multiples of 2−1 and multiples of −21 are the same line. Later slides use −21.

Look at the row 12 of A. Its dot product with 2−1 is 0, and lesson 1 said that means a right angle. So the nullspace line is perpendicular to the row. Slide 6 shows that this always happens.

What a nullspace vector tells us

Ax = 0 says x₁·(column 1) + x₂·(column 2) = 0. So a nonzero x in N(A) is a recipe that mixes the columns into zero. That means the columns are dependent: one is a combination of the others (slide 5 says more). Here 2·12 − 1·24 = 0 tells us column 2 = 2·column 1.

When only zero gets through

If A is invertible (lesson 3), multiply Ax = 0 by A⁻¹: x = A⁻¹0 = 0. The nullspace is just the zero vector. For a 2×2 matrix, ad − bc ≠ 0 tells us that.

A = 2111:   ad − bc = 2 − 1 = 1 ≠ 0, so N(A) = {0}

Then every output comes from exactly one input. A nullspace with more than 0 in it means some different inputs share an output: A40 and A21 are both 48 for our first matrix, because 40 − 21 = 2−1 is in N(A).
