Strang §3.4 · Independence, basis and dimension

A basis: enough vectors, and not one too many.

Vectors are independent when none of them is a combination of the others. An independent set that reaches the whole space is a basis, and every basis of a space has the same number of vectors: the dimension.

Lesson 4 · slide 5Basis and dimension
independent + spans the space = basis    size of every basis = dimension
Key ideas
  1. Independent: the only combination giving 0 is the one with all coefficients 0.
  2. Span: all combinations of the vectors.
  3. Basis: independent vectors that span the space.
  4. Dimension: the number of vectors in any basis. The rank r is the dimension of C(A).

Think of a minimal toolkit

A good toolkit lets you do every job, and contains no tool that another tool already covers. "Every job can be done" is the vectors spanning the space: every vector in it is some combination of them. "No redundant tool" is the vectors being independent. Both together make a basis.

The dimension is how many tools that takes. A point on a map needs exactly two numbers, and a drone in the air needs three. That count does not depend on which directions we choose.

Testing for independence

Put the vectors in the columns of A. These statements all mean the same thing:

  • The only solution of Ax = 0 is x = 0.
  • N(A) contains only the zero vector.
  • Every column has a pivot, so the rank is r = n.

We write ℝⁿ for all vectors with n components: ℝ² is the plane and ℝ³ is 3D space.

Four vectors in ℝ³ are always dependent. Put them in the columns of a 3 by 4 matrix. Each pivot needs its own row, so there are at most 3 pivots for 4 columns. At least one column is free, and its special solution is a nonzero x with Ax = 0.

A worked example

v₁ = (1, 0, 1), v₂ = (0, 1, 1), v₃ = (1, 1, 2).
v₃ = v₁ + v₂,  so 1·v₁ + 1·v₂ − 1·v₃ = 0
The vectors are dependent and the rank is 2. All three lie in one plane, and v₁, v₂ alone form a basis for that plane. Its dimension is 2.

A basis is not unique

(1, 0) and (0, 1) form a basis of the plane, and so do (1, 1) and (1, −1). The vectors differ, but there are always two of them. In general, the pivot columns of A form a basis of its column space, and their number is the rank.

Worked examples

Example 1 · A basis of the plane

(1, 0) and (1, 1).

Not multiples of each other: independent. Two independent vectors in 2D span the plane

A basis.

Example 2 · Too many vectors

(1, 2), (2, 4) and (0, 1) in the plane.

(2, 4) = 2·(1, 2): dependent
Keep (1, 2) and (0, 1): a basis of the plane

Three vectors in 2D are always dependent.

Example 3 · Triangular columns

The columns of 101011001.

Upper triangular with nonzero pivots: rank 3
The columns are a basis for 3D space

Are (1, 1, 0), (0, 1, 1), (1, 0, 1) independent?

Worked examples

Example 1 · Is it a subspace?

Is the set of all (x, y, z) with x = 2y a subspace of 3D space?

Zero: (0, 0, 0) has 0 = 2·0 ✓
Add: if x₁ = 2y₁ and x₂ = 2y₂, then x₁ + x₂ = 2(y₁ + y₂) ✓
Scale: cx₁ = 2(cy₁) ✓

Yes. It is a plane through the origin. With x = 2y + 1 it would fail at once: the origin is missing.

Example 2 · Nullspace and special solutions

Find the nullspace of A = 123246.

Row 2 − 2·row 1 = 0, so R = 123000. One pivot (column 1), rank 1.
Free: x₂, x₃.   x₂ = 1, x₃ = 0 gives (−2, 1, 0).   x₂ = 0, x₃ = 1 gives (−3, 0, 1).

N(A) is all combinations c·(−2, 1, 0) + d·(−3, 0, 1): a plane, dimension n − r = 3 − 1 = 2.

Example 3 · The complete solution

Solve x + 2y + 3z = 6.

Particular solution: set the free variables y = z = 0, then x = 6. x_p = (6, 0, 0)
Nullspace: A = [1 2 3], the first row of Example 2's matrix, with special solutions (−2, 1, 0) and (−3, 0, 1)
x = (6, 0, 0) + c·(−2, 1, 0) + d·(−3, 0, 1)

Geometrically: a plane parallel to the nullspace, shifted to pass through (6, 0, 0).

Problems

1

Which of these are subspaces of the plane? (a) all (x, y) with x = y (b) all (x, y) with x + y = 1 (c) all (x, y) with xy = 0.

Show solutionHide solution

(a) Yes: a line through the origin.

(b) No: (0, 0) is not on it.

(c) No: it is the two axes together, and (1, 0) + (0, 1) = (1, 1) has xy = 1.

2

Find the nullspace of 1−12−2.

Show solutionHide solution

Both rows say x − y = 0. So N(A) is every multiple of (1, 1): a line.

Check: A(1, 1) = (1 − 1, 2 − 2) = (0, 0) ✓

3

Find R, the rank and a special solution for A = 121243364.

Show solutionHide solution

Row 2 − 2·row 1 = (0, 0, 1), row 3 − 3·row 1 = (0, 0, 1), then row 3 − row 2 = 0. Clearing above the pivot: R = 120001000.

Pivots in columns 1 and 3, so rank 2. Column 2 is free: x₂ = 1 gives the special solution (−2, 1, 0).

4

Are (1, 2, 0), (0, 1, 1) and (1, 3, 1) independent?

Show solutionHide solution

No. (1, 3, 1) = (1, 2, 0) + (0, 1, 1), so 1·v₁ + 1·v₂ − 1·v₃ = 0. The rank is 2 and the three vectors lie in one plane.

5

A is 3 by 5 with rank 2. Give the dimension of each of the four subspaces.

Show solutionHide solution

m = 3, n = 5, r = 2.

Row space r = 2, nullspace n − r = 3, column space r = 2, left nullspace m − r = 1.
