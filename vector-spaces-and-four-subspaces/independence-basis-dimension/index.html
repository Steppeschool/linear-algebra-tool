Strang §3.4 · Independence, basis and dimension

A basis: enough vectors, and not one too many.

Vectors are independent when none of them is a combination of the others. Independent vectors that reach the whole space form a basis. Every basis of a space has the same number of vectors: the dimension.

independent + spans the space = basis    size of every basis = dimension
Key ideas
  1. Independent: the only combination giving 0 is the one with all coefficients 0.
  2. Span: all combinations of the vectors.
  3. Basis: independent vectors that span the space.
  4. Dimension: the number of vectors in any basis. The rank r is the dimension of C(A).

Think of a minimal toolkit

A good toolkit can do every job, and has no tool that another tool already covers. "Every job" means the vectors span the space: every vector in it is a combination of them. "No extra tool" means they are independent. Both together make a basis.

The dimension is how many tools that takes. A point on a map needs two numbers. A drone in the air needs three. That count is the same whichever directions you choose.

Two ways to say independent

"No vector is a combination of the others" and "only the all-zero combination gives 0" mean the same thing. If v₃ = v₁ + v₂, then v₁ + v₂ − v₃ = 0: a combination with nonzero coefficients. The other way round: if a combination with a nonzero coefficient gives 0, solve it for that vector. It is a combination of the others.

Testing for independence

Put the vectors in the columns of A. These all say the same thing:

  • The only solution of Ax = 0 is x = 0.
  • N(A) contains only the zero vector.
  • Every column has a pivot, so the rank is r = n, the number of vectors.

ℝⁿ means all vectors with n components. ℝ² is the plane and ℝ³ is 3D space.

Four vectors in ℝ³ are always dependent. Put them in a 3 by 4 matrix. Each pivot needs its own row, so there are at most 3 pivots for 4 columns. At least one column is free, and its special solution is a nonzero x with Ax = 0.
