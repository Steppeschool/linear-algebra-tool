Strang §3.5 · Dimensions of the four subspaces

The four fundamental subspaces and their sizes

Slide 5 gave every subspace a size, its dimension. Now we collect all the subspaces one matrix carries. Picture the sun straight overhead: every object casts a shadow on the floor. Object to shadow is like A taking an input x to an output Ax. Lift the object straight up and its shadow doesn't move: that direction does nothing, like the nullspace. Slide it along the floor and the shadow slides too: those floor directions are the row space. Every place a shadow can fall is the column space. The fourth one, the left nullspace, holds the output directions at right angles to every possible output, that is, to the whole column space. (Lesson 5 studies shadows like this.) The rank r sets the size of all four.

Lesson 4 · slide 6Four subspaces
inputs (ℝⁿ):  row space r + nullspace n − r   |   outputs (ℝᵐ):  column space r + left nullspace m − r
Key ideas
  1. Inputs (ℝⁿ, all vectors with n components): the row space C(Aᵀ) (all combinations of the rows), dimension r, and the nullspace N(A), dimension n − r.
  2. Outputs (ℝᵐ): the column space C(A), dimension r, and the left nullspace N(Aᵀ) (all y with Aᵀy = 0), dimension m − r.
  3. The row space and the column space always have the same dimension, r.
  4. The row space is perpendicular to the nullspace.

The two new subspaces

You know the column space C(A) and the nullspace N(A). Two more come from the transpose Aᵀ (lesson 3), which turns rows into columns:

  • The row space is all combinations of the rows of A. The rows of A are the columns of Aᵀ, so we write it C(Aᵀ).
  • The left nullspace N(Aᵀ) is all y with Aᵀy = 0. Transpose both sides (lesson 3): (Aᵀy)ᵀ = yᵀ(Aᵀ)ᵀ = yᵀA, so it is the same as yᵀA = 0: y multiplies A from the left, and mixes the rows of A into zero.

The shadow as a matrix

The shadow is A = 100010: it keeps x and y and drops the height z. A215 = 21.

  • Nullspace: A00z = 00, so it is the up-down line, all multiples of 001.
  • Row space: combinations of 100 and 010: a flat floor inside the 3D input space (vectors with 3 numbers).
  • Column space: every xy: all of ℝ², a separate 2D picture of the outputs.
  • Left nullspace: only 0. The column space is all of ℝ², so no nonzero direction is at right angles to all of it. It grows when the column space is smaller than the output space, as in the examples below.

The row space is perpendicular to the nullspace

Ax = 0 says each row of A, dotted with x, gives 0. Lesson 1 said a dot product of 0 means a right angle. So x is perpendicular to every row, and to every combination of rows: the whole row space. In the shadow: 001·100 = 0 and 001·010 = 0.

A 2×2 example: A = 1236. Both rows lie on the line through 12. The nullspace is the line through −21, and 12·−21 = −2 + 2 = 0.

The same argument on Aᵀ shows the left nullspace is perpendicular to the column space. Lesson 5 builds on this.

The dimensions

For an m by n matrix of rank r:

row space: r  +  nullspace: n − r  =  n
column space: r  +  left nullspace: m − r  =  m

The shadow: m = 2, n = 3, r = 2. Row space 2 + nullspace 1 = 3, and column space 2 + left nullspace 0 = 2 ✓.

The row space and column space always have the same dimension, even though they live in different spaces. The reason: both are counted by the pivots. Row steps only mix rows, so they never change the row space: the nonzero rows of R span the same row space as A. They are also independent, since each has a 1 where the others have 0. So the pivot rows of R are a basis of the row space. Careful: for the row space we take rows from R, but for the column space we take the pivot columns from A, because row steps do change the columns. Strang calls these four dimensions Part 1 of the Fundamental Theorem of Linear Algebra.
