Strang §7.2 · The pieces of the SVD

A is a sum of simple pieces, biggest first.

Multiply out UΣVᵀ column by column and A falls apart into r simple pieces σᵢuᵢvᵢᵀ, one for each nonzero singular value. Each piece is a rank-one matrix: every row is a multiple of the same row. The pieces come ordered by size, which is the key to compression.

Lesson 8 · slide 3Rank-one pieces
A = σ₁u₁v₁ᵀ + σ₂u₂v₂ᵀ + … + σᵣuᵣvᵣᵀ
Key ideas
  1. UΣVᵀ = σ₁u₁v₁ᵀ + … + σᵣuᵣvᵣᵀ, where r is the rank (the number of nonzero σ's).
  2. Each uvᵀ is a rank-one matrix: a column times a row. All its rows are multiples of vᵀ.
  3. The pieces are ordered: σ₁ ≥ σ₂ ≥ …, so the first pieces carry the most.
  4. Keeping only the first k pieces gives the best rank-k approximation of A: the closest matrix of rank k (slide 4).

A song as layers

A recorded song can be split into tracks: drums, bass, vocals, some quiet background sounds. Mute the quiet tracks and the song is still recognisable. The SVD splits a matrix into layers in the same way, and lists them from loudest to quietest.

Column times row

A column u times a row vᵀ is a whole matrix, uvᵀ, called an outer product. Every row of uvᵀ is a multiple of vᵀ, so it has rank 1: the simplest matrix there is.

u = (1, 2), v = (3, 1):   uvᵀ = 3162.   Row 2 = 2 × row 1

The SVD as a sum

Multiply U times ΣVᵀ as a sum of columns times rows: column i of U times row i of ΣVᵀ. Row i of ΣVᵀ is σᵢvᵢᵀ, so each term is σᵢuᵢvᵢᵀ:

A = UΣVᵀ = σ₁u₁v₁ᵀ + σ₂u₂v₂ᵀ + … + σᵣuᵣvᵣᵀ

Pieces with σ = 0 add nothing, so there are exactly r pieces, where r is the rank.

A worked example

A = 1221: eigenvalues 3 with (1, 1)/√2 and −1 with (1, −1)/√2
σ₁ = 3:   v₁ = u₁ = (1, 1)/√2,   3u₁v₁ᵀ = 1.51.51.51.5
σ₂ = 1:   v₂ = (1, −1)/√2, u₂ = Av₂ = (−1, 1)/√2 (the eigenvalue −1 puts its minus sign into u₂),   1·u₂v₂ᵀ = −0.50.50.5−0.5
Sum: 1221 ✓

The first piece alone, all 1.5's, is already the best rank-one guess at A. The second piece adds the detail.

Where this is used

Recommendation systems (films, products) treat a huge table of ratings as a matrix and keep a few big SVD pieces. Each piece is a "taste" shared by many people. A few dozen pieces explain most of millions of ratings.

Worked examples

Example 1 · Spot a rank-one matrix

246123 = (2, 1) times the row (1, 2, 3).

One piece. Make both vectors unit length: u = (2, 1)/√5, v = (1, 2, 3)/√14. The two lengths move into σ: σ₁ = √5 · √14 = √70, and σ₂ = 0.

Example 2 · A diagonal matrix

4001 = 4·(1, 0)(1, 0)ᵀ + 1·(0, 1)(0, 1)ᵀ.

The pieces are the two axes, weighted by the diagonal entries.

Example 3 · Best rank-one approximation

For A = 3000.1, keep only the first piece: 3000.

The error is the dropped piece, of size σ₂ = 0.1: small, because σ₂ is small.

Worked examples

Example 1 · SVD of a tall matrix

A = 101101 (3 by 2).

AᵀA = 2112: λ = 3 with (1, 1)/√2,   λ = 1 with (1, −1)/√2
σ₁ = √3, σ₂ = 1
u₁ = Av₁/σ₁ = (1, 2, 1)/√6,   u₂ = Av₂/σ₂ = (1, 0, −1)/√2 (perpendicular ✓)

Example 2 · A rank-one matrix

A = 122436 = (1, 2, 3) times the row (1, 2).

One piece: σ₁ = |(1, 2, 3)| · |(1, 2)| = √14 · √5 = √70 ≈ 8.37,   σ₂ = 0
u₁ = (1, 2, 3)/√14,   v₁ = (1, 2)/√5

Example 3 · Pseudoinverse of a tall matrix

A = 100001, b = (1, 2, 3).

30 · (200 + 300 + 1) = 15,030, compared with 60,000 for the full image: a quarter.
