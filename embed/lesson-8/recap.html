What you can now do.

You can now break any matrix into turns and stretches, find its most important pieces, compress data with them, and find the main directions of a cloud of measurements.

Lesson 8 · slide 7Recap
A = UΣVᵀ = σ₁u₁v₁ᵀ + … + σᵣuᵣvᵣᵀ
Key ideas
  1. Every matrix is turn, stretch, turn: A = UΣVᵀ.
  2. σᵢ = √(eigenvalues of AᵀA); the vᵢ are its eigenvectors, uᵢ = Avᵢ/σᵢ.
  3. The first k pieces give the best rank-k approximation: compression and PCA.
  4. A⁺ = VΣ⁺Uᵀ undoes what can be undone; σ₁/σₙ measures sensitivity.
  • §7.4 Geometry. Kneading dough: turn, stretch along perpendicular axes, turn. The unit circle becomes an ellipse with half-axes σ₁, σ₂.
  • §7.2 Singular values. |Av|² = vᵀAᵀAv: the σ's are square roots of the eigenvalues of AᵀA.
  • §7.2 Pieces. A song as tracks: A = σ₁u₁v₁ᵀ + σ₂u₂v₂ᵀ + …, loudest first.
  • §7.1 Images. A sketch artist: keep k pieces, store k(m + n + 1) numbers.
  • §7.3 PCA. The robot along the wall: center, SVD, v₁ is the main direction.
  • §7.4 Pseudoinverse. The best undo: A⁺ = VΣ⁺Uᵀ, and the condition number σ₁/σₙ.

This completes the path through Strang's chapters 1 to 7: from combining two arrows to taking any matrix apart. Everything in modern data work, from control to machine learning, is built on these pieces.

A 6 by 4 data matrix (centered) has singular values 9, 3, 1, 0. How many principal components explain over 95% of the spread?

Squares: 81, 9, 1, 0, total 91. The first explains 89%, the first two 98.9%. Two components.

3

Find x⁺ for A = 2000 and b = (4, 7).

Show solutionHide solution

A⁺ = [½ 0; 0 0], x⁺ = (2, 0). The second equation 0 = 7 cannot be met; x⁺ fixes the first and keeps x₂ = 0 (shortest).

Worked examples

Example 1 · SVD of a tall matrix

A = 101101 (3 by 2).

AᵀA = 2112: λ = 3 with (1, 1)/√2,   λ = 1 with (1, −1)/√2
σ₁ = √3, σ₂ = 1
u₁ = Av₁/σ₁ = (1, 2, 1)/√6,   u₂ = Av₂/σ₂ = (1, 0, −1)/√2 (perpendicular ✓)

Example 2 · A rank-one matrix

A = 122436 = (1, 2, 3) times the row (1, 2).

One piece: σ₁ = |(1, 2, 3)| · |(1, 2)| = √14 · √5 = √70 ≈ 8.37,   σ₂ = 0
u₁ = (1, 2, 3)/√14,   v₁ = (1, 2)/√5

Example 3 · Pseudoinverse of a tall matrix

A = 100001, b = (1, 2, 3).

Both σ's are 1 and A⁺ = Aᵀ here: A⁺ = 100001,   x⁺ = (1, 3)
The middle equation 0 = 2 cannot be met; x⁺ satisfies the other two exactly

Problems

1

Find the singular values of 2112.

Show solutionHide solution

It is symmetric with eigenvalues 3 and 1, both positive, so σ₁ = 3 and σ₂ = 1.

2

Find the singular values of 403-5.

Show solutionHide solution

AᵀA = [25 −15; −15 25]: trace 50, det 625 − 225 = 400. λ² − 50λ + 400 = (λ − 40)(λ − 10). σ₁ = √40 ≈ 6.32, σ₂ = √10 ≈ 3.16. Check: σ₁σ₂ = 20 = |det A| ✓

3

Write 3311 as one piece σuvᵀ with unit vectors.

Show solutionHide solution

It is (3, 1) times the row (1, 1). σ = |(3, 1)| · |(1, 1)| = √10 · √2 = √20, u = (3, 1)/√10, v = (1, 1)/√2.

4

A 200 by 300 image has singular values that drop below 1% of σ₁ after the first 30. How many numbers does the rank-30 copy store?

Show solutionHide solution

30 · (200 + 300 + 1) = 15,030, compared with 60,000 for the full image: a quarter.

5

Centered data has singular values 6, 2, 1. What share of the spread do the first two principal components explain?

Show solutionHide solution

Squares 36, 4, 1, total 41. (36 + 4)/41 ≈ 97.6%.
