Strang §3.5 · Dimensions of the four subspaces

Four subspaces, one big picture.

Every matrix has four subspaces. The row space and the nullspace live among the inputs, the column space and the left nullspace among the outputs. The rank r fixes the size of all four.

Lesson 4 · slide 6Four subspaces
inputs (ℝⁿ):  row space r + nullspace n − r   |   outputs (ℝᵐ):  column space r + left nullspace m − r
Key ideas
  1. Inputs (ℝⁿ, all vectors with n components): the row space C(Aᵀ), dimension r, and the nullspace N(A), dimension n − r.
  2. Outputs (ℝᵐ): the column space C(A), dimension r, and the left nullspace N(Aᵀ), dimension m − r.
  3. The row space and the column space always have the same dimension, r.
  4. The row space is perpendicular to the nullspace.

Think of a shadow

The sun is straight overhead, and every object casts a shadow on the floor. Taking an object to its shadow is like a matrix taking 3D inputs to 2D outputs.

  • Moving an object straight up or down does not change its shadow. That lost direction is the nullspace.
  • Moving it along the floor moves the shadow by the same amount. That part of the input is the row space.
  • Every place where a shadow can fall is the column space.
  • The directions in the floor that are perpendicular to every possible shadow form the left nullspace, N(Aᵀ). Here shadows cover the whole floor, so only the zero vector qualifies.

The dimensions

For an m by n matrix of rank r:

row space: r  +  nullspace: n − r  =  n
column space: r  +  left nullspace: m − r  =  m

The row space is the column space of Aᵀ, so we write it C(Aᵀ). The left nullspace N(Aᵀ) holds every y with Aᵀy = 0, which is the same as yᵀA = 0: y multiplies A from the left. The same perpendicular argument as below, applied to Aᵀ, shows that the left nullspace is perpendicular to the column space.

The row space and column space have the same dimension, even though they live in different spaces. Strang calls these four dimensions Part 1 of the Fundamental Theorem of Linear Algebra.

Why the row space is perpendicular to the nullspace

Ax = 0 says that each row of A, dotted with x, gives 0. So x is perpendicular to every row, and therefore to every combination of rows, which is the whole row space. The next lesson (Strang, chapter 4) builds on this.

A worked example

A = 1236 has rank 1.
row space: the line through (1, 2)   nullspace: the line through (−2, 1)
column space: the line through (1, 3)   left nullspace: the line through (−3, 1)
Finding the left nullspace: Aᵀ = 1326, and Aᵀy = 0 says y₁ + 3y₂ = 0 (the second row, 2y₁ + 6y₂ = 0, says the same). The free variable is y₂. Set y₂ = 1, then y₁ = −3, so y = (−3, 1).
Each pair is perpendicular: (1, 2)·(−2, 1) = 0 and (1, 3)·(−3, 1) = 0 ✓
The 2 by 4 matrix from slide 3 has r = 2: row space 2, nullspace 2 (its two special solutions), column space 2 (all of ℝ²), left nullspace 0.

Any invertible 2 by 2 matrix has rank 2.

Row space = column space = the whole plane

Worked examples

Example 1 · Is it a subspace?

Is the set of all (x, y, z) with x = 2y a subspace of 3D space?

Zero: (0, 0, 0) has 0 = 2·0 ✓
Add: if x₁ = 2y₁ and x₂ = 2y₂, then x₁ + x₂ = 2(y₁ + y₂) ✓
Scale: cx₁ = 2(cy₁) ✓

Yes. It is a plane through the origin. With x = 2y + 1 it would fail at once: the origin is missing.

Example 2 · Nullspace and special solutions

Find the nullspace of A = 123246.

Row 2 − 2·row 1 = 0, so R = 123000. One pivot (column 1), rank 1.
Free: x₂, x₃.   x₂ = 1, x₃ = 0 gives (−2, 1, 0).   x₂ = 0, x₃ = 1 gives (−3, 0, 1).

N(A) is all combinations c·(−2, 1, 0) + d·(−3, 0, 1): a plane, dimension n − r = 3 − 1 = 2.

Example 3 · The complete solution

Solve x + 2y + 3z = 6.

Particular solution: set the free variables y = z = 0, then x = 6. x_p = (6, 0, 0)
Nullspace: A = [1 2 3], the first row of Example 2's matrix, with special solutions (−2, 1, 0) and (−3, 0, 1)
x = (6, 0, 0) + c·(−2, 1, 0) + d·(−3, 0, 1)

Geometrically: a plane parallel to the nullspace, shifted to pass through (6, 0, 0).

Problems

1

Which of these are subspaces of the plane? (a) all (x, y) with x = y (b) all (x, y) with x + y = 1 (c) all (x, y) with xy = 0.

Show solutionHide solution

(a) Yes: a line through the origin.

(b) No: (0, 0) is not on it.

(c) No: it is the two axes together, and (1, 0) + (0, 1) = (1, 1) has xy = 1.

2

Find the nullspace of 1−12−2.

Show solutionHide solution

Both rows say x − y = 0. So N(A) is every multiple of (1, 1): a line.

Check: A(1, 1) = (1 − 1, 2 − 2) = (0, 0) ✓

3

Find R, the rank and a special solution for A = 121243364.

Show solutionHide solution

Row 2 − 2·row 1 = (0, 0, 1), row 3 − 3·row 1 = (0, 0, 1), then row 3 − row 2 = 0. Clearing above the pivot: R = 120001000.

Pivots in columns 1 and 3, so rank 2. Column 2 is free: x₂ = 1 gives the special solution (−2, 1, 0).

4

Are (1, 2, 0), (0, 1, 1) and (1, 3, 1) independent?

Show solutionHide solution

No. (1, 3, 1) = (1, 2, 0) + (0, 1, 1), so 1·v₁ + 1·v₂ − 1·v₃ = 0. The rank is 2 and the three vectors lie in one plane.

5

A is 3 by 5 with rank 2. Give the dimension of each of the four subspaces.

Show solutionHide solution

m = 3, n = 5, r = 2.

Row space r = 2, nullspace n − r = 3, column space r = 2, left nullspace m − r = 1.
