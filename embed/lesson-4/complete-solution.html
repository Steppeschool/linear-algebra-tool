Strang §3.3 · The complete solution to Ax = b

Every solution = one particular solution + the nullspace.

When Ax = b has a solution, it usually has many. All of them have the same form: one particular solution plus any vector from the nullspace.

x = x_p + x_n     Ax_p = b,   Ax_n = 0
Key ideas
  1. If Ax_p = b, then every solution is x = x_p + x_n with x_n in N(A).
  2. Ax = b is solvable exactly when b is in the column space C(A).
  3. To find x_p, set all free variables to 0 and solve for the pivot variables.
  4. The rank r decides whether there are zero, one or infinitely many solutions.

Think of a route plus a loop

You know one route that reaches your destination. Add any loop that brings you back to where you started, and you still reach the destination. The loops are the nullspace.

With the boat: one throttle setting produces the motion you want. Add any cancelling combination such as (2, −1), and the boat moves exactly the same; the engines just work harder.

Why every solution has this form

  • Adding a nullspace vector keeps a solution: A(x_p + x_n) = Ax_p + Ax_n = b + 0 = b.
  • Any two solutions differ by a nullspace vector: if Ax = b and Ay = b, then A(x − y) = b − b = 0.

In the plot, the solutions form a line parallel to N(A), shifted so that it passes through x_p.

A worked example

A = 1224, b = (4, 8). Setting the free variable x₂ = 0 gives x_p = (4, 0).
N(A) = all c·(−2, 1)  →  x = (4 − 2c, c)
With c = 2: x = (0, 2). Check: 0 + 2·2 = 4 and 0 + 4·2 = 8 ✓
With b = (4, 9) instead, elimination ends with 0 = 1. That b is not on the column space line, so there is no solution at all.

How many solutions?

For an m by n matrix of rank r:

  • r = m = n: exactly one solution for every b. A is invertible.
  • r = n < m: zero or one solution. There are more equations than unknowns.
  • r = m < n: infinitely many solutions for every b. There are free variables.
  • r < m and r < n: zero or infinitely many, depending on b.

Worked examples

Example 1 · One equation, two unknowns

x + y = 2.

x_p = (2, 0); N(A) = multiples of (−1, 1)
x = (2 − c, c)

Example 2 · A 2 by 3 system

A = 111123, b = (3, 6).

Eliminate: R = [1 0 −1 | 0; 0 1 2 | 3]
x_p (free x₃ = 0) = (0, 3, 0); special solution (1, −2, 1)
x = (0, 3, 0) + c·(1, −2, 1)

Example 3 · No solution

A = 1224, b = (1, 3).

Row 2 − 2·row 1: 0 = 3 − 2 = 1. Impossible

b is not in the column space.

Worked examples

Example 1 · Is it a subspace?

Is the set of all (x, y, z) with x = 2y a subspace of 3D space?

Zero: (0, 0, 0) has 0 = 2·0 ✓
Add: if x₁ = 2y₁ and x₂ = 2y₂, then x₁ + x₂ = 2(y₁ + y₂) ✓
Scale: cx₁ = 2(cy₁) ✓

Yes. It is a plane through the origin. With x = 2y + 1 it would fail at once: the origin is missing.

Example 2 · Nullspace and special solutions

Find the nullspace of A = 123246.

Row 2 − 2·row 1 = 0, so R = 123000. One pivot (column 1), rank 1.
Free: x₂, x₃.   x₂ = 1, x₃ = 0 gives (−2, 1, 0).   x₂ = 0, x₃ = 1 gives (−3, 0, 1).

N(A) is all combinations c·(−2, 1, 0) + d·(−3, 0, 1): a plane, dimension n − r = 3 − 1 = 2.

Example 3 · The complete solution

Solve x + 2y + 3z = 6.

Particular solution: set the free variables y = z = 0, then x = 6. x_p = (6, 0, 0)
Nullspace: the same matrix as Example 2's first row, special solutions (−2, 1, 0) and (−3, 0, 1)
x = (6, 0, 0) + c·(−2, 1, 0) + d·(−3, 0, 1)

Geometrically: a plane parallel to the nullspace, shifted to pass through (6, 0, 0).

Problems

1

Which of these are subspaces of the plane? (a) all (x, y) with x = y (b) all (x, y) with x + y = 1 (c) all (x, y) with xy = 0.

Show solutionHide solution

(a) Yes: a line through the origin.

(b) No: (0, 0) is not on it.

(c) No: it is the two axes together, and (1, 0) + (0, 1) = (1, 1) has xy = 1.

2

Find the nullspace of 1−12−2.

Show solutionHide solution

Both rows say x − y = 0. So N(A) is every multiple of (1, 1): a line.

Check: A(1, 1) = (1 − 1, 2 − 2) = (0, 0) ✓

3

Find R, the rank and a special solution for A = 121243364.

Show solutionHide solution

Row 2 − 2·row 1 = (0, 0, 1), row 3 − 3·row 1 = (0, 0, 1), then row 3 − row 2 = 0. Clearing above the pivot: R = 120001000.

Pivots in columns 1 and 3, so rank 2. Column 2 is free: x₂ = 1 gives the special solution (−2, 1, 0).

4

Are (1, 2, 0), (0, 1, 1) and (1, 3, 1) independent?

Show solutionHide solution

No. (1, 3, 1) = (1, 2, 0) + (0, 1, 1), so 1·v₁ + 1·v₂ − 1·v₃ = 0. The rank is 2 and the three vectors lie in one plane.

5

A is 3 by 5 with rank 2. Give the dimension of each of the four subspaces.

Show solutionHide solution

m = 3, n = 5, r = 2.

Row space r = 2, nullspace n − r = 3, column space r = 2, left nullspace m − r = 1.
