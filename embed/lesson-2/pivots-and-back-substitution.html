Strang §2.2 · Pivots

Pivots clear the columns. Back substitution climbs back up.

With three equations we eliminate one column at a time. The first pivot clears column 1, the second pivot clears column 2, and the system becomes a triangle. Then back substitution solves it from the bottom up.

Lesson 2 · slide 2Pivots
2114−60−272  →  2110−8−2001
Key ideas
  1. Elimination works column by column, from left to right.
  2. Each multiplier uses the current pivot, after the earlier steps.
  3. The result is an upper triangular matrix U: zeros below the diagonal, the line from the top-left corner to the bottom-right (entries U₁₁, U₂₂, U₃₃). Those diagonal entries are the pivots.
  4. Back substitution solves the last row first, then moves up one row at a time.

From two equations to three

Nothing new is needed for bigger systems. We just repeat the step from slide 1, carefully, in a fixed order. Take

A = 2114−60−272    with right side b = 5−29

We carry b along with A. Each equation becomes one row, written like (2, 1, 1 | 5): the numbers before the bar | are the coefficients, and the number after it is the right-hand side. So (2, 1, 1 | 5) means 2x + y + z = 5. Every step acts on the whole row, bar included. Always apply each step to b as well as to A: changing only the left side would give a different system.

We also name the multipliers. ℓᵢⱼ is the multiplier used to clear the entry in row i, column j. So ℓ₂₁ clears row 2, column 1.

Column 1

The first pivot is 2, in the top left corner. Below it we must clear the 4 and the −2:

  • ℓ₂₁ = 4 ÷ 2 = 2. Subtract 2 times row 1 from row 2: (4, −6, 0 | −2) − 2·(2, 1, 1 | 5) = (0, −8, −2 | −12).
  • ℓ₃₁ = −2 ÷ 2 = −1. Subtract −1 times row 1 from row 3, which means adding row 1: (−2, 7, 2 | 9) + (2, 1, 1 | 5) = (0, 8, 3 | 14).

Column 2

Now the second row starts with 0, −8. The second pivot is −8, and we use it to clear the 8 below it. The multiplier is ℓ₃₂ = 8 ÷ (−8) = −1, so we add row 2 to row 3: (0, 8, 3 | 14) + (0, −8, −2 | −12) = (0, 0, 1 | 2).

Notice that ℓ₃₂ uses −8, the pivot as it stands now, not the −6 that was in that position at the start. This is the most common mistake in hand calculations.

The triangle

U = 2110−8−2001    pivots 2, −8, 1    c = 5−122

The new right-hand side gets its own name, c: it is b after the same elimination steps. The triangular system is Ux = c, and it has the same solution as Ax = b.

The diagonal of a square matrix runs from the top-left corner to the bottom-right: here the entries U₁₁, U₂₂, U₃₃ (row 1 column 1, and so on). U is upper triangular: every entry below the diagonal is zero, and its diagonal entries are the pivots. A pivot must not be zero, because we divide by it to get the multipliers. Slide 3 is about what happens when one is.

Back substitution: a chain of keys

Picture three locked boxes. The key to box 2 is inside box 3, and the key to box 1 is inside box 2. You have to open box 3 first. A triangular system works the same way: the last equation has only one unknown, its value unlocks the equation above, and so on to the top.

Row 3: z = 2  →  Row 2: −8y − 2·2 = −12, so y = 1  →  Row 1: 2x + 1 + 2 = 5, so x = 1

Examples

Example 1 · A full 3 by 3 solve

Solve x + y + z = 3, x + 2y + 2z = 5, x + 2y + 3z = 6.

ℓ₂₁ = 1: row 2 → (0, 1, 1 | 2).   ℓ₃₁ = 1: row 3 → (0, 1, 2 | 3)
ℓ₃₂ = 1: row 3 → (0, 0, 1 | 1)
z = 1  →  y + 1 = 2, y = 1  →  x + 1 + 1 = 3, x = 1

The pivots are 1, 1, 1.

Example 3 · The pivots give the determinant

For A = 2114−60−272, elimination gave the pivots 2, −8 and 1.

Show solutionHide solution
det A = 2 · (−8) · 1 = −16

A side remark. Lesson 1 met the determinant of a 2 by 2 matrix as its area factor. For a square matrix of any size, when no rows are exchanged (slide 3), the determinant is the product of the pivots. That is how computers find determinants. We take it on trust for now; Professor Strang's chapter 5 explains why it works.

Example 4

Solve x + 2y + z = 4, 2x + 5y + z = 8, 3x + 7y + 4z = 14.

ℓ₂₁ = 2: (0, 1, −1 | 0). ℓ₃₁ = 3: (0, 1, 1 | 2). ℓ₃₂ = 1: (0, 0, 2 | 2).

z = 1, then y − 1 = 0 so y = 1, then x + 2 + 1 = 4 so x = 1.
