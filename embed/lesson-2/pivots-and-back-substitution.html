Strang §2.2 · Pivots

Pivots clear the columns. Back substitution climbs back up.

With three equations we clear one column at a time. The first pivot clears column 1, the second clears column 2, and the system becomes a triangle. Then back substitution solves it from the bottom up.

Lesson 2 · slide 2Pivots
2114−60−272  →  2110−8−2001
Key ideas
  1. Elimination works column by column, from left to right.
  2. Each multiplier uses the current pivot, after the earlier steps.
  3. The result is an upper triangular matrix U: zeros below the diagonal (the entries U₁₁, U₂₂, U₃₃, from top-left to bottom-right). The diagonal entries are the pivots.
  4. Back substitution solves the last row first, then moves up one row at a time.

From two equations to three

Bigger systems need nothing new. We repeat slide 1's step in a fixed order. Take

A = 2114−60−272    with right side b = 5−29

Each equation becomes a row like (2, 1, 1 | 5), meaning 2x + y + z = 5: coefficients before the bar, right side after. Every step acts on the whole row, bar included. Change only the left side and you get a different system.

ℓᵢⱼ is the multiplier that clears row i, column j.

Column 1

The first pivot is the 2 in the top-left corner. Below it we clear the 4 and the −2:

  • ℓ₂₁ = 4 ÷ 2 = 2. Subtract 2 times row 1 from row 2: (4, −6, 0 | −2) − 2·(2, 1, 1 | 5) = (0, −8, −2 | −12).
  • ℓ₃₁ = −2 ÷ 2 = −1. Subtract −1 times row 1 from row 3, which means adding row 1: (−2, 7, 2 | 9) + (2, 1, 1 | 5) = (0, 8, 3 | 14).

Column 2

Row 2 now starts 0, −8. The second pivot is −8. It clears the 8 below: ℓ₃₂ = 8 ÷ (−8) = −1, so add row 2 to row 3: (0, 8, 3 | 14) + (0, −8, −2 | −12) = (0, 0, 1 | 2).

Use the pivot as it is now (−8), not the −6 that sat there at the start. This is the most common mistake by hand.

The triangle

U = 2110−8−2001    pivots 2, −8, 1    c = 5−122

The new right side, c, is b after the same steps. Ux = c has the same solution as Ax = b.

U is upper triangular, with the pivots on its diagonal. A pivot can't be zero, because we divide by it. Slide 3 covers what happens when one is.

Back substitution: a chain of keys

The last equation has one unknown. Its value is the key to the equation above, and so on up to the top.

Row 3: z = 2  →  Row 2: −8y − 2·2 = −12, so y = 1  →  Row 1: 2x + 1 + 2 = 5, so x = 1

Examples

Example 1 · A full 3 by 3 solve

Solve x + y + z = 3, x + 2y + 2z = 5, x + 2y + 3z = 6.

ℓ₂₁ = 1: row 2 → (0, 1, 1 | 2).   ℓ₃₁ = 1: row 3 → (0, 1, 2 | 3)
ℓ₃₂ = 1: row 3 → (0, 0, 1 | 1)
z = 1  →  y + 1 = 2, y = 1  →  x + 1 + 1 = 3, x = 1

The pivots are 1, 1, 1.

Example 3 · The pivots give the determinant

For A = 2114−60−272, elimination gave the pivots 2, −8 and 1.

Show solutionHide solution
det A = 2 · (−8) · 1 = −16

A side remark. Lesson 1 met the determinant of a 2 by 2 matrix as its area factor. For a square matrix of any size, when no rows are exchanged (slide 3), the determinant is the product of the pivots. That is how computers find determinants. We take it on trust for now; Professor Strang's chapter 5 explains why it works.

Example 4

Solve x + 2y + z = 4, 2x + 5y + z = 8, 3x + 7y + 4z = 14.

Show solutionHide solution

ℓ₂₁ = 2: (0, 1, −1 | 0). ℓ₃₁ = 3: (0, 1, 1 | 2). ℓ₃₂ = 1: (0, 0, 2 | 2).

z = 1, then y − 1 = 0 so y = 1, then x + 2 + 1 = 4 so x = 1.
