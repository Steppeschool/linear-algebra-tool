Strang §2.7 · Permutations

Permutation matrices shuffle rows.

A permutation matrix is the identity with its rows in a new order. Multiplying PA puts the rows of A into that order. Permutations are how elimination records row exchanges.

Lesson 3 · slide 6Permutations
P = 001100010   PA = rows 3, 1, 2 of A
Key ideas
  1. Each row and each column of P contains a single 1.
  2. PA reorders the rows of A; AP reorders its columns (Example 1).
  3. P⁻¹ = Pᵀ: transposing undoes the reordering.
  4. With row exchanges, elimination gives PA = LU.

Think of a playlist

A playlist has slots: first, second, third. In PA, the slots are filled with rows of A. Row i of P fills slot i. A 1 at (i, j) in P, that is in row i and column j, means "slot i takes row j". In the P at the top of this slide, the 1 at (1, 3) means "slot 1 takes row 3".

Undoing a permutation

To put things back, each row returns to where it came from. If slot i took row j, the reverse instruction is "slot j takes row i back". That is a 1 at (j, i). Moving every 1 from (i, j) to (j, i) mirrors P across its diagonal, which is exactly the transpose Pᵀ. For the P at the top: slot 1 took row 3, so the undo says "slot 3 takes row 1 back", a 1 at (3, 1). Pᵀ has its 1 there. So P⁻¹ = Pᵀ for every permutation matrix.

A worked example

Use a matrix A whose rows are full of 1s, 2s and 3s, so you can see where each row goes.
P = 001100010   PA = 333111222
PᵀP = I ✓

How many are there?

  • n rows can be ordered in n! ways, so there are 6 permutation matrices of size 3 (including I).
  • In the plane the only exchange is 0110. As a motion it is the mirror on the line y = x from lesson 1, with det = −1.

Back to elimination

When lesson 2 met a zero pivot, we exchanged rows. If A is invertible and we do all the exchanges first, with a permutation P, elimination never meets a zero pivot, and we get PA = LU. This is the form that NumPy and other solvers actually compute, choosing the exchanges so that each pivot is as large as possible.

Worked examples

Example 1 · Rows or columns

P = 0110, A = 1234.

PA = 3412: the rows swap
AP = 2143: the columns swap

Why columns? Column j of AP is A times column j of P (Ax by columns, lesson 1). Each column of P has a single 1, so it picks out one column of A. Column 1 of P is (0, 1), which picks column 2 of A.

Example 2 · Reverse order

P = 001010100 puts rows in the order 3, 2, 1.

Pᵀ = P, so P⁻¹ = P: doing it twice restores the order

Example 3 · PA = LU

A = 0231 has a zero first pivot.

Swap: PA = 3102, already upper triangular
So PA = LU with L = I

Worked examples

Example 1 · A 2 by 2 inverse

Find the inverse of A = 4726.

det A = 4·6 − 7·2 = 10
A⁻¹ = 1/10 · 6−7−24
Check, top-left entry of AA⁻¹: (4·6 + 7·(−2)) / 10 = 1 ✓

Example 2 · Gauss-Jordan step by step

Invert A = 1237 by elimination on [A | I].

[1 2 | 1 0; 3 7 | 0 1]  → row 2 − 3·row 1 →  [1 2 | 1 0; 0 1 | −3 1]
row 1 − 2·row 2 →  [1 0 | 7 −2; 0 1 | −3 1]
A⁻¹ = 7−2−31

det A = 1, so the formula gives the same answer with no fractions.

Example 3 · The transpose of a product

Check (AB)ᵀ = BᵀAᵀ for A = 1201 and B = 1031.

AB = 7231, so (AB)ᵀ = 7321
BᵀAᵀ = 13011021 = 7321 ✓

AᵀBᵀ would be 1327: the wrong order gives a different matrix.
