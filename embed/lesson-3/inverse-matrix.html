Strang §2.5 · Inverse matrices

The inverse undoes A.

The inverse of A is the matrix that undoes A. Apply A, then A⁻¹, and every vector is back where it started. When it exists, it solves Ax = b in one step: x = A⁻¹b.

Lesson 3 · slide 1The inverse
A⁻¹A = I     Ax = b  ⇔  x = A⁻¹b
Key ideas
  1. A⁻¹A = I and AA⁻¹ = I, where I is the identity matrix.
  2. If A is invertible, Ax = b has exactly one solution, x = A⁻¹b.
  3. A matrix that sends two different vectors to the same output cannot be undone.
  4. An n by n matrix A is invertible ⇔ it has n nonzero pivots ⇔ its columns are independent ⇔ det A ≠ 0.

Think of rewinding a film

Lesson 1 showed a matrix as a motion of the plane: it stretches, turns or slants the graph paper. The inverse plays that motion backwards. After A and then A⁻¹, nothing has moved.

"Nothing has moved" is the identity matrix I, with 1s on the diagonal and 0s elsewhere. It satisfies Ix = x for every vector x.

Why the inverse solves equations

Start from Ax = b and multiply both sides on the left by A⁻¹. Since A⁻¹A = I, the left side becomes Ix = x, so x = A⁻¹b. If the inverse exists, there is exactly one solution, and we know how to get it.

Example: undoing a shear

The shear S = 1101 slides each point to the right by its height.
To undo it, slide each point back to the left by the same amount: S⁻¹ = 1−101
S⁻¹S = 1−1011101 = 1001 ✓

In the lab, follow the vector v = 12: S moves it to 32, and your S⁻¹ should bring it back.

When there is no inverse

Think of the boat from lesson 1 with both thrusters pointing the same way, thruster 2 twice as strong as thruster 1:

A = 1224
Column 1, 12, is the push from thruster 1 at full power. Column 2, 24, is the push from thruster 2: the same direction, twice as long. The input x holds the two throttle settings. The output Ax is the total push, written as (push along x, push along y).

The setting 20 runs thruster 1 at 2. The setting 01 runs thruster 2 at 1. Since thruster 2 is twice as strong, both settings give the same push:

A(2, 0) = 2·12 = 24   A(0, 1) = 1·24 = 24
A(2, 0) = A(0, 1)

If you only see the boat move, you cannot tell which setting was used.

That is a matrix with no inverse: it sends two different inputs to the same output, so no matrix can reverse it. For a square matrix A with n rows and n columns (n by n), all of these say the same thing:

  • A has n nonzero pivots (lesson 2).
  • The columns of A are independent (lesson 1).
  • det A ≠ 0: the plane is not squashed. For now, think 2 by 2; determinants of larger matrices come in the determinants lesson.
  • Ax = 0 only for x = 0. Here is why this belongs: if some x ≠ 0 had Ax = 0, then x and 0 would give the same output, 0. Two inputs, one output, so A could not be undone.
