Strang §2.5 · Gauss-Jordan elimination

Eliminate on [A | I] and the inverse appears.

To find A⁻¹ by elimination, write A and the identity side by side. Use row operations to turn A into I. The same operations turn I into A⁻¹.

Lesson 3 · slide 4Gauss-Jordan
[ A  |  I ]  →  [ I  |  A⁻¹ ]
Key ideas
  1. Start with A and I written side by side: [A | I].
  2. Eliminate below the pivots, then above them, then divide each row by its pivot.
  3. When the left half becomes I, the right half is A⁻¹.
  4. To solve Ax = b, use elimination (A = LU), not A⁻¹: it is faster and more accurate.

Think of carbon paper

Every row operation you do on A gets copied onto I beside it, like carbon paper. When A has become I, the copy holds all your steps. Together those steps undo A, so the copy is A⁻¹.

In matrices: each step is a matrix E₁, E₂, and so on (lesson 2). Dividing a row by its pivot is a step matrix too. Multiply all the steps, last step on the left: E = ⋯E₃E₂E₁. The steps turn A into I, so EA = I, and E = A⁻¹. On the right, the same steps turn I into EI = E, which is A⁻¹.

The three stages

  • Forward: clear the entries below each pivot, as in lesson 2.
  • Backward: clear the entries above each pivot, from the bottom row up.
  • Scale: divide each row by its pivot, so the diagonal is all 1s.

Scaling doesn't disturb the zeros, so you can do it any time. Doing it last keeps the fractions away until the end.

The result is the reduced row echelon form (rref). The lab's rref does all three stages.

A worked example

K = 2−10−12−10−12 appears in models of a chain of springs and masses.
Start from [K | I]. Each step below changes one row; the numbers after | are the right half.
Forward: row 2 + ½·row 1 → [0  3/2  −1 | ½  1  0]
Forward: row 3 + ⅔·row 2 → [0  0  4/3 | ⅓  ⅔  1]. The pivots are 2, 3/2, 4/3.
Backward: row 2 + ¾·row 3 → [0  3/2  0 | ¾  3/2  ¾]
Backward: row 1 + ⅔·row 2 → [2  0  0 | 3/2  1  ½]
Scale: row 1 ÷ 2 → [1  0  0 | ¾  ½  ¼]
Scale: row 2 ÷ 3/2 → [0  1  0 | ½  1  ½]
Scale: row 3 ÷ 4/3 → [0  0  1 | ¼  ½  ¾]
The left half is now I. Every entry of the right half is a multiple of ¼, so pull ¼ out front:
K⁻¹ = ¼ · 321242123
Check one column. The first column of K⁻¹ is ¼·321, and K times it must give the first column of I, 100. Because of the ¼ in front, K·321 itself should give 4·100 = 400:
K·321 = 6 − 2−3 + 4 − 1−2 + 2 = 400 ✓
The lab does all of these steps with rref.

Think with the inverse, compute without it

Finding A⁻¹ takes about three times the work of factoring A = LU, and it adds rounding error. So to solve Ax = b, use elimination. The inverse is great for reasoning, as in x = A⁻¹b. It is rarely the best way to compute.

Example 2 · A triangular matrix

Invert A = 120013001. Only upward steps are needed.

Show solutionHide solution
row 2 − 3·row 3, then row 1 − 2·row 2
A⁻¹ = 1−2601−3001

Where does the 6 come from? Follow the right half, which starts as I. Step 1 puts −3 in row 2, column 3, so row 2 becomes [0 1 −3]. Step 2 subtracts 2 times this new row 2 from row 1. Row 1 had 0 in column 3, so it gets 0 − 2·(−3) = 6. The second step uses the result of the first.

Example 3 · When Gauss-Jordan stops

The left side has a zero row, so it can never become I. No inverse.
