Strang §6.4 · Symmetric matrices

Symmetric matrices: perpendicular eigenvectors.

Symmetric matrices (A = Aᵀ) are the friendliest case. Their eigenvalues are real, and their eigenvectors can be chosen perpendicular and of length 1. Then X becomes an orthogonal matrix Q, its inverse is just Qᵀ, and A = QΛQᵀ.

Lesson 7 · slide 5Symmetric matrices
A = Aᵀ ⇒ A = QΛQᵀ    QᵀQ = I
Key ideas
  1. A symmetric matrix has only real eigenvalues.
  2. Eigenvectors for different eigenvalues are perpendicular.
  3. Scaled to length 1, they form the columns of an orthogonal Q (lesson 5): Q⁻¹ = Qᵀ.
  4. So A = QΛQᵀ: the spectral theorem. Every symmetric matrix is a stretch along perpendicular axes.

Pulling a sheet in two perpendicular directions

Stretch a sheet of rubber harder east-west than north-south. The two stretch directions are perpendicular, and each is a direction the stretch does not turn. That is what a symmetric matrix always looks like: stretches (or squeezes, or flips) along perpendicular axes, and nothing else.

Why the eigenvectors are perpendicular

Take Ax = λ₁x and Ay = λ₂y with λ₁ ≠ λ₂. Compute xᵀAy in two ways:

xᵀ(Ay) = λ₂ xᵀy
(Ax)ᵀy = λ₁ xᵀy,   and (Ax)ᵀy = xᵀAᵀy = xᵀAy because A = Aᵀ
So λ₁ xᵀy = λ₂ xᵀy. Since λ₁ ≠ λ₂, xᵀy = 0: x ⟂ y

A worked example

A = 3113: trace 6, det 8, λ² − 6λ + 8 = (λ − 4)(λ − 2)
λ = 4 with (1, 1),   λ = 2 with (1, −1).   (1, 1) · (1, −1) = 0 ✓
Unit length: q₁ = (1, 1)/√2,   q₂ = (1, −1)/√2
Q = (1/√2)111−1,   Λ = 4002,   A = QΛQᵀ

Forget the √2 and use Q = [1 1; 1 −1]: then QᵀQ = 2I, not I, and QΛQᵀ comes out as 2A. Length 1 matters. That is the lab exercise.

A sum of simple pieces

Multiplying out QΛQᵀ gives A = λ₁q₁q₁ᵀ + λ₂q₂q₂ᵀ. Each qqᵀ is a projection onto one axis (lesson 5). So a symmetric matrix projects onto each axis, stretches by its λ, and adds up. Here A = 4·(projection onto (1, 1)) + 2·(projection onto (1, −1)).

Where this is used

Covariance matrices of sensor data are symmetric. Their perpendicular eigenvectors are the directions in which the data varies most and least. That is principal component analysis (PCA), which comes with the SVD in the next lesson. The inertia matrix of a drone is symmetric too: its eigenvectors are the principal axes from slide 1.

Worked examples

Example 1 · A diagonal matrix

A = 5001: Q = I, Λ = A. The axes are already perpendicular eigenvectors.

Example 2 · Negative eigenvalues are fine

A = 2332: λ = 5 with (1, 1), λ = −1 with (1, −1).

Still perpendicular: (1, 1) · (1, −1) = 0
A stretches by 5 along (1, 1) and flips along (1, −1)

Example 3 · A non-symmetric contrast

A = 4123 (slide 2) has eigenvectors (1, 1) and (1, −2).

(1, 1) · (1, −2) = −1 ≠ 0

Not perpendicular: without symmetry there is no such guarantee.

Find Q and Λ for 5222 (eigenvalues 6 and 1).

λ = 6: A − 6I = [−1 2; 2 −4], x = (2, 1). λ = 1: A − I = [4 2; 2 1], x = (1, −2). Perpendicular ✓. Q = (1/√5)[2 1; 1 −2], Λ = diag(6, 1).

2

Show that AᵀA is always symmetric, so its eigenvectors can be chosen perpendicular.

Show solutionHide solution

(AᵀA)ᵀ = Aᵀ(Aᵀ)ᵀ = AᵀA. This fact is the starting point of the SVD.

3

A symmetric 2 by 2 matrix has eigenvector (3, 4). Without more information, what is the other eigenvector direction?

Show solutionHide solution

It must be perpendicular: (4, −3) or any multiple.

Worked examples

Example 1 · Eigenvalues of a triangular 3 by 3

A = 120030005.

Triangular: det(A − λI) = (1 − λ)(3 − λ)(5 − λ), so λ = 1, 3, 5
λ = 3: A − 3I = −220000002 gives x = (1, 1, 0)
λ = 1: x = (1, 0, 0).   λ = 5: x = (0, 0, 1)

Example 2 · A power by eigenvectors

A = 2112, u₀ = (3, 1). Find A⁵u₀.

Split: (3, 1) = 2·(1, 1) + 1·(1, −1)
A⁵u₀ = 2·3⁵(1, 1) + 1·1⁵(1, −1) = 486(1, 1) + (1, −1) = (487, 485)

Example 3 · A steady state

A = 0.60.40.40.6: columns add to 1.

λ = 1 with (1, 1),   λ = 0.2 with (1, −1)
Steady state (½, ½): the symmetric swap evens things out

Problems

1

Find the eigenvalues and eigenvectors of 3103. Can it be diagonalized?

Show solutionHide solution

λ = 3 twice. A − 3I = [0 1; 0 0] has null space only along (1, 0). One eigenvector line, so no: not diagonalizable.

2

Find the eigenvalues of 01-2-3. Is du/dt = Au stable?

Show solutionHide solution

Trace −3, det 2: λ² + 3λ + 2 = (λ + 1)(λ + 2), so λ = −1, −2. Both negative: every solution decays like e^(−t) and e^(−2t). Stable.

3

The Fibonacci rule F_(k+2) = F_(k+1) + F_k is u_(k+1) = Au_k with A = 1110. Find its eigenvalues.

Show solutionHide solution

λ² − λ − 1 = 0, so λ = (1 ± √5)/2 ≈ 1.618 and −0.618. The first grows; it is the golden ratio, and F_(k+1)/F_k approaches it.

4

Diagonalize A = 2112 with Q orthogonal.

Show solutionHide solution

λ = 3 with (1, 1)/√2 and λ = 1 with (1, −1)/√2. Q = (1/√2)[1 1; 1 −1], Λ = diag(3, 1), A = QΛQᵀ.

5

Is 2-10-12-10-12 positive definite?

Show solutionHide solution

Yes. Pivots 2, 3/2, 4/3 are all positive (lesson 6). The eigenvalues are 2 − √2, 2, 2 + √2, all positive.
