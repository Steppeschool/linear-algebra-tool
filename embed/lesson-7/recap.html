What you can now do.

You can now find the directions a matrix does not turn, use them to take powers, predict whether a system settles or blows up, and tell a bowl from a saddle.

Lesson 7 · slide 7Recap
Ax = λx    det(A − λI) = 0    A = XΛX⁻¹    symmetric: A = QΛQᵀ
Key ideas
  1. Eigenvectors keep their direction; λ is the stretch.
  2. Eigenvalues solve det(A − λI) = 0; they add to the trace and multiply to det.
  3. A = XΛX⁻¹ makes powers easy; |λ| decides growth or decay.
  4. Symmetric matrices have perpendicular eigenvectors; positive definite means all λ > 0.
  • §6.1 Eigenvectors. The rubber sheet: directions that only stretch. Ax = λx.
  • §6.1 Finding them. Turn the λ dial until A − λI is singular: det(A − λI) = 0, then a null space for each λ.
  • §6.2 Diagonalizing. Turning the map: A = XΛX⁻¹ and Aᵏ = XΛᵏX⁻¹.
  • §6.2 Powers and stability. Two cities: parts with |λ| < 1 die out, λ = 1 is the steady state.
  • §6.4 Symmetric matrices. A sheet pulled two ways: real λ, perpendicular eigenvectors, A = QΛQᵀ.
  • §6.5 Positive definite. A bowl, not a saddle: all λ > 0, xᵀAx > 0.

Next in Strang: chapter 7, the singular value decomposition. It does for every matrix, even rectangular ones, what A = QΛQᵀ does for symmetric ones.

1

Find the eigenvalues and eigenvectors of 6223.

Show solutionHide solution

Trace 9, det 14. λ² − 9λ + 14 = (λ − 7)(λ − 2).   λ = 7: x = (2, 1).   λ = 2: x = (1, −2). Perpendicular, as for every symmetric matrix.

2

A Markov matrix has eigenvalues 1 and 0.5. What happens to uₖ = Aᵏu₀?

Show solutionHide solution

The λ = 0.5 part halves every step and vanishes; uₖ approaches the steady state (the λ = 1 eigenvector, scaled so its entries add to the same total as u₀: 1 when u₀ holds fractions).

3

Is 1221 positive definite?

Show solutionHide solution

No: det = 1 − 4 = −3 < 0, so one eigenvalue is negative (λ = 3 and −1). A saddle.

Worked examples

Example 1 · Eigenvalues of a triangular 3 by 3

A = 120030005.

Triangular: det(A − λI) = (1 − λ)(3 − λ)(5 − λ), so λ = 1, 3, 5
λ = 3: A − 3I = −220000002 gives x = (1, 1, 0)
λ = 1: x = (1, 0, 0).   λ = 5: x = (0, 0, 1)

Example 2 · A power by eigenvectors

A = 2112, u₀ = (3, 1). Find A⁵u₀.

Split: (3, 1) = 2·(1, 1) + 1·(1, −1)
A⁵u₀ = 2·3⁵(1, 1) + 1·1⁵(1, −1) = 486(1, 1) + (1, −1) = (487, 485)

Example 3 · A steady state

A = 0.60.40.40.6: columns add to 1.

λ = 1 with (1, 1),   λ = 0.2 with (1, −1)
Steady state (½, ½): both cities lose the same share each step, so they end up equal

Problems

1

Find the eigenvalues and eigenvectors of 3103. Can it be diagonalized?

Show solutionHide solution

λ = 3 twice. A − 3I = [0 1; 0 0] has null space only along (1, 0). One eigenvector line, so no: not diagonalizable.

2

Find the eigenvalues of 01-2-3. Is du/dt = Au stable?

Show solutionHide solution

Trace −3, det 2: λ² + 3λ + 2 = (λ + 1)(λ + 2), so λ = −1, −2. Both negative: every solution decays like e^(−t) and e^(−2t). Stable.

3

The Fibonacci rule F_(k+2) = F_(k+1) + F_k is u_(k+1) = Au_k with u_k = (F_(k+1), F_k) and A = 1110. Find its eigenvalues.

Show solutionHide solution

λ² − λ − 1 = 0, so λ = (1 ± √5)/2 ≈ 1.618 and −0.618. The first grows; it is the golden ratio, and F_(k+1)/F_k approaches it.

4

Diagonalize A = 2112 with Q orthogonal.

Show solutionHide solution

λ = 3 with (1, 1)/√2 and λ = 1 with (1, −1)/√2. Q = (1/√2)[1 1; 1 −1], Λ = diag(3, 1), A = QΛQᵀ.

5

Is 2-10-12-10-12 positive definite?

Show solutionHide solution

Yes. Pivots 2, 3/2, 4/3 are all positive (lesson 6). The eigenvalues are 2 − √2, 2, 2 + √2, all positive.
