Strang §1.3 and §3.1 · Column space

The column space C(A) is every possible Ax.

Try every x and collect every output Ax. That collection is the column space of A. So solving Ax = b, for a target b, comes down to one question: is b in the column space?

Lesson 1 · slide 3Column space
C(A) = all vectors Ax = all combinations of the columns
Key ideas
  1. The column space C(A) contains every combination of the columns of A, that is, every vector Ax.
  2. Ax = b has a solution exactly when b is in C(A).
  3. In the plane, C(A) is the whole plane, a line through the origin, or just the origin.
  4. The rank measures the size of C(A): 2 for the whole plane, 1 for a line, 0 for the origin alone.

All the outputs at once

Let x be every possible vector and mark each Ax on the plane. All those points form the column space, C(A). Every Ax is a combination of the columns, hence the name.

A quick picture: a boat with two thrusters

Each column is one thruster's push. x holds the throttles (negative means reverse). Thrusters pointing different ways can push the boat anywhere: C(A) is the plane. Both pointing forward, it only goes forward or back: C(A) is a line.

Three possibilities in the plane

  • The whole plane: the columns point different ways. They are independent.
  • A line: one column is a multiple of the other. They are dependent.
  • Just the origin: both columns are zero.

The rank names the case: 2, 1 or 0.

A closer look at the dependent case

A = 1224. Column 2 is 2 times column 1.
Ax = x₁12 + x₂24 = (x₁ + 2x₂)·12
Every output is a multiple of 12. So b = 36 is reachable, but b = 10 is not.

Also, x = 30 and x = 11 both give 36. With dependent columns, different inputs can give the same output. Lesson 4 gives this extra freedom a name: the nullspace.

Two questions that sound alike

  • Can we solve Ax = b for this one b? Yes, if b is in C(A).
  • Can we solve Ax = b for every b? Only if C(A) is the whole plane.

A 2 by 2 matrix has a quick test. Write A = pqrs, with columns pr and qs. They are independent exactly when ps − qr ≠ 0. If ps − qr = 0, C(A) is only a line (or the origin). This number ps − qr is the determinant, det A. Slide 5 shows what it means as a motion of the plane.

Examples

Example 1 · A line, and who is on it

A = 2412. Column 2 = 2·column 1, so C(A) is the line through 21.

b = 63 = 3·21: in C(A), for example x = 30
b = 11: not a multiple of 21, so Ax = b has no solution

Example 2 · The whole plane

A = 111−1. Here p = 1, q = 1, r = 1, s = −1, so det A = ps − qr = 1·(−1) − 1·1 = −2. That is not 0, so C(A) is the whole plane. Solve Ax = 42:

x₁ = 3, x₂ = 1

Example 3 · Is b in the column space?

A = 1326, b = 25.

Show solutionHide solution
Column 2 = 3·column 1, so C(A) is the line of multiples of 12
Is 25 a multiple of 12? It would need 2·12 = 24, not 25

So b is not in C(A), and Ax = b has no solution. Changing b to 24 would make it solvable.

Example 4

Describe C(A) for A = 3612. What is the rank?

Show solutionHide solution

Column 2 = 2·column 1, so C(A) is the line through 31. Rank 1.

Example 5

What is C(A) when A is the zero matrix? When A is the identity matrix I = 1001, the matrix that leaves every vector where it is?

Show solutionHide solution

Zero matrix: only the origin, rank 0. Identity: the whole plane, rank 2, since Ix = x reaches everything.
