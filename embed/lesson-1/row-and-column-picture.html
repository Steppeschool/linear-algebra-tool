Strang §2.1 · Vectors and linear equations

Two pictures of the same equations.

A system of two equations can be read in two ways. By rows, each equation is a line, and we look for the crossing point. By columns, we look for the combination of columns that produces b. Both pictures give the same answer.

Key ideas
  1. Row picture: each equation is a line. The solution is where the lines meet.
  2. Column picture: call the unknown vector u = (x, y). On this slide x and y are plain numbers, the two entries of u. The system says x·(column 1) + y·(column 2) = b. The solution gives the right weights.
  3. Both pictures find the same solution (x, y). They fail together too: parallel lines go with dependent columns.
  4. In higher dimensions the column picture stays easy to think about, so we lean on it.

One system, two readings

Take Professor Strang's first example: x − 2y = 1 and 3x + 2y = 11. In matrix form, Au = b, where u = (x, y) is the unknown vector. On this slide x and y are plain numbers, the two entries of u:

A = 1−232    b = (1, 11)

The row picture: two clues

Think of a navigator who takes two compass bearings. Each bearing says "the ship is somewhere on this line". The ship is at the point that lies on both lines.

Each equation is such a clue. All points (x, y) with x − 2y = 1 form one straight line. All points with 3x + 2y = 11 form another. The solution is the crossing point, (3, 1). You can check it in both equations: 3 − 2 = 1 and 9 + 2 = 11.

The column picture: a recipe

Now read the same system by columns, as on slide 2:

x·(1, 3) + y·(−2, 2) = (1, 11)
3·(1, 3) + 1·(−2, 2) = (3 − 2, 9 + 2) = (1, 11) ✓

Now the question is different: how much of each column do we need to produce b? The answer is the same pair, x = 3 and y = 1. Only the picture has changed.

When the pictures go wrong

  • Parallel lines: the clues never agree, so there is no solution. In the column picture the two columns are dependent, and b lies off their line.
  • The same line twice: the second clue adds nothing new, so there are infinitely many solutions. In the column picture b lies on the line of the columns.

Why do parallel lines go with dependent columns? Lines are parallel when the left side of one equation is a multiple of the other, like x + y and 2x + 2y. Then both columns have the form (n, 2n), here (1, 2) and (1, 2), so they lie on one line.

Why the column picture wins later

With three unknowns each equation becomes a plane in space, and three planes meeting at a point is hard to draw. The column picture stays simple: three arrows, and one target to build from them.

When we actually solve by hand, though, we work with the rows. That is elimination, the subject of lesson 2.

Worked examples

Example 1 · One crossing

x + y = 3 and x − y = 1.

Rows: the lines cross at (2, 1)
Columns: 2·(1, 1) + 1·(1, −1) = (3, 1) = b ✓

Example 2 · The same line twice

x + 2y = 4 and 2x + 4y = 8.

Rows: the second equation is 2 × the first, so both are one line
Columns: (1, 2) and (2, 4) are dependent, and b = (4, 8) lies on their line

Infinitely many solutions, for example (4, 0) and (0, 2).

Example 3 · No crossing at all

x + y = 2 and 2x + 2y = 5.

Rows: the second line is x + y = 2.5, parallel to the first. They never meet
Columns: (1, 2) and (1, 2) are the same vector, and b = (2, 5) is not a multiple of (1, 2)

Both pictures agree: no solution.

Worked examples

Example 1 · Find the combination

Write b = (7, 4) as a combination of v = (1, 2) and w = (3, 1).

We need c and d with c·(1, 2) + d·(3, 1) = (7, 4). Component by component:

c + 3d = 7    2c + d = 4
From the second: d = 4 − 2c. Into the first: c + 12 − 6c = 7, so c = 1 and d = 2.
Check: 1·(1, 2) + 2·(3, 1) = (7, 4) ✓

In matrix form this is Ax = b with the columns v and w: 1321 x = (7, 4), x = (1, 2).

Example 2 · Ax by rows and by columns

Compute Ax for A = 2−113 and x = (3, 2).

By columns: 3·(2, 1) + 2·(−1, 3) = (6 − 2, 3 + 6) = (4, 9)
By rows: (2·3 − 1·2, 1·3 + 3·2) = (4, 9)

Same answer. The column way shows that (4, 9) lies in the column space, because it is built from the columns.

Example 3 · Build a matrix from where (1, 0) and (0, 1) land

Find the matrix that sends (1, 0) to (1, 1) and (0, 1) to (−1, 1). What does it do to areas?

The landing spots are the columns: A = 1−111.

det A = 1·1 − (−1)·1 = 2

Both arrows have length √2 and are at 90° to each other. (1, 1) points at 45°, so (1, 0) has turned by 45°. (−1, 1) points at 135°, so (0, 1) has turned by 45° too. So A turns the plane by 45° and stretches it by √2. Areas double, which matches det A = 2.

Is (5, 1) a combination of (1, 1) and (2, −1)? If so, find the numbers c and d.

Show solutionHide solution

Solve c + 2d = 5 and c − d = 1. Subtracting gives 3d = 4, so d = 4/3 and c = 7/3.

Check: 7/3 + 8/3 = 5 and 7/3 − 4/3 = 1 ✓. Yes, because the two vectors point in different directions, every vector in the plane is a combination of them.

3

For which number k are the columns of 1k26 dependent? What is the column space then?

Show solutionHide solution

The columns are dependent when det = 1·6 − 2k = 0, so k = 3.

Then column 2 = (3, 6) = 3·(1, 2). The column space is the line through (1, 2). Ax = b can only be solved when b is a multiple of (1, 2).

4

Find the 2 by 2 matrix that mirrors the plane across the x-axis. What is its determinant, and what does the sign mean?

Show solutionHide solution

(1, 0) stays put and (0, 1) flips to (0, −1), so A = 100−1.

det A = −1. Areas keep their size (|det| = 1), and the minus sign says the plane was flipped over.

5

R = 0−110 turns the plane by 90°. R² means R·R and R⁴ means R·R·R·R. Predict R² and R⁴ from the picture, then check by multiplying.

Show solutionHide solution

Prediction: two quarter turns make a half turn, so R² sends every vector to its opposite. Four quarter turns make a full turn, so R⁴ leaves every vector where it started: R⁴ = I, the identity.

Check: column 1 of R² is R(0, 1) = (−1, 0) and column 2 is R(−1, 0) = (0, −1), so R² = −100−1 ✓. Then R⁴ = R²·R² = 1001 = I ✓
