Strang §4.4 · Orthonormal bases

Orthonormal vectors and Q: the easiest basis to work with.

Vectors that are perpendicular to each other and have length 1 are orthonormal. Put them in the columns of a matrix Q and QᵀQ = I. With such a basis, coordinates are plain dot products, and projections and least squares need no inverse.

QᵀQ = I    square Q: Q⁻¹ = Qᵀ    ‖Qx‖ = ‖x‖
Key ideas
  1. q₁, ..., qₙ are orthonormal when qᵢᵀqⱼ = 0 for i ≠ j and qᵢᵀqᵢ = 1.
  2. With those vectors as columns, QᵀQ = I.
  3. A square Q with QᵀQ = I is an orthogonal matrix. Its inverse is its transpose.
  4. Q keeps lengths and angles: rotations and reflections.
  5. Coordinates in an orthonormal basis are dot products: x = (q₁ᵀx)q₁ + ... + (qₙᵀx)qₙ.

A city with a perfect grid

In a city where the streets meet at right angles and every block is exactly 1 km, you can read your position directly from the street signs: 3 blocks east, 2 blocks north. In a city with slanted streets and uneven blocks, finding your coordinates means solving equations.

An orthonormal basis is the perfect grid. "Ortho" means perpendicular, and "normal" means length 1.

QᵀQ = I

Put the vectors in the columns of Q. Entry (i, j) of QᵀQ is the dot product qᵢᵀqⱼ. Perpendicular columns put zeros off the diagonal, and length 1 puts ones on it:

q₁ = (0.6, 0.8),   q₂ = (−0.8, 0.6)
q₁ · q₁ = 0.36 + 0.64 = 1,   q₂ · q₂ = 1,   q₁ · q₂ = −0.48 + 0.48 = 0
QᵀQ = 1001

When Q is square, QᵀQ = I says that Qᵀ is the inverse of Q. Inverting an orthogonal matrix costs nothing: just transpose it.

Lengths are kept

‖Qx‖² = (Qx)ᵀ(Qx) = xᵀQᵀQx = xᵀx = ‖x‖². An orthogonal matrix moves vectors without stretching them. In the lab, the unit square stays a unit square; it only turns. Rotations and reflections are the orthogonal matrices of the plane.

Coordinates are dot products

To write x = c₁q₁ + c₂q₂, take the dot product of both sides with q₁. Every other term dies, because the q's are perpendicular, so c₁ = q₁ᵀx. No elimination is needed.

x = (5, 5):   c₁ = q₁ᵀx = 3 + 4 = 7,   c₂ = q₂ᵀx = −4 + 3 = −1
7·(0.6, 0.8) − 1·(−0.8, 0.6) = (5, 5) ✓

Projections become simple as well. With orthonormal columns, AᵀA becomes QᵀQ = I, the normal equations say x̂ = Qᵀb, and the projection matrix is P = QQᵀ.

Where this is used

A drone's orientation is stored as a 3 by 3 rotation matrix, an orthogonal matrix. After thousands of small updates, rounding errors make its columns drift away from orthonormal. The fix is to make them orthonormal again, which is the job of the next slide.

Worked examples

Example 1 · A rotation is orthogonal

Q = cos θ−sin θsin θcos θ.

q₁ · q₁ = cos²θ + sin²θ = 1,   q₂ · q₂ = 1
q₁ · q₂ = −cos θ sin θ + sin θ cos θ = 0
So QᵀQ = I, and Q⁻¹ = Qᵀ is the rotation by −θ

Example 2 · A permutation is orthogonal

P = 0110 from lesson 3 swaps the two components.

Its columns (0, 1) and (1, 0) are orthonormal
PᵀP = I, so P⁻¹ = Pᵀ (here P is its own inverse)

Example 3 · An orthonormal basis of 3D

q₁ = ⅓(1, 2, 2), q₂ = ⅓(2, 1, −2), q₃ = ⅓(2, −2, 1).

q₁ · q₂ = ⅑(2 + 2 − 4) = 0,   q₁ · q₃ = ⅑(2 − 4 + 2) = 0,   q₂ · q₃ = ⅑(4 − 2 − 2) = 0
‖q₁‖² = ⅑(1 + 4 + 4) = 1, and the same for q₂, q₃
For x = (3, 0, 0): coordinates q₁ᵀx = 1, q₂ᵀx = 2, q₃ᵀx = 2

Worked examples

Example 1 · Project onto a line in 3D

Project b = (3, 0, 3) onto the line through a = (1, 2, 2).

aᵀb = 3 + 0 + 6 = 9,   aᵀa = 1 + 4 + 4 = 9,   x̂ = 1
p = (1, 2, 2),   e = b − p = (2, −2, 1)
a · e = 2 − 4 + 2 = 0 ✓

The distance from b to the line is ‖e‖ = 3.

Example 2 · Fit a line to five points

Fit C + Dt to (−2, 0), (−1, 1), (0, 1), (1, 2), (2, 4).

The times are centred: Σt = 0, so the normal equations separate
5C = Σb = 8,   C = 1.6
10D = Σtb = 0 − 1 + 0 + 2 + 8 = 9,   D = 0.9

Best line: 1.6 + 0.9t. Choosing t so that Σt = 0 is a common trick: it makes the columns of A perpendicular.

Example 3 · Gram-Schmidt and QR in 3D

a = (1, 0, 1), b = (1, 1, 0).

aᵀb = 1, aᵀa = 2:   B = b − ½a = (½, 1, −½),   a · B = ½ − ½ = 0 ✓
q₁ = (1, 0, 1)/√2,   q₂ = B/√1.5
R = QᵀA = √21/√20√1.5

Check in the lab: Q, R = np.linalg.qr(A), then Q @ R gives A back.
