Strang §4.4 · The Gram-Schmidt process

Gram-Schmidt: making any basis orthonormal.

Start with independent vectors a and b. Keep the direction of a. From b, remove its projection onto a: what is left is perpendicular to a. Then divide each vector by its length. That is Gram-Schmidt, and recording the steps gives A = QR.

Lesson 5 · slide 7Gram-Schmidt
B = b − (aᵀb / aᵀa) a    q₁ = a / ‖a‖,   q₂ = B / ‖B‖    A = QR
Key ideas
  1. The first vector a is kept as it is.
  2. From b, subtract its projection onto a. The remainder B is perpendicular to a.
  3. From a third vector c, subtract its projections onto both a and B.
  4. Finally divide each by its length: q₁ = a/‖a‖, q₂ = B/‖B‖, and so on.
  5. The columns of A are combinations of the q's: A = QR with R upper triangular.

Squaring up a frame

A carpenter building a frame fixes the first board wherever it should go. The second board is then pushed until it sits at a right angle to the first, using a set square. Any lean towards the first board is removed. If there is a third board, it is squared against both.

Gram-Schmidt does the same with vectors. The lean of b towards a is exactly its projection onto a, which we know from slide 2.

The steps

Keep a.   B = b − (aᵀb / aᵀa) a
Check: aᵀB = aᵀb − (aᵀb / aᵀa) aᵀa = 0 ✓
q₁ = a / ‖a‖,   q₂ = B / ‖B‖

B is the error vector e from slide 2: the part of b that sticks out of the line through a.

A worked example

a = (1, 1),   b = (2, 0)
aᵀb = 2,   aᵀa = 2:   B = (2, 0) − 1·(1, 1) = (1, −1)
a · B = 1 − 1 = 0 ✓
q₁ = (1, 1)/√2,   q₂ = (1, −1)/√2

Three vectors and more

For a third vector c, subtract its projection onto each earlier direction:

C = c − (aᵀc / aᵀa) a − (Bᵀc / BᵀB) B

Each fraction is a number (a dot product over a dot product). Because a and B are already perpendicular, the two subtractions do not interfere with each other. Each new vector gets squared against everything built before it.

A = QR

Each original vector is a combination of the q's built so far: a uses only q₁, b uses q₁ and q₂, c uses q₁, q₂ and q₃. Collect the coefficients in a matrix R. It is upper triangular, and A = QR. Its entries are dot products, R = QᵀA.

A = 1210 = 1/√21/√21/√2−1/√2√2√20√2

Elimination recorded its steps as A = LU. Gram-Schmidt records its steps as A = QR. With A = QR, least squares becomes Rx̂ = Qᵀb, a triangular system. This is how good software solves least squares.

Where this is used

The drone's rotation matrix from the last slide drifts away from orthonormal. One Gram-Schmidt pass on its three columns squares it up again, a few times per second.

Worked examples

Example 1 · Two vectors in the plane

a = (1, 0), b = (3, 4).

aᵀb = 3, aᵀa = 1:   B = (3, 4) − 3·(1, 0) = (0, 4)
q₁ = (1, 0),   q₂ = (0, 1)

The result is the standard basis, and R = 1304.

Example 2 · Three vectors in 3D

a = (1, 1, 0), b = (1, 0, 1), c = (0, 1, 1).

B = b − ½a = (½, −½, 1)
C = c − ½a − (Bᵀc / BᵀB) B = c − ½a − ⅓B = (−⅔, ⅔, ⅔)
Checks: a · B = 0,   a · C = 0,   B · C = −⅓ − ⅓ + ⅔ = 0 ✓
Divide by the lengths √2, √(3/2) and 2/√3 to get q₁, q₂, q₃

Example 3 · The computer's version

np.linalg.qr(A) returns Q and R. For A = 1210 it may return −q₁ and −q₂ with a matching sign change in R. Both are correct factorizations. A direction and its opposite span the same line.

Check any answer with two tests: Q.T @ Q is the identity, and Q @ R gives back A.

What happens if b is a multiple of a?

Show solutionHide solution

Then b equals its own projection onto a, and B = 0. There is nothing to normalize, and Gram-Schmidt stops.

That is the signal that the vectors were dependent: b added no new direction.

Worked examples

Example 1 · Project onto a line in 3D

Project b = (3, 0, 3) onto the line through a = (1, 2, 2).

aᵀb = 3 + 0 + 6 = 9,   aᵀa = 1 + 4 + 4 = 9,   x̂ = 1
p = (1, 2, 2),   e = b − p = (2, −2, 1)
a · e = 2 − 4 + 2 = 0 ✓

The distance from b to the line is ‖e‖ = 3.

Example 2 · Fit a line to five points

Fit C + Dt to (−2, 0), (−1, 1), (0, 1), (1, 2), (2, 4).

The times are centred: Σt = 0, so the normal equations separate
5C = Σb = 8,   C = 1.6
10D = Σtb = 0 − 1 + 0 + 2 + 8 = 9,   D = 0.9

Best line: 1.6 + 0.9t. Choosing t so that Σt = 0 is a common trick: it makes the columns of A perpendicular.

Example 3 · Gram-Schmidt and QR in 3D

a = (1, 0, 1), b = (1, 1, 0).

aᵀb = 1, aᵀa = 2:   B = b − ½a = (½, 1, −½),   a · B = ½ − ½ = 0 ✓
q₁ = (1, 0, 1)/√2,   q₂ = B/√1.5
R = QᵀA = √21/√20√1.5

Check in the lab: Q, R = np.linalg.qr(A), then Q @ R gives A back.
