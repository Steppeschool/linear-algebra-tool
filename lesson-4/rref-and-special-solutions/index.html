Strang §3.2 · Solving Ax = 0 and Rx = 0

Free columns are yours to choose. Pivot columns follow.

To find the whole nullspace, reduce A to its reduced row echelon form R. Columns with pivots belong to pivot variables, the others to free variables. Setting one free variable to 1 and the rest to 0 gives a special solution, and every nullspace vector is a combination of these.

12132438  →  R = 12010012
Key ideas
  1. Elimination does not change the nullspace: Ax = 0 and Rx = 0 have the same solutions.
  2. Pivot variables belong to columns with pivots. Free variables belong to the other columns.
  3. Each free variable gives one special solution.
  4. An m by n matrix of rank r has n − r special solutions, and every vector in N(A) is a combination of them.

Think of a mixing desk

A mixing desk has four sliders. Two of them are free: you set them however you like. The other two are linked and move on their own to keep the total output at zero.

Free variables are the free sliders, and pivot variables are the linked ones. Each setting of the free sliders gives exactly one vector in the nullspace.

Reading R

R is the reduced row echelon form: each pivot is 1, and the pivot columns have zeros everywhere else. For our matrix

A = 12132438  →  R = 12010012

The pivots are in columns 1 and 3, so x₁ and x₃ are pivot variables, and x₂ and x₄ are free. Rx = 0 reads:

x₁ + 2x₂ + x₄ = 0    and    x₃ + 2x₄ = 0

The special solutions

x₂ = 1, x₄ = 0:   x₁ = −2, x₃ = 0  →  s₁ = (−2, 1, 0, 0)
Check with A: 1·(−2) + 2·1 = 0 and 2·(−2) + 4·1 = 0 ✓
The second special solution comes from x₂ = 0, x₄ = 1. That is your exercise.

Counting

A has n = 4 columns and r = 2 pivots, so there are n − r = 2 free variables and 2 special solutions. Every vector in N(A) is a combination x = c·s₁ + d·s₂, so N(A) is a plane inside 4-dimensional space. The number r of pivots is the rank of A.

A shortcut: the entries of R in a free column, with their signs flipped, are the pivot values in that column's special solution.

Worked examples

Example 1 · One free column

A = 123001.

row 1 − 3·row 2: R = 120001. Pivots in columns 1 and 3
Free x₂ = 1: x₁ = −2, x₃ = 0. Special solution (−2, 1, 0)

Example 2 · Two free columns

A = 11111234.

R = 10−1−20123
x₃ = 1: (1, −2, 1, 0).   x₄ = 1: (2, −3, 0, 1)

n − r = 4 − 2 = 2 special solutions.

Example 3 · A tall matrix

A = 122436.

R = 120000, rank 1
Free x₂ = 1: special solution (−2, 1)

Worked examples

Example 1 · Is it a subspace?

Is the set of all (x, y, z) with x = 2y a subspace of 3D space?

Zero: (0, 0, 0) has 0 = 2·0 ✓
Add: if x₁ = 2y₁ and x₂ = 2y₂, then x₁ + x₂ = 2(y₁ + y₂) ✓
Scale: cx₁ = 2(cy₁) ✓

Yes. It is a plane through the origin. With x = 2y + 1 it would fail at once: the origin is missing.

Example 2 · Nullspace and special solutions

Find the nullspace of A = 123246.

Row 2 − 2·row 1 = 0, so R = 123000. One pivot (column 1), rank 1.
Free: x₂, x₃.   x₂ = 1, x₃ = 0 gives (−2, 1, 0).   x₂ = 0, x₃ = 1 gives (−3, 0, 1).

N(A) is all combinations c·(−2, 1, 0) + d·(−3, 0, 1): a plane, dimension n − r = 3 − 1 = 2.

Example 3 · The complete solution

Solve x + 2y + 3z = 6.

Particular solution: set the free variables y = z = 0, then x = 6. x_p = (6, 0, 0)
Nullspace: the same matrix as Example 2's first row, special solutions (−2, 1, 0) and (−3, 0, 1)
x = (6, 0, 0) + c·(−2, 1, 0) + d·(−3, 0, 1)

Geometrically: a plane parallel to the nullspace, shifted to pass through (6, 0, 0).

Problems

1

Which of these are subspaces of the plane? (a) all (x, y) with x = y (b) all (x, y) with x + y = 1 (c) all (x, y) with xy = 0.

Show solutionHide solution

(a) Yes: a line through the origin.

(b) No: (0, 0) is not on it.

(c) No: it is the two axes together, and (1, 0) + (0, 1) = (1, 1) has xy = 1.

2

Find the nullspace of 1−12−2.

Show solutionHide solution

Both rows say x − y = 0. So N(A) is every multiple of (1, 1): a line.

Check: A(1, 1) = (1 − 1, 2 − 2) = (0, 0) ✓

3

Find R, the rank and a special solution for A = 121243364.

Show solutionHide solution

Row 2 − 2·row 1 = (0, 0, 1), row 3 − 3·row 1 = (0, 0, 1), then row 3 − row 2 = 0. Clearing above the pivot: R = 120001000.

Pivots in columns 1 and 3, so rank 2. Column 2 is free: x₂ = 1 gives the special solution (−2, 1, 0).

4

Are (1, 2, 0), (0, 1, 1) and (1, 3, 1) independent?

Show solutionHide solution

No. (1, 3, 1) = (1, 2, 0) + (0, 1, 1), so 1·v₁ + 1·v₂ − 1·v₃ = 0. The rank is 2 and the three vectors lie in one plane.

5

A is 3 by 5 with rank 2. Give the dimension of each of the four subspaces.

Show solutionHide solution

m = 3, n = 5, r = 2.

Row space r = 2, nullspace n − r = 3, column space r = 2, left nullspace m − r = 1.
