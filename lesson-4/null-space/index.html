Strang §3.2 · The nullspace of A

The nullspace: inputs that do nothing.

The nullspace N(A) contains every vector x with Ax = 0. These are the inputs that produce no output at all. It tells us whether solutions are unique.

N(A) = all x with Ax = 0
Key ideas
  1. N(A) = all solutions of Ax = 0. It always contains x = 0.
  2. N(A) is a subspace: if Ax = 0 and Ay = 0, then A(cx + dy) = 0.
  3. If A is invertible, N(A) contains only 0.
  4. A nonzero x in N(A) describes a dependency between the columns.

Think of engines running and a boat standing still

Back to the boat with two thrusters pointing the same way, thruster 2 twice as strong: A = 1224.

Run thruster 1 forward at 2 and thruster 2 in reverse at 1. The two pushes cancel exactly: both engines are working, and the boat does not move. The throttle setting x = (2, −1) is in the nullspace, because Ax = 0.

Why the nullspace is a subspace

If Ax = 0 and Ay = 0, then A(x + y) = Ax + Ay = 0 and A(cx) = cAx = 0. So sums and multiples of nullspace vectors stay in the nullspace. In the example, every multiple c·(2, −1) is also a cancelling setting, and N(A) is a whole line.

What a nullspace vector tells us

Ax = 0 says x₁·(column 1) + x₂·(column 2) = 0. So a nonzero vector in N(A) is a recipe for combining the columns into zero, which means the columns are dependent. Here: 2·(1, 2) − 1·(2, 4) = (0, 0).

If A is invertible, the only solution of Ax = 0 is x = A⁻¹0 = 0, so the nullspace is just the zero vector.

A worked check

A(2, −1) = (1·2 + 2·(−1), 2·2 + 4·(−1)) = (0, 0) ✓
In the plot, N(A) is the line through (2, −1). It is perpendicular to the row (1, 2). That is no accident: slide 6 explains why.

Where this is used

A robot arm with more joints than it needs has a nullspace. Joint motions in that nullspace move the elbow while the hand stays exactly where it is. Engineers use this freedom to steer the elbow around obstacles while the tool keeps working.

Worked examples

Example 1 · Equal columns

A = 1111.

Ax = 0 means x₁ + x₂ = 0
N(A) = all multiples of (1, −1)

Example 2 · An invertible matrix

A = 1234, det = −2 ≠ 0.

Only x = 0 solves Ax = 0. N(A) = {0}

Example 3 · A plane in 3D

A = [1 1 1], one row and three columns.

Ax = 0 means x + y + z = 0
N(A) is a plane, spanned by (−1, 1, 0) and (−1, 0, 1)

Worked examples

Example 1 · Is it a subspace?

Is the set of all (x, y, z) with x = 2y a subspace of 3D space?

Zero: (0, 0, 0) has 0 = 2·0 ✓
Add: if x₁ = 2y₁ and x₂ = 2y₂, then x₁ + x₂ = 2(y₁ + y₂) ✓
Scale: cx₁ = 2(cy₁) ✓

Yes. It is a plane through the origin. With x = 2y + 1 it would fail at once: the origin is missing.

Example 2 · Nullspace and special solutions

Find the nullspace of A = 123246.

Row 2 − 2·row 1 = 0, so R = 123000. One pivot (column 1), rank 1.
Free: x₂, x₃.   x₂ = 1, x₃ = 0 gives (−2, 1, 0).   x₂ = 0, x₃ = 1 gives (−3, 0, 1).

N(A) is all combinations c·(−2, 1, 0) + d·(−3, 0, 1): a plane, dimension n − r = 3 − 1 = 2.

Example 3 · The complete solution

Solve x + 2y + 3z = 6.

Particular solution: set the free variables y = z = 0, then x = 6. x_p = (6, 0, 0)
Nullspace: the same matrix as Example 2's first row, special solutions (−2, 1, 0) and (−3, 0, 1)
x = (6, 0, 0) + c·(−2, 1, 0) + d·(−3, 0, 1)

Geometrically: a plane parallel to the nullspace, shifted to pass through (6, 0, 0).

Problems

1

Which of these are subspaces of the plane? (a) all (x, y) with x = y (b) all (x, y) with x + y = 1 (c) all (x, y) with xy = 0.

Show solutionHide solution

(a) Yes: a line through the origin.

(b) No: (0, 0) is not on it.

(c) No: it is the two axes together, and (1, 0) + (0, 1) = (1, 1) has xy = 1.

2

Find the nullspace of 1−12−2.

Show solutionHide solution

Both rows say x − y = 0. So N(A) is every multiple of (1, 1): a line.

Check: A(1, 1) = (1 − 1, 2 − 2) = (0, 0) ✓

3

Find R, the rank and a special solution for A = 121243364.

Show solutionHide solution

Row 2 − 2·row 1 = (0, 0, 1), row 3 − 3·row 1 = (0, 0, 1), then row 3 − row 2 = 0. Clearing above the pivot: R = 120001000.

Pivots in columns 1 and 3, so rank 2. Column 2 is free: x₂ = 1 gives the special solution (−2, 1, 0).

4

Are (1, 2, 0), (0, 1, 1) and (1, 3, 1) independent?

Show solutionHide solution

No. (1, 3, 1) = (1, 2, 0) + (0, 1, 1), so 1·v₁ + 1·v₂ − 1·v₃ = 0. The rank is 2 and the three vectors lie in one plane.

5

A is 3 by 5 with rank 2. Give the dimension of each of the four subspaces.

Show solutionHide solution

m = 3, n = 5, r = 2.

Row space r = 2, nullspace n − r = 3, column space r = 2, left nullspace m − r = 1.
